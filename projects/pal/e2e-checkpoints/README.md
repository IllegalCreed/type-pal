# pal e2e 碎片地图 + 检查点

> **目的**:把整个游戏切成几百个小碎片,每碎片小到足够单独验证。每个碎片 =
> **一个起始存档**(`NNN-名.save.json`,秒进该状态)+ **一份流程说明**(本文件每节 + 可选单独 md)。
> **碎片 N 的结束存档 = 碎片 N+1 的起始存档**。这样重复 e2e 时可从任意碎片直接进、只验那一小段,不必每次从头跑。
>
> 碎片边界由作者(仙剑专家)定义 —— 见下方每节的「边界」。**Claude 不自行猜边界。**

## 机制(待建)

- **存档导出**:浏览器 evaluate 读 `buildPayload(world)` → 存 `NNN-名.save.json`。
- **存档恢复**:reforge 加 `?e2e-load=<save.json url>` 入口 —— fetch payload → `normalizePayload` → 注入 world + 跳该 scene(跳过 onEnter 演出),秒进碎片起点。
- **验证**:每碎片按流程走,双图对照一阶段(6002)、记录验证点。战斗一律 `?win` 速胜(e2e 只测流程/演出,不测战斗)。

## 001 · 开场

- **边界**:新游戏开始 → 到李逍遥在自己房间「可操控」为止。
- **起始**:`?menu` → 选「新的故事」(无存档,全新开局)。
- **流程**:
  1. 播 `3.mp4`(新游戏视频)
  2. `s000` 梦境:躺姿李逍遥 + 自动对话三句(narration「李~逍~遥」→ 梦话「作恶多端的罗煞鬼婆」…)
  3. `loadScene s001`(渐变)
  4. `s001` 叫醒:李大娘「李逍遥!你皮痒啊?敢说老娘是什么鬼婆!」→ 李逍遥起身(躺→站)→ 双方对话 → **李大娘离开(手动控 NPC 走位)** → 李逍遥独白「真没意思…」→ 走到床边开密道「嘿嘿」
  5. 演出结束 → 李逍遥可操控
- **结束状态**:李逍遥在 `s001` 房间可自由操控(= 002 起始存档)。
- **验证点**:
  - ✅ narration 槽渲染(Bug A)、控制码 `$XX`/`~XX` 解析(Bug B)
  - ✅ loadScene 目标正确(系统性 off-by-one -1;s000→s001 而非 s002)
  - ✅ videoId=3(新游戏视频,非开场 trademark 1.mp4)
  - ⏳ **李大娘离开途中停顿回头的格位** = 一阶段(GameUpdate 冻结停)vs 二阶段(手动走位停)须逐格一致
  - ⏳ #5:1/2.mp4 开场 CG 该在**启动游戏时**播(当前缺)
