## 目的

进行人物、战场、内容发布、调试、场景入场或共享脚本操作时，从这里进入对应指南。

## 范围

各指南维护操作步骤、输入与前置条件；格式和界面约束引用[现行规范](../specs/README.md)，不另造一套模型。

## 当前状态

本页是操作导航，不是已执行的runbook。具体操作是否可用、是否完成以及未决边界回目标正文与任务证据核实。
