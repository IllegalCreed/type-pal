## 5. 架构红线（75 个修复反推；建设时逐条过）

1. **单一 live 状态派生姿势**；任何"结算改状态、演出稍后画"的字段，先答"谁管过渡期显示"（pendingDeaths 模式推广）。
2. **时间线帧 = 副作用唯一挂点**（音/数字/屏波/位移），禁 dispatch 即时 emit；同帧同音 id 折叠。
3. 帧计数型副作用门控逻辑推进；补帧只读（time-based 幂等插值天然免疫）。
4. 屏幕特效战斗/探索**共用装配管线** + 统一层序 + 完整生命周期（设→叠→恢复→清）。
5. **UI 默认不画**，仅可交互选择期正向开启；transient 态同 tick commit 或显式 gate（防闪帧）。
6. 召唤链/收尾复位 = 高危模块：PostMagic 在神在场时抖完才淡出；fadeOut 首帧复位队员；坐标+姿势同帧归位；停顿帧 idle 呼吸活着。
7. per-action/per-battle 瞬态显式复位清单（iBlow 类击退、屏波叠加、替换精灵、隐身）。
8. 法术精灵层偏移（special）必填贯穿 z 排序；iColorShift 精灵**两遍绘制**（第二遍浮顶）防闪白被前排盖（`1fe40f17`）。
9. 群攻按群攻语义设计非单体特例（`b09dd757` 从零重建的教训）；全体目标立即提交不高亮（`82af407b` 防闪帧）。
10. **失败早退**：scriptOnUse 失败不放动画不结算（MP 已扣）；降级链（被封/MP 不足 → 普攻/防御）**已落地(2026-07-05 battle-core validatePlayerAction)**。
11. 全敌死 → 立即中止剩余 action 队列（`battle-system.ts:2415` 语义）。
