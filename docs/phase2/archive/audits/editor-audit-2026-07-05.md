## 2. 编辑器工作流盘点（对标 RPG Maker 功能面）

RPG Maker 系的编辑器 = 7 个核心工作流。逐个对照：

| # | 工作流（RPG Maker 对应物） | 现状 | 缺口（→ 已记地图格） |
|---|---|---|---|
| 1 | **地图编辑**（Map Editor + tile palette） | ❌ rail 占位「地图」 | 自有地图 tile 编辑器整个不存在；现只能复用原版地图（→ **W7 新格**） |
| 2 | **事件编辑**（Event Editor 指令页） | ✅ 强项 | 树+参数表单+模板库+演出预览+跳转预览，**超出** RPGM 2000 年代设计；缺：无脚本实体/场景加第一段脚本的入口（空态死路） |
| 3 | **数据库**（Database 9 页签） | ⚠️ 大半 | 角色/物品/敌人/敌队/精灵/音乐/变量 ✅；**技能页是空壳标签**（点了无内容）；locale 文案无编辑页（角色名等只读） |
| 4 | **素材管理**（Resource Manager） | ⚠️ 半 | 精灵库预览/布局/姿势框选 ✅；**无导入**（A4）；579 精灵 0 poses 待手工标注（工具已备） |
| 5 | **测试游玩**（Playtest F5） | ✅ | X5「🎮 引擎试玩」跳事件现场；缺世界态前置（flag 快照） |
| 6 | **项目管理**（新建/打开/部署） | ⚠️ | FSA 打开+保存 ✅；新建工程向导/导出 zip 缺（A3/A5）；**新建场景也缺**（只能编辑既有场景） |
| 7 | **系统设置**（System/Terms/Title） | ❌ | 标题画面/开场配置/词汇表——依赖引擎 X3，同期立项 |

### 布置模式的工作流断点（今日核实）

1. **放置流断裂**：「+ 添加实体」固定放 `sprites[0]`——没有「先选精灵再放置」的 palette 流
   （对标：RPGM/Tiled 的左侧素材 palette 是放置类编辑器的核心交互）。放完也没有换精灵入口（实体检查器精灵只读）。
2. **新建场景/换地图不可**：场景下拉只能切换；`reuseOriginalMap` 只读。
3. ~~图层开关/网格/禁入格是装饰~~ → **今日已接真**（渲染层开关 + 菱形网格 + 碰撞叠加）。
4. 命名入口/进场点在画布上无 pin 可视化（只在检查器表单里）。

### 事件模式断点

5. **空态死路**：0 脚本源的场景进入后只有一句「此场景无脚本源。」，没有「＋给实体/场景创建脚本」入口
   （命令层注释明说「v1 不新建脚本源」）。配合布置模式实体检查器的「行为脚本」区（今日加了跳转）——
   跳过去发现没脚本还是死路。**这是内容创作闭环的第一断点。**

### 数据模式断点

6. **技能页空壳**：TABS 有「✨ 技能」但无内容分支。
7. locale 文案无编辑入口（对话文本在事件表单里能改=改成字面量；但角色名/菜单词条没有编辑页）。

### 通用 UX

8. undo/redo 无键盘快捷键（⌘Z/⌘⇧Z），只有顶栏按钮。
9. 无全局搜索（跨域按 id/名字找东西）。
10. 校验问题条（底部「19 问题」）✅ 好设计——非阻塞、常显。

## 3. UI/UX 评审（基于 2026-07-05 六张实况截图）

**总体**：五区布局（rail/outliner/canvas/inspector/问题条）清晰专业，暗色主题统一，
信息密度与层级对标 GB Studio 水平，**架子是好的**。具体：

**做得好的**
- 布置画布：整图缩放平移 + 拖动移位 + Del 删除，操作提示常显（「整图·滚轮缩放·拖空白平移·133%」）；
  今日的菱形网格/禁入格叠加视觉清晰（红格与碰撞数据一致，与引擎同一套 buildIsBlocked 零漂移）。
- 角色模式帧网格：四向分组 + 站立/迈1/迈2 逐帧标注 + 步序预览「与引擎同源 sprite-anim」——考究。
- 物品页：图标+名字+价格+说明+JSON 兜底+被事件引用（可跳转）一屏成型。
- 事件模式三栏（源列表/树+预览/参数表单）+ 黄色未翻译标注 + 演出临时副本不改数据——设计成熟。

**要修的（按痛感排序）**
1. 放置 palette 缺失（断点 #1）——布置模式的核心交互没闭环。
2. 事件空态死路（断点 #5）——创作新内容的第一步就卡住。
3. 技能页空壳（断点 #6）——挂着标签点不出内容，比没有更误导。
4. 新建场景/换地图（断点 #2）。
5. 物品页中栏下半留白大（表单可分两列或补战斗/商店相关字段区）。
6. undo 快捷键（#8）——肌肉记忆级需求，一行 keydown 的事。

## 4. 地图模块（W7）体量评估

> 2026-07-10 更新：下表是 07-05 的历史拆分。W7D 已把早期“双层 + 碰撞位”方案返工为
> OwnMap v1（N 视觉层 + 独立碰撞层）；当前真值见 `capability-map.md` W7 与
> `foundation/content-schema.md` §5。

「自有地图编辑器」= 让创作者不依赖原版地图造新场景。拆解：

| 分期 | 内容 | 体量感 |
|---|---|---|
| W7a 数据模型 | 自有地图 schema（tileset 引用/双层 tile/碰撞位），`SceneDef.map` 变联合（reuseOriginalMap ⊕ ownMap）；引擎 loadTilemap 分流 | 中 |
| W7b tileset 管理 | 导入 PNG 切片成 tileset（依赖 A4 用户上传的一部分）+ 预览 | 中 |
| W7c 绘制工具 | 画布 palette 选 tile + 笔刷/矩形/填充/擦除 + 双层切换 + 碰撞标记笔刷 | 大 |
| W7d 迁移共存 | 原版复用地图场景照常跑；新场景用自有地图 | 小 |

合计 ≈ 今天一整天闭掉的 8 个格的总和。**建议**：等 E6 设计轮落地后单独立项，
分期推进（W7a 先行——schema 定对了后面全是 UI 活）；W7b 与 A4 素材导入合并做。

## 6. 追记（同日晚,作者三连反馈轮）

- **「布置」改名「场景」**（作者:布置=场景编辑的家,名不副实）;W7 地图模式 = tile 本体,分工清晰。
- **放置 palette 补缩略图**（作者:光看名字不知道是什么）——SpriteThumb 懒加载(IntersectionObserver+模块缓存)。
- **数据导航三改定稿**:挤堆 tab(审计前) → rail 二级展开(作者拍板后实施,**中文标签在窄条竖排断行,形态不成立,作者二次否决**) → **左栏垂直页列 2×4 网格(RPGM 数据库范式,定稿)**。教训:中文 UI 的侧栏子导航需要 ≥88px 文字横排空间,rail 加宽破坏窄工具条美感 —— 子导航应放进内容列而非 rail。
- **技能编辑器重做**(作者:太简陋/看不出效果):15 种效果 kind 结构化表单(顺序语义=gate 截断)+ 动画参数组 + **FIRE 特效实时预览**(帧率/循环起点/音效对齐引擎考证;65535=无特效哨兵容错)。完整战斗语境预览待引擎 B5 召唤/变身补齐(拍板记录)。
- **事件模块重组(作者提议,拍板分两步)**:Step1 已落 —— 数据模式「事件库」页(全工程 4369 源可查/过滤/跳转);**Step2 已落(2026-07-07,作者拍板底部抽屉形态):场景模式内嵌 ScriptDrawer(源列/指令树/表单+预览三栏),独立事件模式退役** —— 对标 RPGM/GB Studio 的内嵌形态,独立事件模式是「验证工具」时期的历史遗留。
