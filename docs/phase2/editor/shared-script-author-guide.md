# 共享脚本作者手册

共享脚本用于“改一处，所有调用方同时生效”的项目级逻辑。它不是减少录入步骤的万能容器，也不会替代普通指令和编辑器模板。

## 什么时候用哪一种

| 需求 | 选择 | 原因 |
|---|---|---|
| 只在一个事件里出现的对话、给物品、移动 | 普通指令 | 行为直接留在事件中最容易阅读 |
| 多次录入同一类流程，但文本、物品、数量等参数各不相同 | 模板 | 模板插入后展开为普通指令，各处可独立修改 |
| 多个场景或实体必须执行同一段固定逻辑，修改后要全部同步 | 共享脚本 | 所有调用方只保存稳定脚本引用，不复制命令体 |

当前版本只提供 `self` 执行实体上下文，不提供通用参数、返回值或局部变量。需要不同参数的流程应继续使用模板，不要为复用而把差异藏进全局变量。

## 创建与编辑

1. 在编辑器“数据”模式打开“共享脚本”。
2. 点击列表标题栏的 `＋` 新建脚本，填写显示名、说明和 `self` 契约。
3. 在指令树中插入并编辑指令；测试上下文可选择场景和实体后直接预览。
4. 显示名可以修改，`shared/user/...` 稳定 id 创建后不会随名称变化。
5. “复制”会创建新的稳定 id 和独立命令体；它不是原脚本的别名。

`self` 契约含义：

- `不使用`：脚本不依赖执行实体，调用时不需要指定 `self`。
- `可选`：有调用实体时继承或覆盖，没有时也允许执行。
- `必须提供`：调用点必须能继承当前实体，或显式选择一个场景实体；否则工程校验失败。

## 调用与跳转

在场景或实体脚本的插入菜单选择“调用共享脚本”，再选择作者脚本。调用行只保存目标稳定 id、派生 chunk 提示和可选 `self`，不会复制共享脚本体。

调用行的“打开目标”可直接进入共享脚本页。共享脚本页的“刷新引用”按需扫描工程，列出场景、实体和其他共享脚本中的直接调用方；点击引用可回到源位置。

## 删除与错误

- 有直接调用方的作者脚本不能删除；先根据引用列表处理调用点。
- 无引用脚本删除后，空分片会自动收敛；撤销可完整恢复元数据和命令体。
- 作者共享脚本之间不允许形成 `callScript` 调用环。
- 在作者共享脚本体中硬编码 `e12` 之类的场景实体 id 会产生警告。跨场景逻辑应优先使用 `self`。
- 保存会阻止悬空引用、缺失命令体、非法作者 id 和作者调用环。

## 迁移内部脚本

迁移器生成的内部脚本默认不出现在作者列表中。它们可从已有调用行打开并检查或编辑命令体，但稳定 id、显示归属和删除权仍由迁移管线维护，不能在作者页重命名或删除。

作者脚本保存在 `content/scripts/index.json` 的 `library` 元数据和现有分片命令体中。MG2 重迁会按稳定 id 三方合并：作者独有内容保留，双方同时修改同一命令体时显式报冲突，不会静默覆盖。
