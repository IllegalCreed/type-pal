## 0. 一句话定位

第二阶段的目标不是「复刻原版」,是**一个现代化引擎 + 一个能让人创作新游戏的编辑器**。原版仙剑降级为「试炼场 + 第一份内容包 + 迁移器练手对象」——**不再是验收标准**(见 [roadmap §8](roadmap.md))。

这张地图把「第二阶段要做成什么」从一团迷雾变成 **8 领域、63 格** 的可数集合(活账,撞到新东西就长)。一格 done = 引擎能跑 AND 编辑器能编。原版撞到新东西就加格,地图会长大。

---

## 1. 北极星

> **一个现代化、先进、合理的引擎 + 一个编辑器,用户能用它创建新内容、新游戏包,甚至制作一款全新的游戏(素材剧情全替换)。**

判据层级(从高到低):
1. **架构层**:一个领域改内部实现,不牵动别的领域(`@type-pal/content` 契约切干净)。这是「现代化」的硬定义。
2. **能力层**:地图上的格,引擎能跑 + 编辑器能编。
3. **内容层**:能用这套平台跑原版内容(回归沙盒)+ 创作新内容。

---

## 2. 原版的三条用法

原版仙剑在第二阶段的角色**不是验收标准**,是三件事:

| 用法 | 判据 | 动作 |
|---|---|---|
| **A · 试炼场** | 一格 done = 能在原版找到**至少一个**真实例子跑通,**不要求**全覆盖 | 每格定义时点名一段原版当考题;考题过=done |
| **B · 第一份内容包** | 迁移器产物能在新引擎实际玩起来;覆盖度**不作里程碑门** | 维护回归沙盒 checklist(§6);能玩打✅,跑不了标缺啥 |
| **C · 迁移器练手对象** | 翻译成现代 schema,覆盖率可量,未覆盖有账 | 迁移器 pending 项是「翻译待办」,不是「验收欠款」 |

**红线(铁律 #6 不让步)**:原版隐式怪癖机制(冻帧副作用、palette 轮转、下标当身份…) **不进新引擎**。非要靠脏耦合才能跑的原版编排 → 标回归沙盒「需重写脚本」,不把脏东西搬进引擎。

### 资产/分发(Assets & Distribution)— 在线编辑器架构([D21](decisions.md))— 7 格

## 5. 下一步选择器(每次开工先跑这个)

```
1. 扫地图,找所有 ⚠️ 半done格 → 有?
     → 挑 ROI 最高的(另一边已done,补缺口即闭合) → 做
   无 ⚠️ ↓
2. 找所有 ❌ 但下游有依赖的格 → 挑解锁最多的 → 做
   无明显高价值 ↓
3. 挑阶梯最底部的 ❌ 格 → 做
   都没有 ↓
4. 当前可见全 done → 跑回归沙盒(§6) → 撞到新东西 → 开新格
```

### 三规则

1. **先闭合半done(⚠️),而非开新格** —— 半done格回报最高(已有投入兑现成完整能力)。
2. **开新格前问「它解锁了谁」** —— 选下游有依赖者优先(X1 解锁 X5、E6 解锁 E7/N7)。
3. **同等优先级,先做阶梯底部** —— 地基先于上层,防返工。

### 纪律:一轮一承诺

选择器这一轮给出的格,**钉死做完(或明确判定不做)才进下一轮**。不允许「做一半又怀疑该不该做」——否则又陷入「是不是该做 E6 而不是 B1」的无限纠结。选择器是承诺机制,不只是建议。

## 8. 能力格发现协议(地图怎么长大)

撞到「原版有、新引擎表达不了」时,标准动作:

1. **先判是不是铁律 #6 该绕开的怪癖**(冻帧副作用、palette 轮转…)。
   - 是 → 标回归沙盒「需重写脚本」,**不开新格**。

   - 标在哪个领域(8 领域之一,或新领域)
   - 引擎侧/编辑器侧现状
   - 原版考题
   - 阶梯位置(依赖谁、解锁谁)

> 原版一个「机制」在新地图里常裂成多格——原版用脏耦合把多个独立功能焊一体,新引擎按职责拆开(冻帧→E6/N7/E7 三格;box-style→对话/旁白/物品框各自归系统)。地图因此长格,但长的格**少于**原版脏机制数(很多是同类反模式)。
