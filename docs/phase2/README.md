## 目的

顶层只维护开工原则、产品方向与进度；规范、使用方法、知识参考和历史材料分别由下层目录维护。本页不重复字段合同或执行结论。

## 当前状态

本页是现行导航。任务准入与状态看[活动看板](../tasks/board.md)及原卡；能力进度看[能力地图](capability-map.md)。导航存在不表示下游能力已通过验收。
