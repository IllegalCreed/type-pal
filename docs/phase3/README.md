## 为什么有这个目录

第二阶段早期讨论冒出大量玩法 / 世界观设想（种族 / 门派 / 御灵 / 炼化 / 阵法 / 五灵矩阵 / 因果轮回 / 羁绊…）和 MMO 留口。2026-06-25 判断：**这些是 MMO 量级的玩法系统设计，对「个人开发者做内容创作引擎 + 编辑器」的第二阶段是过早的范围**，只会徒增焦虑与过度设计。于是整体移交本目录，从第二阶段心智里清出去。

**性质 = 愿望清单 / 白日梦，不是承诺。** 第二阶段完全可以不碰它们；这些系统要不要做、怎么做，等引擎 + 编辑器 + 内容真正成熟后再说，甚至永不实现也没关系。
