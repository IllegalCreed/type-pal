Status: current
Last reviewed: 2026-11-02
Owner: Codex

## 目的

从 [AGENTS](../../AGENTS.md) 的工作分类进入，定位具体任务的目标、准入、当前状态与下一步。

## 范围

这里保存开发任务和长期工作；跨阶段规则统一在[工程规范与指南](../engineering/README.md)，阶段知识、测试与剧情回各自领域。计划写在对应任务中，不另建一套计划总账。

## 当前状态

看板安排活动分工，卡顶部 `Status` 是任务状态源；目录和生成索引不重复维护完成结论。

## 入口与责任

| 需要什么 | 只进入相关分支 |
|---|---|
| 接手开发或长期任务 | [活动看板](board.md) → 对应卡顶部、范围和准入 |
| 按任务 ID 查找或新建卡 | [任务卡规则](cards/README.md)、[完整／轻量模板](templates/README.md)；需要全量检索时才读[生成索引](cards/index.md) |
| 判断已有审计、代码治理与修复范围 | [审计入口](audits/README.md) → 对应账本或报告 |
| 核验某项交付 | 从原卡进入[任务证据](evidence/README.md)，只读相关候选和原件 |
| 查已结束的工作 | [历史归档](archive/README.md)，按日期、候选和原始范围追溯 |

## 证据与下一步

Coding Owner 同提交更新原卡和受影响的现行知识；Codex 核验后同步看板及生成索引。历史签字、旧交接与证据目录不加入普通开发必读，也不恢复执行授权。
