### 已证整改

- 成长行沿实际工程撤销序号丢弃过期草稿。空技能表不会创建虚假条目。经验曲线的平移从指针起点计算，取消只清本次草稿，缩短等级后画布仍显示合法点。
- WAV 读取、解码和播放失败由各自所有者释放。MIDI、图片和视频的并发导入在提交时分配目录 ID。音效依现存稳定 ID 合入原合同。
- 同一视频 ID 更换时按内容版本释放旧 URL 和元数据。帧画布只显示当前来源，错误出现时保留可用的缩略图。图片 Canvas 初始化失败时关闭已解码 Bitmap。
- [媒体撤销版本](EDITOR-MEDIA-UNDO-REVISION-1.md)经用户确认。图片替换及删除、WAV 替换与视频替换的四个交错红例通过。读取笔记确认磁盘提供缺省字节，存在的会话快照拥有版本优先权。
- MIDI 与音效选择器的浏览器播放器各由独立生命周期控制。跨工程同一素材 ID 可正常试听。上一工程的等待与释放不会改写下一工程，当前窗口关闭时释放相应上下文。

### 真实界面验证边界

Chrome 中以 PAL 工程测过 1280px 和 900px 的成长面板、原生滚轮缩放与等级缩短撤销。原生 WAV 播放和停止复位通过。同一素材 ID 的 MP4 换为 80×60，撤销恢复 288×180。浏览器无页面异常，控制台有 32 条隔离环境未提供可选 `save-state.json` 的 404，原件保留。MIDI 和音效选择器竞态由真实业务入口和可控 Web Audio 端口复验，示例只证明明确的初始化与释放行为。
