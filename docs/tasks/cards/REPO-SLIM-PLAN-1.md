## 目标

Agent从AGENTS工作分类进入薄索引，只读必要的现行规则、知识和任务；开发留痕按需追溯。清理已证明多余的载体，保留可复核的必要证据与恢复来源。治理对象数、物理文件数、工作树字节和Git历史空间分开报告。

本轮完成出口是下列存量候选全部处理、保留对象有具体理由、读取与质量合同通过。后续开发按[产物收口流程](../../engineering/guides/agent-workflow.md#任务产物收口用户-2026-11-02-固化)持续执行，不把所有未来产物或全仓代码治理设为本次结束前提。用户要求全部瘦身工作收齐后再提交PR。

| 保留对象 | 已核理由 |
|---|---|
| 当前代码、测试、依赖声明 | 现行runner/接口/工具消费者存在；未形成可证删除项，后续代码治理不作为本次未完成项 |

| 原生JSON/HTML、图片及已压缩原件 | 保留语义、执行/transport身份、许可和复核用途；不为小余量再建千行共享机制 |
| 大型N3/E2E/Save历史Markdown | 已退出默认阅读，含被规范/剧情引用的锚点与独有历史内容；不以大或旧直接删除 |
| reference/data与原脏工作树 | 上游真源、许可、字体输入或用户已有改动；归属与恢复边界不同于本轮可删载体 |

所有已确认候选均有本轮动作或上述保留理由。本轮没有留下无Owner、无到期规则的“临时待定”对象；未来新产物沿公共流程收口，不再给旧总纲增加平行流水账。
