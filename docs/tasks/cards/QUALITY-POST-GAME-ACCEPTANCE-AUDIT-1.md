## 验收

26 个后来变动的路径全部是测试，涉及 29 次变动。24 次能在后继归档定位到新版本指纹。#71 的五次由 Git 增量、原始用例及现行文件重新对齐。复跑现行四个 Reforge 文件 41 项、一个 Editor 文件 14 项，两次均 exit 0、无诊断或跳过。分别核对新断言观察的帧字节、URL、场景落点、播放清理及 Worker 终止结果。

[唯一执行归档](../evidence/QUALITY-POST-GAME-ACCEPTANCE-AUDIT-1.tar.gz)保存字节对账重放器 `trace-review.py`、实际结果、两个 Vitest 原生报告和占位精灵命令回执。可将重放器读到临时文件，从仓库根执行 `python3 <重放器路径> <临时输出.json>`。它核对主线账本变化、原卡存在性及候选身份。源码、调用及断言的判断见上表和对应原卡。重型产品包门与官方覆盖率由稳定代码批次统一执行。

### 输入不变性同类回查

六次合并新增关闭的 test 类路径有 260 份，其中 248 份为 `*.test.ts`，12 份为测试夹具、辅助模块和声明。对 248 份专测按 `does not mutate`、`without mutating`、输入不变、不污染等标题措辞初筛，逐个对照命中用例的输入与断言。#72 的来源不变性见原卡。另查实两条超出实际断言范围的结论。

- #68 的 `entity-lifecycle.test.ts:62–74` 通过存档解码实际调用的 `normalizeEntityLifecycleTable` 验证未知场景及实体报错。两条失败只指定错误。输入独立性断言使用第三份合法输入，验证正常归一的结果可独立修改。标题将成功路径的观察范围扩到了拒绝路径。须收窄标题并区分两类合同，或直接对失败输入做前后比较。
- #70 的 `scene-preflight.chain.test.ts:324–331` 验证合法无脚本世界仍得到继承的进入演出，输入 `script` 保持缺席。`ScenePreparer.assertCurrent` 只重算场景切换依赖，`scene-switch-transaction.ts:27–60` 明确排除无关金钱等字段。须把全世界状态不变的表述收窄到实测字段，或用请求前独立快照核需要保留的状态。

### 扩查结果与本轮整改

2026-11-20，按六次合入时的 374 个候选再次检查测试声明、路径名及直接文件写点。在 248 份专测中识别 1,403 个字面测试声明，71 个文件有 133 条生命周期或输入不变性的筛查命中。按名称规则扫描未见模型/波次标记，按字面测试声明未见 `.skip/.only/.todo`。这些数字用于定位证据，未把一次声明扫描认作全量八维重审。

扩大复核聚焦两个重复失误：异常退出和并发测试漏掉真实状态变化，文件工具的正例漏掉固定输出路径的所有权。核对每个直接写点及相关命中用例的在途时点、状态断言和隔离宿主。发现并处置 FBP 缺省输出、BGM 取消预取与编辑器资产删除专测三处遗漏。Worker 的双请求、同键位图的新旧待办、淡入淡出接管和 MIDI 试听的迟到请求均有实际的在途门槛及不同结果观察。仍有效的原八维锚按原候选范围引用。
