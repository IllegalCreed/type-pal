## 目的

## 范围

## 当前状态

current只指导航；当前状态以原卡顶部及明确后继裁决为准。[全量文档治理](../cards/DOCS-FULL-TEMPLATE-1.md)已done，旧“当前治理仍rework”属于早期时点，不能覆盖母卡终态；历史撤信也不因后继完成恢复。
