> > > #### 3. A namespace 的唯一内容选择

> > > - namespace 是 `.governance/docs/terminal`。规范 leaf 只允许 `<lowercase40D>.json.gz`、Git100644、物理 regular。目录父链不跟 symlink。名字、坏后缀、padding、symlink、gitlink、额外目录/文件必须诊断，不能先 filter `.gz`。

> > > - **physical**：递归全枚举，包括 ignored/untracked。每个 leaf 的实际 bytes 走同一个有界 codec、J、schema。恒定选 physical；坏 physical 不能退回 good index/HEAD，good physical 不因旧 index/HEAD 坏 bytes 被当下内容门永久拒绝。

> > >
> > > #### 4. 有界读取与 codec 的准确次序
> > >
> > > 压缩完整帧≤8,388,608 B，decoded 完整 J bytes≤67,108,864 B（含唯一 LF）。物理读取前 lstat 父链/leaf，FD no-follow + fstat regular；已知 size 超限先拒，最多读 cap+1，核前后 identity、短读、额外增长和最终路径 identity。Git blob 先查类型/size，再有界管道读，核实际长度；不先任意 readFile/cat 输出后才测。
> > >
> > > Git rawNUL 元数据也不得无限 capture；采用受审固定 stdout 界限或有界逐 record 流式处理/hash，截断/overflow/error 都失败。具体实现 limit 必须在候选代码和 focused 测试中明确，不冒称64MiB decoded 上限就是整个 Git/heap 的总上限。
> > >
> > > 固定 header=`1f8b08000000000002ff` → `inflateRawSync(rest,{info:true,finishFlush:Z_FINISH,maxOutputLength:67108864})` → consumed c 是 subarray10 的安全整数且剩余恰8 footer/EOF → CRC32/ISIZE 等真实 decoded → fatal UTF8/BOM 拒 → 全层 decoded duplicate keys → J exact bytes → schema → A 指定元数据。无 gunzip、第二 member（空的也拒）、尾零、optional header、Z_SYNC_FLUSH 或后缀 fallback。
> > >
> > > encoder manual fixed10header + level9 rawDEFLATE +真实 CRC/ISIZE，同样守两 byte caps，不接 caller override。固定 inflater 平台行为沿已读真实独立/原生报告；本次不重冒 strict codec 已实现。
> > >
> > > parser 根 container depth1、primitive 不增深、最高128；根 value计1，每 member/element的 value再计1，container不双算，最高2M。单 string=原 JSON token内容 UTF8 bytes≤16,777,216，不含两引号、含 escape，key/value 同规。扫描中、入栈/集合/分配前检查，不先整树 JSON.parse，不平方复制 remainder。不是 heap/RSS cap。
> > >
> > > 全层 duplicate key 按解码后的 key 判，own-key 安全，包括 `__proto__` 和 escape-equivalent 名字；不重写 prototype。J 直接按 JSON.stringify(key) UTF8 无符号 byte 排序输出 token，不能先建 object 再 stringify（整数key会被重排）；path tuple 按原 path UTF8。scalar quoting 沿原 JSON.stringify，`-0` 特判、lone-surrogate 按原规则，有限数/无 hole/undefined，唯一末 LF，不归一化 Unicode。

> > > #### 5. A 的 closed schema 与 B 的实际解析分界
> > >
> > > A 解析对象必须由显式 named schema 分派，未知 top key、tag-union extra/missing、未知 tag 均拒。13 top keys、各 named exactKeys 与 unions 是已冻结 wire 值；完整逐定义字段清单在同 stem JSON 的 `closedWireSchema` 中，直接取自固定 wire，不新增兜底变体。A 不 import model/core，不造 empty/default source、33cc、full 或 approval。
