# docs/ops/evidence/ — 任务卡证据产物

任务卡引用的截图、性能测量、census 产物等证据。全部为 **evidence（时点证据）**：记录产生
当时的观测，不承诺随后不变；产品真值以源码与当前工程为准。

约定：

- 目录/文件以引用它的任务 ID 命名（如 `ED-3/`、`ED-SHOP/`、`ED-3A-reference-index-performance-2026-09-04.md`）。
- 截图目录禁止提交超大二进制；单图与 Markdown 报告可直接存放。
- 证据不作为当前状态的唯一依据——引用它的任务卡若已关闭，本目录内容即为历史。
