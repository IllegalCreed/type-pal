# 任务模板

Status: current
Last reviewed: 2026-10-15
Owner: Codex
Template: governance-index-v1 / 1.0.0

## 目的

选择任务卡的完整或轻量变体；两者都属于 task-card，不产生平行的文档类型。

## 范围

只导航模板，不记录实际任务状态或授权。创建任务时填写单一初始状态，再按[现行工作流](../agent-workflow.md)推进。

## 当前状态

当前准入为 Codex 核前提、范围、单一 Owner 与验收方式；已获授权的普通维护不因模板整理重复要求签字。

## 入口与责任

- [完整任务卡](TASK-template.md)：高风险、跨包/schema/save/资产/机制或大规模 generated rewrite。
- [轻量任务卡](TASK-lite-template.md)：前提简单的中等任务；触发高风险时升级完整卡。
- [任务卡说明](../tasks/README.md)：命名、索引、准入与历史边界。

## 证据与下一步

完整/轻量模板的验收提示均接入[长期工程质量规范](../code-quality.md)：逐文件八维结论、问题处置、候选身份与失效条件、快速复验及原始结果。任务卡类型、状态词和必填章节合同保持，纯文档任务按实际范围说明适用性；小改可紧凑引用已有完整记录，不为填表新造专项。

模板结构由[统一注册表](../../phase-governance/templates/README.md)管理，任务实施和签字只落实际卡。上级为[协作与工程维护](../README.md)；创建后由 Coding Owner 补实证据，不以空模板充当交付。
