本页是 ops 历史任务归档的当前导航：只负责把读者送到 done/cancelled 两类归档卡与当前操作入口。被索引任务仍按各卡顶部状态和原文日期解释，本页不授予当前 build 授权，也不证明 runtime/E2E/视觉/coverage。

## 目的

- 区分已归档的已完成（done）与已取消（cancelled）任务入口，并接入统一机器索引，防止把历史卡误当当前执行授权。

## 范围

- 当前包含：done/cancelled 两类归档任务的目录入口，以及统一任务索引、任务卡说明、看板和协作流程等当前操作入口的导航。
- 明确不包含：逐卡清单复制、done/cancelled 语义与结论的重述、当前 build 授权、runtime/E2E/视觉/coverage 结论。

## 当前状态

- `status`: current（仅指导航）；被索引的历史任务保持各自的 done/cancelled 终态。
- 任务事实源是各卡顶部 `Status`：统一索引按卡顶部状态分组投影，不从目录名推断；原句「所有卡片都进入活动目录中的统一机器索引」指统一索引位于 `docs/ops/tasks/`，不是要求历史卡搬回活动目录，终态卡允许原位关闭。

## 入口与责任

- 归档分类：[已完成任务](done/README.md)、[已取消任务](cancelled/README.md)。
- 上级归档：[运维历史归档](../README.md)。
- 当前操作入口：[统一任务索引](../../tasks/index.md)、[任务卡说明](../../tasks/README.md)、[活动看板](../../board.md)与[协作流程](../../agent-workflow.md)。
- Owner：Codex（文档治理）。历史卡的执行、签字与回执责任保留在原卡；文档 review 只证明治理呈现，不是任务事实源，也不能重授历史执行。
