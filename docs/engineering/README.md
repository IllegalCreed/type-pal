## 目的

按 [AGENTS](../../AGENTS.md) 的工作类型选择跨阶段规范和操作指南，只读当前任务需要的条款。

## 范围

持续有效的规则统一放在[指南目录](guides/README.md)；具体任务、状态与执行证据由[任务入口](../tasks/README.md)承载。阶段规范、测试合同与剧情知识留在各自领域。

## 当前状态

本页是导航，规则以对应正文为准。历史协议与机器治理登记按需追溯，不作为每次开工的默认上下文。

## 入口与责任

| 需要什么 | 下一层 |
|---|---|
| 现行开发、质量、文档与环境规则 | [指南目录](guides/README.md)，按工作选择具体正文 |
| 追溯协作协议 | [历史协议](archive/protocols/README.md)，不恢复旧三签门禁 |
| 维护模板、路由、检查器或评审存储 | [文档治理存储](../phase-governance/README.md)，只在维护机器消费者时进入 |

## 证据与下一步

规则或工具改变时同提交更新对应指南与消费者。旧目录封套和原文保存在[迁移前固定版本](https://github.com/IllegalCreed/type-pal/blob/159cd0e2f8753536800ba4635e896020a897fddc/docs/ops/guides/README.md)；当前导航不继承旧页面的执行结论。
