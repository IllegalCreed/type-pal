## 自动职责与局部接管

当前 1329 个自动方案均为一步，自动正文没有关键对白、奖励或切场。25 个选择中有 5 个指令切 trigger：

这些指令本身不证明主剧情藏错入口；例如 s048 显式恢复 interact，下一次玩家交互才领奖本就合理。
名字可写清“动作完成后开放交互”，不应该把每个 select 都改成立即 run。

`docs/phase2/archive/designs/e6-position-authority-design.md:58` 明确 release 后恢复。

`:1080` 自动安全点检查也没有 authority 条件。因此在主链已 take 一个实体后，它的 pose auto 仍能写姿态。
这是公共执行路径缺口，不能再在每个 NPC 上用停止全局 auto 掩盖。
