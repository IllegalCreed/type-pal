# 动态脚本安装边普查

本工具为共性治理提供完整的原始安装指令分母和保守的当前方案映射，帮助审查后继丢失、重复奖励、错误复读。
它不是退役转换器的恢复版，不生成剧情，不修改作者工程，也不把候选命中数当缺陷数。
任务范围与产品准入见[治理任务卡](../../ops/tasks/SCRIPT-GOV-1-script-family-governance.md)。

## 重跑与输出

```sh
node --test scripts/script-governance/*.test.mjs
node scripts/script-governance/run.mjs
```

需要Node 22.18以上及本机原始提取输入。运行器只接受仓库内固定输入，不接受修复、工程写入、任意输入或输出路径参数。
完整结果写入忽略目录`build/script-governance/install-census.json`。保留所有原始边和调用上下文，命中映射附原始段与当前行为SHA256。
[入库快照](install-census.json)固定读取修复前`8990f0cde`的作者内容，仅保存地址、身份、计数、摘要和hash，不含原版对白正文。
它保留初扫29条候选的观察结果，后续三条显式交接反例已在下表纠正；不会用当前修复内容覆盖旧基线。
快照不随着产品修改自动成为新的验收结论；重跑后的输入hash不同，必须重新审查。

## 分母与身份

原始`all.json`有43,503条指令，所有已有label均与全局指令地址一致。完整枚举得到639条0x24或0x25指令：

| 分类 | 指令边数 | 含义 |
| --- | ---: | --- |
| auto安装类指令 | 418 | 包含实际安装、清绑定和无操作 |
| trigger安装类指令 | 221 | 同上 |
| 实际非零安装 | 580 | operand0非零且目标入口非零 |
| 清绑定 | 53 | operand0非零且目标入口为零 |
| 无操作 | 6 | operand0为零，不能当self安装 |

两种通道分类与后三种效果分类是两个维度，不能相加。另有48条operand0为65535的self指令。
按通道、operand0、入口去重是554个非零绑定，但去重不能替代639条调用边的分母。

场景根来自全部295份原始场景的显式`sceneId`、`eventObjects[].id`、`triggerLabel`、`autoLabel`、
`onEnterLabel`和`onTeleportLabel`；另读道具、法术、敌人与角色脚本根。这些额外根不冒充世界NPC身份。
原始ID至当前ID的约定来自现行[内容供应核](../../../packages/migrate/src/pal-content-supply.ts)，不是数组顺序。
每个候选仍须检查原始实体确实存在、目标场景中canonical实体确实存在；缺失或重复身份不能进入确定映射。
当前作者场景按`content/scenes/index.json`的显式清单加载，共294个；索引文件本身不是第295个作者场景。

## 调用上下文与可达性

每条原始安装指令独立保留，不采用旧注册缓存，也不因另一个call、goto或安装已见过同一入口而丢弃本边。
显式操作数使用经过存在校验的全局ID；65535的self从每个caller继承，出现多个owner全部保留。
场景入场、道具和未知caller的self保留unknown。特别是0x04调用的operand1：0继承caller，65535并非self。

静态根、动态安装根、场景hook根分别追踪。报告区分直接从静态根触达、经动态安装触达、仅未证动态根触达、
未在建模根中观察到四类；后两类不等于死代码。条件分支取可能分支，不能据此证明玩家一定能够触发。
这是一张结构图，不是原引擎执行器；调用返回、auto/trigger调度与分支条件没有被重新实现成运行时。

## 映射和结论等级

`mapped`只表示同一实体和通道下，原始目标首段的可识别正文指纹唯一对应当前方案，且竞争源入口没有同指纹。
指纹使用对白ID、给物品、指定帧、切场等稳定标记，不使用`legacy-001`等名称推断源地址，也不以一句相似台词下结论。
指纹不覆盖所有指令语义，因此映射成立不等于正文未被作者改过，更不等于已经证明后继正确。

| 状态 | 可以说什么 | 不能说什么 |
| --- | --- | --- |
| mapped | 有唯一正文映射线索，可以核完整绑定和游标 | 自动等价、自动修复或已验收 |
| unknown | 源有分支、标记不足、身份未明或正文不同，需要继续核 | 这就是缺脚本 |
| multicontext | 有多个caller owner、正文或源入口候选 | 任选一个当成正确答案 |
| author-protected | s000至s005作者改写保护，禁止自动判错覆盖 | 忽略这些边或重新迁移 |
| clear和no-op | 清理绑定或原本不操作 | 错误地注册一个空脚本 |
| proven-missing | 需独立核原始后继、当前实际绑定和连续激活反例后另记 | 仅因后继标记未出现就判定 |
| already-fixed | 需当前内容hash、真实runner验证和独立验收后另记 | 后继正文在某个别的方案出现就算修好 |

自动扫描器不签发最后两种结论，其对应计数固定为0；实际已修/无问题/待核状态由任务卡与经过独立验收的修复台账维护。
扫描候选只是审查优先级：源段advance/reset后有独特内容，但当前被安装方案缺失，或源给物品后advance而当前单步重复。
其他方案已有相同后继、甚至本方案存在不可达后继，都不能证明本NPC下次交互游标会正确进入它。
