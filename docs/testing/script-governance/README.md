## 普通步骤治理原则

方案代表剧情时期，步骤代表多次激活中的进度，正文中的连续走路、转身和等待不应被拆成下一次激活。
作者最终只使用方案、步骤、指令；内部执行游标不能变成另一套需要作者理解的“高级连续流程”。
本轮先整理现有指令足以表达的部分，复杂机器尚未全部退役。
