## 第一阶段的激活和游标语义

`packages/game/src/core/scene-system.ts:304` 优先读取实体的 `triggerResume.ip`，否则使用 `triggerLabel`，并把触发者记为 `triggerOwnerId`。
`packages/game/src/core/event-system.ts:1922` 对最外层结束指令结算：`advance` 保存下一条全局 IP，`reset` 保存指定入口，普通 `end` 保持已推进的入口。
