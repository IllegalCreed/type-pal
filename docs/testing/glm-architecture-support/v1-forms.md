## 分类条目

- **V1-001 covered** V1-01/V1-02/V1-05：表单布局、间距、按钮文案、状态色符合现行设计系统
  （`docs/phase2/specs/editor-design-system.md` DS-F.4 阶梯与 §文案 规则）。
- **V1-002 risk（交互语义一致性）** 技能多选弹层"逐击即提交 + Esc 仅关闭"；而 D-01/quick-trial
  族（App.leave-guard.test.tsx:199）是"草稿 + 显式同意替换"模型。两种语义并存——不是缺陷证据，
  建议产品/实施确认多选类控件是否应有统一的取消保真语义。
- **V1-003 risk（无障碍）** 弹层顶部过滤输入**无可访问名**：弹层打开时的 ARIA 快照无该输入的
  textbox/searchbox 条目，视觉上也无 placeholder 提示（空聚焦框）。键盘/读屏用户无法得知其用途。
  静态+视觉双证；建议实施补 `aria-label`/placeholder（一行改动级）。
- **V1-004 N/A** 360px 只记录既有边界（V0/工作包纪律），未测，不提新要求。
- **V1-005 blocked** ActorMode、TrialDialog、物品/敌队/战场 Tab 独立页面未本轮截图——不假装覆盖；
  判定方法与 V1-01 相同链路可复用。
