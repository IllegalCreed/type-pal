# 仙剑江湖势力关系图（factions）

> 仙剑世界观的势力结构总览。**扩展创作时先看这张图**，确定你要写的故事落在哪个体系、会不会和别的线打架。
> 广度版（2026-06-25 查证）。各势力的细化待"深度挖掘"时按需补。
> 可靠性：✅ 多源一致 ＞ ⚠️ 单源/解读 ＞ 💡 官方无设定（可创作空间）

## 总览：四大体系（彼此基本不交叉）

```
┌─ 中原武林（凡人江湖）─────────────┐
│  南林北沈（南北对立）              │
│  + 各门派（唐门/霹雳堂/丐帮…）     │
└────────────────────────────────────┘
┌─ 朝廷 vs 江湖（官盗对立）──────────┐
│  三大神捕 ↔ 四大恶人（四方位）     │
└────────────────────────────────────┘
┌─ 修仙门派（超然物外）──────────────┐
│  蜀山 / 仙霞 / 水月宫 / 琼华       │
└────────────────────────────────────┘
┌─ 苗疆（独立体系）──────────────────┐
│  黑苗族（南诏）↔ 白苗族（大理）    │
│  + 女娲族（贯穿守护）              │
└────────────────────────────────────┘
```

**关键**：这四组之间官方几乎没有交叉。挑任何一组深挖，不会和别的线打架。

## 一、中原武林：南林北沈

> ✅ [知乎·江湖势力大揭秘](https://zhuanlan.zhihu.com/p/501314444)、[沈家堡·百度百科](https://baike.baidu.com/item/%E6%B2%88%E5%AE%B6%E5%A0%A1/9777297)

| 势力 | 据点 | 盟主 | 出处 | 备注 |
|---|---|---|---|---|
| **南武林** | 林家堡 | **林天南**（月如之父，40岁/仙剑一） | 仙剑一 | 家传剑指双绝 |
| **北武林** | 沈家堡（济南） | **沈青锋**（"镇三山"，欺霜之父） | 仙剑二 | 妾室所生女沈欺霜不受待见 |

- **"南林北沈"大会**：官方设定，两者"数次交锋"，既有合作也有竞争。
- **镜像结构**：林天南（仙剑一月如之父）↔ 沈青锋（仙剑二欺霜之父）——两个"盟主父亲"，分属两代女主角。
- 林天南因月如重伤寻续命方而淡出武林。

**💡 扩展金矿**：南林北沈的"数次交锋"官方只给了一句话，没展开。**林天南的盟主往事 + 与沈青锋的南北博弈**是干净的武侠题材，且林天南是你点名想做的"独立入口 DLC"候选。

### 四大恶人（江湖侧，朝廷通缉，四方位）

| 称号 | 姓名 | 方位 | 状态 |
|---|---|---|---|
| 东江虎 | **游天霸** | 东 | ❓ 官方几乎无展开 |
| **南盗侠** | **李三思** | 南 | ✅ 李逍遥之父（已坐实，详见 [characters.md](characters.md)） |

**💡 顶级扩展金矿**：**东/西/北三个"恶人"官方只给了名字和方位，没有故事。** 你可以为游天霸、司马无忧、钱无通补完前史，让他们与李三思并列为"四大恶人"群像——**这是官方留的结构缺口，填它等于补完世界观**，且不碰任何红线。

## 深度挖掘优先级建议

按"官方背书强度 × 创作空间 × 不碰红线"排：

1. **李三思夫妇之死 + 皇甫英暗线**（已查证，顶级金矿）
2. **四大恶人群像**（东/西/北补完，结构缺口）
3. **南林北沈 / 林天南往事**（武侠题材，官方有骨架）
4. 苗疆线深化（盖罗娇/圣姑/巫王，已部分查证）
5. 修仙门派前传（涉及蜀山代数，较受约束）
