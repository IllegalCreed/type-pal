# 世界规则（world-rules）

> 仙剑世界观的核心设定。扩展创作时引用这些规则必须前后一致。
> 可靠性：✅ 官方/多源一致 ＞ ⚠️ 单源/解读 ＞ ❓ 存疑
> 最后查证：2026-06-25

## 一、五灵珠（核心道具，贯穿全系列）

### 基本设定 ✅
- 五颗灵珠 = **风、雷、水、火、土**（对应五灵之力）。
- **只有女娲及其后人能催动灵珠的灵力**（赵灵儿用灵珠祭天救世）。
- 灵珠灵力一旦耗尽，会在灵气聚集之地**重新凝聚成新的灵珠**（"五灵轮回"机制）。
- 来源：✅ [游民星空·编年史](https://www.gamersky.com/handbook/201607/786912.shtml)、[百度百科·仙剑年表](https://baike.baidu.com/item/%E4%BB%99%E5%89%91%E5%B9%B4%E8%A1%A8/2690919)

### ⚠️ 来源分歧（扩展要注意）

| 作品 | 五灵珠来源说法 |
|---|---|
| **仙剑一** | 女娲利用**风神、雷神、雪妖、火神、山神**五神骸骨炼成，由**苗族世代相传**，后失散 |
| **仙剑三 / 三外传** | **三皇**将大地五种灵力凝聚成五颗灵珠 |

来源：✅ [知乎专栏·系列背景](https://zhuanlan.zhihu.com/p/661149729)

> **⚠️ 扩展注意**：这两套说法并不一致。仙剑一扩展应以**仙剑一的"五神骸骨 + 苗族相传"**为准（本项目主线是仙剑一），但在跨作品引用时需注意冲突。这是 [versions.md](versions.md) 该登记的条目。

### 仙剑一中的五灵珠获取（大致）❓
- 散落各处，李逍遥一行需集齐 → 前往大理女娲神殿祭坛施法救世。
- 各灵珠具体获取地点 / 关联剧情：**待查**（扩展用到时补）。

> 仙剑世界观的宏观框架。本节待扩展需要时深入查证，先放骨架。

## 三、女娲族传承（最关键的世界规则）

> 详见 [timeline.md](timeline.md) 的传承链表。这里讲规则。

| 规则 | 内容 | 可靠性 |
|---|---|---|
| 守护宿命 | 女娲族后裔代代守护人界苍生，以身殉道 | ✅ |
| 灵力传承 | 母亲将力量传给女儿，代代相传 | ✅ |
| 生育即亡 | 一旦繁衍后代，母亲灵力衰竭而死（生子前理论上不死） | ⚠️ 粉丝解读 |
| 不入轮回 | 死后不入轮回 | ⚠️ 粉丝解读 |

> **⚠️ 待核**："生育即亡""不入轮回"在粉丝圈广泛流传，但是否为**官方明文**需确认。扩展剧情动用这两条前，建议作者先查官方表述。

### 女娲族能力 ✅
- **回魂仙梦**（回到过去 / 梦境，李逍遥回十年前即此能力）
- **御灵**（驾驭灵兽）
- **驾驭五灵**（催动灵珠）
- 来源：[百度百科·女娲族](https://baike.baidu.com/item/%E5%A5%B3%E5%A8%B2%E5%90%8E%E4%BA%BA/9097458)

## 四、蜀山（核心组织）

> 仙剑系列核心组织。李逍遥后续成为蜀山掌门，扩展若涉及后传必须用对设定。

| 项 | 设定 | 可靠性 |
|---|---|---|
| 蜀山仙剑派 | 修仙门派，历代有掌门传承 | ✅ |
| 掌门代数 | 李逍遥为**第 27 代**（仙剑二时）；徐长卿为第 23 代（仙剑三全盛期） | ✅ |
| 蜀山七圣 | 李逍遥晚年卸任掌门后成为蜀山七圣之一 | ✅ |
| 锁妖塔 | 蜀山镇妖之所，仙剑一关键场景（救灵儿、月如重伤） | ✅ |
| 酒剑仙司徒钟 | 李逍遥的师父，蜀山系人物 | ✅ |

来源：✅ [维基·李逍遥](https://zh.wikipedia.org/zh-cn/%E6%9D%8E%E9%80%8D%E9%81%A5)

> **扩展注意**：掌门代数是硬约束——若扩展涉及蜀山前传（如李三思时代），徐长卿（23 代）与李逍遥（27 代）之间还有 24-26 代，扩展不得乱编掌门代数。

## 五、苗疆 / 黑白苗（仙剑一故事主舞台）

| 项 | 设定 | 可靠性 |
|---|---|---|
| 地理 | 苗疆（设定在云南，水源匮乏） | ✅ |
| 两族 | **黑苗族**（巫王 / 拜月所在，南诏国统治层）与**白苗族**（阿奴所在，据点大理） | ✅ |
| 冲突根源 | 两族长期为**争夺水源**开战 | ✅ [豆瓣](https://m.douban.com/movie/review/10564350/) |
| 和平机制 | 巫后林青儿曾用**五灵珠祭天求雨**，为两族带来 8 年和平；拜月打破之 | ✅ |
| 南诏国 | 巫王为南诏国王，巫后为王后 | ✅ |
| 大理城 | 白苗族据点；女娲神殿所在（祭坛施法救世处） | ✅ |
| 巫月神教 | 阿奴晚年（仙剑五）掌管的教派，位于封闭山谷 | ⚠️ |

> **💡 扩展契机**：黑白苗的水源冲突是仙剑一故事底层矛盾。扩展若做苗疆支线，这是现成的、官方背书的戏剧冲突来源。
