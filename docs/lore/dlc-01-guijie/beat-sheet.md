## 第一幕 · 铺垫链（盛渔村 → 鬼阴山）`[框架已定]`

> 主题：给"重新认识父母"立动机。李逍遥崇拜父母，但盛渔村的偏见让崇拜掺了怀疑——这是鬼界"拼图"的情感引擎。

### B1 盛渔村偏见前置任务 `[草案·核心已定，细节待打磨]`

> 🌟 **核心设计（作者提出）**：用游戏机制点题——李逍遥进村民家"拿东西"（仙剑系列最被吐槽的"偷"机制）→ 被老人当场抓获 → 玩家亲手验证"贼"的偏见。这是用交互讲主题（小说/电影做不到）。

**支线入口**：盛渔村地图上一间原本打不开的房间，开放出来做支线。插在买鱼主线（李逍遥第一次出客栈）时，作为**进入鬼界的必要前置**（执念铆钉②：情感点燃，非物理信物）。

**偏见者设定（2026-06-30 定）**：
- **身份**：原是某富户（李三思"劫富济贫"劫过的"为富不仁者"）家的**老仆/管事**，半生尽忠。主家破败后流落盛渔村，靠打杂/看守破屋度日。
- **恨的正当性**：他本人没做过恶，却因主家被劫、家族破败而失去半生依靠。恨李三思"不分善恶，把好人坏人的生计一起毁了"。
- **民间舆论**：他在盛渔村散布对李三思的负面看法（"什么侠盗，就是贼！"），部分村民信他（亲历者，说话实在）→ 李逍遥感受到的是**一整片舆论**，不是一个人骂。
- **"误会"层次**：他不知李三思劫财的原因（济贫/救人），也不知李三思后来送命。认知不全 → "误会"成立；但苦是真的，恨是真的。
- **阶层视角**："侠盗"二字对江湖是美谈，对被抢的富人/被连累的底层就是"贼"——这是李逍遥崇拜里的裂缝。

**B1 节拍拆分**：

| 拍 | 玩家做什么 | 玩家感受什么 | 信息变化 | 载体 |
|---|---|---|---|---|
| B1.1 | 买鱼途中，发现那间原本锁着的房间开了（或听到村民议论"那屋的老人今早出门了"） | 好奇 | 房间可进 | 探索 |
| B1.2 | 进屋，按仙剑习惯翻箱倒柜拿东西（外屋→偏房） | 习以为常（玩家不自知） | 拿到几件旧杂物 | 探索+拿取 |
| B1.3 | 走进**内屋/卧室** → 🎬 演出触发：老人回来，当场撞见李逍遥擅闯私室 | 突发尴尬/心虚 | 被抓现行 | 🎬 演出 |
| B1.4 | 老人一通痛骂："跟你爹一样，是个贼！" → 🎬 强制赶走，关门。**此后该房间永久关闭，再也进不去** | 灵魂暴击 + 悬置的憋屈——问题没被回答，门永久关上了 | 老人认识李三思；偏见爆发但**无解释** | 🎬 演出 + 对话 |
| B1.5 | （事后）李逍遥从**房子周围的 NPC** 处拼出老人身世：他曾在大户人家做工，主家被李三思"劫富济贫"整垮，他失去半生依靠流落至此 | 懊悔 + 更深的困惑——原来老人恨得有理 | 父亲"侠义"伤及无辜的另一面（侧面叙事，非老人亲述） | 对话（周围 NPC） |
| B1.6 | 李逍遥带着"我爹到底是不是贼"的未解之结离开盛渔村。执念点燃 | 释怀前的刺痛——寻父执念的**情感燃点**（=没被回答的问题） | 执念铆钉②达成（情感，非道具） | 独白/情绪 |

**收尾方式（2026-06-30 作者定）**：老人只骂不解释 → 强制赶走 → 关门 → 房间**永久关闭**。盛渔村成为"没有答案的地方"，李逍遥带着悬置的困惑离开——执念 = 没被回答的问题。比"在房间内和解/辩论"更强：不给他任何消解机会，把结钉死在心里。

**侧面叙事（2026-06-30 作者定）**：老人背景不靠 B1.4 那场骂戏讲（保持冲突干脆），而是由**房子周围的 NPC** 补充（"别怪他，他以前在大户人家做工，被李三思害的……"）。好处：① 不打断冲突节奏；② 制造信息差（玩家从第三方拼真相）；③ 落地"民间舆论"——整个盛渔村都知道这段旧事，偏见是环境性的，非孤立。呼应支线"拼图"主题。

**触发方式（2026-06-30 作者定）**：李逍遥走进**卧室**即触发演出被抓现行，**不绑定具体物品**。冲突挂在"擅闯私室+翻动"这个行为本身，不靠"偷了多重要的东西"加重——老人那句"是个贼"针对的是"闯进别人卧室"的行径。

**红线**：老人是恩怨关系，**非恋爱线**（李逍遥此刻已有灵儿）。

### B2 韩医仙提醒 `[已定·2026-06-30]`

> 功能：给鬼界入口一个可信的预警铺垫。挂在原版"村民解救"这个**既有节点**上，不改主线。

**触发节点（2026-06-30 作者定，贴合原版流程）**：
仙剑一第七章——鬼阴坛石长老必败战、灵儿自愿跟石长老回苗疆 → 李逍遥林月如战败倒地 → **韩医仙、韩梦慈带村民来解救** → 临别前，韩医仙叮嘱。

**B2 节拍**：

| 拍 | 玩家做什么 | 玩家感受什么 | 信息变化 | 载体 |
|---|---|---|---|---|
| B2.1 | 村民解救后，韩医仙临别叮嘱："鬼阴山阴气重，晚上别在此地逗留，速速下山。" | 隐隐的不安（但李逍遥此刻沉浸在灵儿被带走的低谷，没当回事） | "此地夜间不宜久留"的暗示埋下，**完全不提鬼界** | 对话（韩医仙） |

**分寸（作者定，2026-06-30 修订）**：韩医仙**只说朴素禁忌**（"晚上别逗留，速速下山"），**完全不提鬼界/传说/魂**。理由：① "鬼界"二字是剧透钩子，会让玩家秒懂 B3 的去向，消解反转意外感；② 韩医仙是乡村医者，不该知道六界设定，朴素禁忌才符合其身份与民间话术。钩子埋下但不挂标签——为 B3 夜间时辰触发入口留伏笔，玩家却不会提前猜到"去鬼界"。

**为什么这个时点好**：李逍遥刚经历"灵儿被抓、战败、无能为力"的低谷，处于最脆弱、最易被异象吸引的心境；玩家同在低谷，对"后山有什么"会更敏感——为 B3（三次背影）的追寻欲做了情绪铺垫。

### B3 三次背影 `[已定·2026-06-30]`

> 功能：铺垫链收尾，凡间→鬼界跨界点。把 B1 执念 + B2 暗示，汇聚成"李逍遥（玩家）自己踏进鬼界"的动作。
> 地点：鬼阴山后山——**鬼阴坛出来就是后山，且后山是去扬州必经之路**（原版结构，零改编）。

**B3 节拍拆分**：

| 拍 | 玩家做什么 | 玩家感受什么 | 信息变化 | 载体 |
|---|---|---|---|---|
| B3.1 | 后山途中（去扬州必经之路），听闻一声**若有若无的"逍遥……"**呼唤（穿过雾气/阴气，李逍遥拿不准是真是幻） | 心头一震——这声音…… | 模糊的钩子（不确定是父亲还是执念幻听） | 🎬 演出（声音 + 镜头向前推进，给一个**正在离开**的背影） |
| B3.2 | 镜头回到李逍遥，他说"那身形……难道是……" | 被点燃的追寻欲（B1 执念铆钉在此兑现） | 背影身形像父亲（李三思特征） | 🎬 演出 + 台词 |
| B3.3 | （三次递进的第 2 次）继续走，又见背影，追，背影消失，但消失处**似有一条本不存在的路/入口轮廓** | 困惑 + 执念加深 | 入口隐约可见（时辰未到，未开） | 探索 + 🎬 |
| B3.4 | （第 3 次，特定时辰=夜间，呼应 B2"晚上别逗留"）背影再次出现，这次**走进**入口 → 入口彻底开启 | 决绝前的最后拉扯 | 入口在夜间时辰开启（昼夜系统触发） | 🎬 演出 |
| B3.5 | 李逍遥正要跟上，**林月如拦一句**："李大哥，此地阴气太重，怕是有古怪……"（点到为止，原版称呼"李大哥"） | 风险感/犹豫的情绪顶点 | 月如点破"此地有异" | 🎬 演出 + 对话 |
| B3.6 | 🎬 **控制权交还玩家**。入口 tile 解锁可见。玩家自己决定：走过去踩 tile = 进鬼界 / 转身走主线去扬州（错过=永久错过，进入扬州不可逆） | 玩家用自己的步伐跨过门槛——投入感最强 | （无 UI 选项，回归游戏最自然的动作：走路） | 探索（踩 tile 切场景） |

**核心设计哲学（2026-06-30 作者定）**：
- **不用选择框/菜单**。月如劝完后直接交还控制权，"进不进"回归成"走不走进去"这个最自然的游戏动作。
- 整个 B3 的目的不是"把玩家推进鬼界"，而是"给玩家足够强的动机，让他**自己走过去**"。引导够了，剩下的交给玩家的脚。
- 比"弹菜单选进/不进"更沉浸（零 UI）；比"执念强制进"更尊重玩家（玩家物理上可转身离开）。
- **错过=玩家自己的选择**（自己转身），不是"手滑选错菜单"（锅在 UI）——责任从设计转移到玩家动机。

**反转伏笔（背影是仇人陷阱，日后识破）**：
- 背影**被动离开**（不刻意），但"逍遥……"呼唤是**主动诱饵**（保证李逍遥会追）。取了"不刻意"+"保证追"，化解了纯被动（巧合）和纯主动（招手刻意）各自的毛病。
- ⚠ **铁律伏笔**：真父亲叫了儿子会等他、会团聚，**不会飘走去鬼界**（父母不会害子女）。"叫了名字却飘走"本身就是日后回想能识破的破绽。
- ⚠ **boss 身份硬约束**：仇人能叫出"逍遥"名字 + 熟知李三思身形步态佩剑 → boss 必须**生前与李三思极其熟识**（不只是泛泛的苗疆受害者）。定 boss 时依此。
- 声音的暧昧性是关键：李逍遥**说不清**呼唤是真是幻，但正因说不清才**非追不可**（是真爹不能错过；是幻听也要看个究竟）。执念铆钉②在 B3 的延续。

**机制点**：鬼界入口 = 鬼阴山后山某 tile，B3.5 后解锁可见，玩家踩上 = 切场景进鬼界。引擎实现细节。

## 第二幕 · 鬼界主体 `[骨架已定·2026-06-30，3路节拍待逐条填]`

> 主题：拼图。中心辐射结构，3条路 = 李三思的3个侧面，渐进解锁。
> 核心游戏循环：走路拿碎片 → 土灵珠回据点 → 玉佩（小鬼）引导 → 走下条路。

### 空间结构（中型，2026-06-30 作者定）
- **中心**：一个鬼界小据点（类似城镇），土灵珠可回到此处。
- **3条辐射路**：渐进解锁（走完一条，玉佩引导解锁下一条）——仙剑一线性叙事为舒适区，渐进解锁收束推荐路径，既给探索感又不迷路乱序。
- **迷宫密度**：**至多2条路放迷宫**，至少1条是叙事路（对话为主）——张弛有度，避仙剑"迷宫过密致疲劳"的坑。

### 3条路分工（2026-06-30 作者重构，比原"善/代价/情"更清晰）

> 关键洞察（作者）：**boss 不是某条路的尽头，boss 是幕后**。路B是 boss 设的陷阱，路C 是李逍遥反杀 boss。形成"陷阱→中计脱困→反击"三段式。

| 段落 | 功能 | 内容 | 迷宫？ | 承担要素 |
|---|---|---|---|---|
| **据点** | 拼图 + 伏笔 | 李逍遥以特征打听父母下落，**拼出父母往事碎片**；**女飞贼伏笔**（据点闲聊，轻，不点名） | 否 | 父母事迹（多块碎片）；女飞贼伏笔链 |
| **路 A · 恩人路** | 善（侠义的救人面） | 进鬼界入口到据点的主路；飞龙探云手救小鬼 | **小迷宫（一张图，有分叉/宝箱/关押处/巢穴）** | 小鬼来源；正面证据（已完整，见下） |
| **路 B · 陷阱路** | 中计 + 小鬼牺牲 | boss 引导李逍遥涉险 → **大型迷宫** → 强力怪 → 打不过/被困 → **小鬼牺牲（玉佩碎）脱困** → 强力怪供出幕后 | **大型迷宫（2+张地图体量，全支线唯一大迷宫）** | 陷阱；小鬼牺牲；戏眼（反转） |
| **路 C · 反击路** | 直面 boss | 强力怪供出幕后 → 去**直面真 boss** → boss 战（恨意反成证据）→ 月如伏笔 | **无/极简，紧凑**（B 已是大迷宫，C 要收束情绪不拖） | boss战；父母代价的真相；月如伏笔 |

**迷宫分配（2026-06-30 修正）**：全支线**两个迷宫——路A一张图（小迷宫）+ 路B两张图+（大迷宫）**，路C不迷宫（紧凑反击）。
- 路A：一张图体量的**小迷宫**——有分叉、宝箱（第1件道具探索点）、关押小鬼处、大鬼巢穴，路线非一本道。但比路B紧凑。（注：早先表述"路A非迷宫"系失误，路A实为小型迷宫。）
- 路B：两张图+体量的**大迷宫**——深陷感，"越走越深找不到出口"模拟"被引诱深入险境"，迷宫本身在叙事。
- 路C：紧凑反击，无迷宫。
- 符合"至多2条路放迷宫"的约束（路A路B各占一名额，路C省）。

**戏眼（反转）位置（2026-06-30 重构）**：从原"3条路走完"提前到**路B脱困、强力怪供出幕后时**——李逍遥此刻才知道"我一直追的背影是 boss 设的局"。比"走完3条才反转"更早更狠，带着被骗的愤怒去路C打boss，情绪连贯。

走完据点+ABC = 拼出立体的李三思 → 兑现"拼图非揭秘"。

### 🌟 小鬼载体：玉佩（2026-06-30 作者定，神来之笔）

> 用仙剑自己的语言（小石头=佛珠灵、玉佛珠=法器、傀儡虫=蛊器）——小鬼灵力凝结成**玉佩**，是道具不是队友，不碰队伍系统。

**玉佩一箭五雕**：
1. **跟随机制**：玉佩形态，不破坏仙剑队伍机制（无"第五个队友"）。
2. **遮蔽气息**：玉佩**本身就是遮蔽活人气息的法器**——小鬼灵力包裹李逍遥月如。机制与叙事合一。
3. **具象化**：关键剧情时从玉佩显化为幽灵（同构"小石头从佛珠现身"，玩家秒懂）。
4. **3路在场**：玉佩挂身=小鬼一直在（通过玉佩说话/提示），无需画随从精灵。
5. **渐进引导**：回据点后玉佩发光/传音，指引解锁下条路。

**玉佩来源（路 A 核心事件）**：路A遇小鬼（李三思生前救过的人的亡魂）→ 认出飞龙探云手/李逍遥 → 报恩 → 灵力/本愿凝结成玉佩交李逍遥。此后玉佩常驻。

### ⚠ 牺牲→boss 战闭环（2026-06-30，待作者确认）

> 小鬼最终**牺牲**触发 boss 战。玉佩形态下，"牺牲"= **玉佩碎裂/灵力耗尽**。

**因果闭环**：小鬼为护李逍遥，玉佩**过载碎裂** → **活人气息遮蔽失效** → boss 锁定李逍遥 → boss 战触发。
- 叙事与机制又一次合一：小鬼牺牲 = 玉佩碎 = 遮蔽失效 = boss 来了。
- 比小鬼"挡刀"更符合仙剑器物灵的悲壮感（器物为护主而碎）。
- ⚠ **待确认**：此闭环是否采用？采用则 boss 战触发从"小鬼挡刀动作戏"改为"玉佩过载碎裂"。

### 路 A · 恩人路 `[已定·2026-06-30]`

> = 进鬼界入口 → 到据点的主路（不是"从据点辐射的路"）。路A是**进来**的路，路B/C才是从据点**出去探索**的路。
> 核心：展示飞龙探云手（偷）→ 小鬼认出恩人之子 → 化玉佩。

### 🌟 月如伏笔 · 最终版（2026-06-30 作者定，红线安全）

> **核心**：玉佩（小鬼残魂）= 原版月如"突兀复活"的可选前因。走支线的玩家获得"懂了"的奖赏；没走的玩家原版体验零损失。

**因果链（补充性叙事，非改写）**：
- 原版（主线，神圣不可改）：锁妖塔月如被砸天灵盖 → 重伤濒死 → 圣姑傀儡虫续命（突兀，无解释）。
- 本支线（走了的玩家）：锁妖塔月如被砸天灵盖 → **天灵盖碎裂瞬间本该魂飞魄散（2魂4魄散失）** → **但鬼界支线获得的玉佩（小鬼残魂）及时容纳了月如残魂，没让她魂散** → 圣姑才有"可救的对象"（否则魂魄早散，傀儡虫无用）→ 傀儡虫续命。
- **两条线互不矛盾**：没走支线，原版月如照样被傀儡虫续命（大宇既定）；走了支线，原来她能活是因为玉佩容魂——突兀的复活突然有了前因。

**小鬼 = 小女孩（2026-06-30 作者定）**：
- 小鬼是个小女孩——李三思生前救过的孩子。死后感念救命之恩，化作玉佩报恩。
- 善的传递链：李三思救小女孩 → 小女孩（鬼）救李逍遥 → 小女孩残魂护月如。仙剑"侠义传承"的具象化。
- 与女飞贼伏笔不混淆：女飞贼=成年女性倾慕李三思；小鬼=小女孩感念救命恩。年龄/性质均不同。

**小鬼人格融入月如（分寸红线，2026-06-30 据三魂七魄设定钉死）**：

> 据道教/古剑奇谭的三魂七魄设定（[维基](https://zh.wikipedia.org/zh-cn/%E4%B8%89%E9%AD%82%E4%B8%83%E9%AD%84)、[古剑奇谭维基](https://gjqt.huijiwiki.com/wiki/三魂七魄)）：
> - **爽灵（觉魂）= 意识人格的核心**（"我是谁"、理性认知）。一个人是不是"她自己"，看爽灵。
> - **幽精（人魂）= 情志本能**（七情六欲）。
> - **七魄 = 生理机能/生存本能**。

- ✅ **小鬼残魂补的是幽精 + 3魄（情志本能/生理本能位），绝不补爽灵** → 月如的"意识人格/我是谁"始终是月如本人，小鬼无法主导。
- ✅ 所以小鬼对月如的影响，**只限于本能/情志的底色**（如多了点护李逍遥的直觉、对鬼界莫名亲近），**绝不是"小鬼取代月如在思考"**。
- ✅ 月如永远是月如，主线归宿（复活→仙灵岛→早逝，T5.5）纹丝不动。
- ✅ 鬼阴山时点绝不点破（时间线纪律），月如自己不知，老玩家日后会心。
- 设定支撑：古剑奇谭已采用三魂七魄体系（天魂胎光/地魂爽灵/命魂幽精 + 七魄），本支线沿用，与仙剑世界观不冲突（仙剑鬼界轮回说同源）。
