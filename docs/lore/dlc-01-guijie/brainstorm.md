## 铺垫链（2026-06-29 讨论，作者提出）

> 关键洞察:作者自发加了"盛渔村偏见前置任务" —— 这给整条支线安了**主题动机锚点**。李逍遥为什么需要"重新认识父母"?因为他从小被父母盗贼身份的流言影响,崇拜里掺着怀疑。这是专业叙事设计才会主动做的事。

### 1. 盛渔村前置铺垫（新增）
- **背景动机**:李逍遥父母李三思夫妇是盗贼(南盗侠),江湖名声复杂 → 盛渔村人**对李逍遥有所偏见**。
- **李逍遥内心**:虽然崇拜父母,但**难免被流言影响** —— 这是支线的**情感起点**(崇拜里有裂痕)。
- **前置分支任务**:在盛渔村做一个**前置支线**,让玩家感受到这种偏见 + 李逍遥的纠结。
  - 作用:给"重新认识父母"这个主题**立动机** —— 没有这个,鬼界的"拼图"就没有张力(拼出的真相为什么要紧?)。
  - 位置:仙剑一开篇盛渔村(第一章 1.1 附近)。

### 2. 鬼阴山·韩医仙提醒（新增铺垫）
- 白河村韩医仙在鬼阴山与李逍遥一行**分开前**,提醒主角"小心"。
- 作用:给鬼界入口一个**可信的预警**,不是凭空冒出来。
- 位置:第七章鬼阴山段(7.x)。

### 3. 鬼界入口触发（待结合昼夜系统）
- **三次背影**:后山可看到疑似父亲的背影飘过,第三次看到他**进入入口** → 引导玩家进入支线地图。
- **时辰触发**:若新引擎做昼夜系统(roadmap 议题 2),这里**指定某刻时辰**才能触发 → 入口的"临时性"用机制落地。
- 位置:鬼阴山后山(第七章后)。

## 戏胆（2026-06-29 作者拍板方向，2026-06-30 增补小角色）

> ~~旧提案"父母执念徘徊、一直等儿子来"~~ **已否决**（作者 2026-06-29 否决）。否决理由：与父母之爱本性矛盾——父母不可能"盼着子女死后团聚"。该方向有情感逻辑漏洞。

### 核心戏胆：误入鬼界 + 背影陷阱 + 父母已入轮回

**关键设定（作者提出）**：
1. **李逍遥是误入鬼界**，不是被父母引来——父母不可能盼子女死。
2. **引导李逍遥的"父亲背影"是仇人假扮的陷阱**。原设想"三次背影"的第三次引导入入口，现反转：那是仇人设的局。
3. **李三思夫妇早已入轮回**，鬼界里只剩**故事/事迹流传**，不是他们的灵魂。
4. **仇人**（李三思的仇敌，死后成鬼界恶鬼）一直引导李逍遥，目的是设计干掉他（报复其子）。

### 为什么这个方向更好（手艺复盘）
- **修复父母之爱逻辑漏洞**：父母因爱子而**不留恋、早入轮回**，更悲更真。
- **有真正的反转（戏眼）**：寻亲故事 → 中途发现是猎杀陷阱。认知翻转 = 高潮。
- **更纯地兑现"拼图非揭秘"**：父母真正不在了，只剩故事流传——最纯的拼图（拼一个不在的人的肖像）。
- **恨意反成证据（戏剧反讽）**：仇人为设局不得不谈论李三思夫妇，越恨越贬低，反越坐实其侠义。

### 小角色（恩人向导）—— 2026-06-30 作者提出，结构性补全

> 补上了整个支线的两个结构性缺口：① 鬼界向导 + 正面信息源；② boss 战的情感导火索。

**角色功能**：
- **识别方式（2026-06-30 作者修订，从"认铁剑"升级）**：李逍遥为进入某处，施展**飞龙探云手**偷了某鬼差的钥匙 → 碰巧被小鬼**目击** → 认出这是李三思的家传绝技 → 判定李逍遥可能是恩人之后。**比铁剑更准**（飞龙探云手是李家独门，铁剑是死物），且把识别从"陈述"变成"场景"（show don't tell）。铁剑可作之后的二次确认。
- **察觉活人气息**：小鬼察觉到李逍遥、林月如的**活人气息** → 帮他们**隐藏气息**，方便在鬼界行动。（潜在游戏机制：气息有持续时间/会泄露/被强鬼识破——做节拍表/关卡时展开。）
- **身份来源**：李三思**生前**救过/帮过的人，比李三思先死，在鬼界等轮回。**不需要李三思灵魂在场**（符合"父母已入轮回"）。
- **作用**：① 向导，引导李逍遥在鬼界行动；② 正面信息源，讲父母真实事迹（与仇人的恨形成对照）；③ **牺牲自己**，促成/触发李逍遥与 boss 的战斗。

**双重证据结构（复调叙事）**：

| | 仇人 | 小角色（恩人） |
|---|---|---|
| 对李三思的感情 | 恨 | 恩 |
| 对李逍遥的行动 | 设陷阱害他 | 引导帮他 |
| 泄露的父母事迹 | 恨意中漏出侠义（反证） | 感恩中讲出侠义（正证） |

两股相反力量独立证明同一件事：李三思夫妇是好人。小角色的死本身是最强证据——愿为已死恩人之子而死，证明恩人生前之事分量重到足以拿"余命"去还。

### 🌟 月如复活伏笔（2026-06-30 作者提出，神来之笔）

> **修原版最大叙事漏洞**：月如复活长期被诟病为"机械降神"（锁妖塔重伤→傀儡虫→仙剑二回魂珠，缺因果）。本支线在**锁妖塔（月如重伤）之前**埋下她能被复活的因果 → 让突兀设定变成"原来如此"。

**伏笔设计**：
- boss 是"水灵珠受害者"，死于苗疆灵力灾变/诅咒 → boss 死后，**残余灵力/怨念凝结体**（与"生→死"边界有关）散落。
- **月如无意间接触/吸收了它** → 获得一种"**魂魄不易离散**"的性质（不是复活，不是续命，只是死后魂魄多停留/多完整一点）。

**为什么这么设计（因果链自洽）**：
- 傀儡虫能起作用，前提是月如还有可操纵的魂/肉身；若魂魄早散，傀儡虫也没用。
- 这个"魂魄不易离散"正是**傀儡虫能起作用的必要条件** → 给"傀儡虫为何对月如有效"补了官方设定一直缺的因果。
- **不剧透**：鬼阴山时点无人提傀儡虫/复活，月如只是"身体里多了点什么，说不清"，完全不影响当下剧情。
- **焊接支线与主线**：月如复活链 = 鬼界奇遇（本支线）+ 傀儡虫（圣姑）+ 回魂珠（仙剑二）。本支线为整条链补了前置因果。

**老玩家体验**：鬼界支线时月如活蹦乱跳、捡东西时不知意义 → 锁妖塔重伤、圣姑用傀儡虫 → 老玩家回想鬼界突然懂："难怪她魂能保住。" 伏笔最高境界：**未来的自己懂了**。

### 🚨 月如复活伏笔的红线（必须拿死）

> 月如归宿是红线 T5.5：傀儡虫续命（活尸态）→ 回魂珠复活 → 仙剑二仙灵岛数年 → **仙剑五早逝**。**最终必死，不得推翻。**

- ✅ 本伏笔只解释"傀儡虫**为何有效**"，**不改变"她最终会死"的结局**。
- 🚫 **严禁**写成"月如从此不死/长生/改命"。
- 分寸：月如吸收的东西是"**延缓离散**"的，不是"永生"的。它让傀儡虫有下手余地，但不能违背"最终早逝"。
```
起：误入鬼界(好奇) + 跟"父亲背影"(期待) + 遇小角色被认出(意外的暖)
承：小角色引导+讲父母真实事迹(崇敬积累，正面证据)
   + 追"背影"总追不上(困惑) + 从其他鬼听碎片(拼图充实)
转/戏眼：发现背影是假的!是仇人陷阱!(震惊/背叛感)
高潮触发：小角色为护李逍遥 / 为揭露陷阱而牺牲(血淋淋的情感导火索)
boss战：仇人愤怒中口不择言，暴露更多父母事迹(恨意反成证据)
合：父母已入轮回(真正的不在)，但事迹/爱是真的
   → 释怀(崇拜有依据) + 带着完整真相离开，不是为复仇而战
```

### ⚠ 反转必须钉好的两点（手艺）
1. **得有伏笔**：事后回想"背影有破绽"——剑不是铁剑 / 背影过处鬼畏惧而非敬重。意料之外、情理之中。
2. **反转只否定"引路人是假的"，不否定"情感是真的"**：背影假，但故事真、爱真。拼图是真的，只有诱饵是假的——守住这条，前面积累才不白费。

### ⚠ 小角色牺牲→boss 战的分寸（必须钉死）
- **风险**：牺牲→boss 战容易变成"为兄弟报仇"的动作片套路，劫持"释怀/认识父母"的主题。
- **分寸**：boss 战的意义不是复仇，是**揭露真相**——仇人战中愤怒口不择言，暴露更多父母事迹（恨意反成证据）。
- 小角色的死 = **触发战斗**（情感导火索）；战斗的**收获** = **拼到更多真相**（主题推进）；战斗**结局** = 李逍遥带着完整真相释怀离开，**不是杀仇人出气**。
- 守住：小角色的死有意义（救了李逍遥），但支线落点仍在"释怀/认识父母"上。

## 悬而未决

### ❓ 入口位置：**已定（2026-06-30）** —— 鬼阴山后山临时裂隙。
- 定论：鬼界入口**不唯一**。酆都是"正路/官道"（制度化、长期开放），鬼阴山后山是"临时裂隙/野路"（偶发、时辰一过即关）。官方从未设定唯一入口，酆都只是"出现过的入口"。
- 设定因果：鬼阴山本阴气汇聚，特定时辰与鬼界偶发共鸣开临时裂隙。名字自洽 + 给昼夜系统真实叙事功能。
- 好处：完全规避"李逍遥仙剑一怎么到酆都"；与仙剑二王小虎走酆都正路是两条独立线，零冲突。
- 详见 [world-rules-ghost-realm.md §二](../world-rules-ghost-realm.md)。

### ❓ 戏胆核心：**已定**（误入 + 背影陷阱 + 父母已入轮回 + 小角色牺牲，见上）。

### ❓ 仇人身份（2026-06-30 据《水灵劫》正典锁定方向；识别依据 2026-06-30 修正）

- ⚠ **原设想"仇人=四大恶人之一"已否决**：经官方百科查证（[百度百科·四大恶人](https://baike.baidu.com/item/%E5%9B%9B%E5%A4%A7%E6%81%B6%E4%BA%BA/3951871)），李三思**本人即四大恶人之一**（南盗侠），另三人是其**同伙**而非仇敌。同伙害其子逻辑不成立。
- 红线 T4：仇人**不能是拜月**（拜月翻案是硬红线）。但《水灵劫》确认——害死李三思的直接元凶是**拜月下无影毒**（详见 [characters.md 李三思条目](../characters.md)）。
- ✅ **《水灵劫》正典给了 boss 恨意的根源**（2026-06-30 查证）：李三思受**巫后托付**带走水灵珠（非主动盗珠）→ 此行为**客观上间接导致巫后牺牲、苗疆遭灾**（拜月无法用珠→操控水魔兽发洪水诬陷巫后→巫后与水魔兽同归于尽→苗疆大旱）。
- **推荐方向：候选②（水灵珠受害者，原创鬼）** —— 因苗疆遭灾家破人亡的无辜者，死后在鬼界恨"李三思"，设局害其子。**这个恨是正当的**（他真的受害了），让 boss 不是纯反派，增加道德灰度。
- **主题升华**：李逍遥走进鬼界崇拜父母，走出来知道——父母侠义（受巫后信任、救皇甫英），但侠义**有代价**（间接害了无辜者）。这是"复杂的释怀"，比"单纯释怀"高级。契合 dlc-ideas.md 的"求而不得但释怀"。

### 🚨 识别依据修正（2026-06-30，作者纠正剧透主线错误）
