# 版本差异登记（versions）

> 仙剑在不同版本（DOS / 98柔情 / 新仙剑 / 电视剧 / Steam重制 等）存在设定分歧。**本项目的扩展剧情以哪个版本为正典，必须先定**——否则不同剧情会互相打架。
>
> **决定权在作者**。本文件只登记分歧 + 列选项 + 给建议，不擅自合并。

## 为什么这是个大问题

仙剑一最大的版本差异点 = **林月如的结局**。这直接决定了：
- 你的"结局后"扩展剧情里，月如是活着、傀儡虫续命、还是死了？
- 你能不能写"月如与逍遥在一起"的后传？
- 你做仙剑二衔接时（月如在仙剑二被救活），要不要和新仙剑隐藏结局对接？

**不定这个，所有涉及月如的扩展都悬着。**

## 分歧登记

### 分歧 1：林月如结局（2026-06-25 部分坐实 + 修订）

**✅ 已坐实部分（跨仙剑一/二/五，主干不再悬置）**：
锁妖塔重伤 → 傀儡虫续命（活尸态）→ **尸身保存在圣姑处（白河村附近），李逍遥每月采灵药续命** → 傀儡虫失效昏睡 → 九转回魂珠复活 → 仙灵岛数年 → **早逝**（仙剑五）。
> 作者记忆 + 搜索结果一致。这条链是硬约束（见 [taboos.md T5.5](taboos.md)）。

**❓ 仍待定的两点**：

| 待定点 | 说法 A | 说法 B | 来源 |
|---|---|---|---|
| **回魂珠谁用** | **李逍遥**（豆瓣、[维基·李逍遥](https://zh.wikipedia.org/zh-cn/%E6%9D%8E%E9%80%8D%E9%81%A5)） | **李忆如**（[维基·林月如](https://zh.wikipedia.org/zh-cn/%E6%9E%97%E6%9C%88%E5%A6%82)） | 来源冲突 |
| **仙剑一结局画面取哪个版本为"正典呈现"** | DOS/98（傀儡虫续命、树下等候的悲剧意象） | 新仙剑隐藏结局（36 傀儡虫真复活） | 玩家自选 |

#### 选项分析（仅针对"仙剑一结局画面"这第二点）

| 选项 | 含义 | 对扩展的影响 |
|---|---|---|
| **A. DOS/98 为正典** | 仙剑一结局是"傀儡虫续命、非真复活" | "结局后"扩展里月如是濒死/傀儡态；戏剧悬念强（"她能否被救活"恰是后传题材） |
| **B. 新仙剑隐藏结局为正典** | 仙剑一结局即真复活 | "结局后"扩展可写月如正常活着；与仙剑二自然衔接 |

**💡 建议（仅供参考，作者定）**：
- 你做**基于仙剑一原版的扩展**，第一阶段忠实复刻 DOS/98。**A 最自洽**——悲剧意象与仙剑一整体美学一致，且月如"濒死待救"状态正好给后传 DLC 提供戏剧动力。
- B 削弱悲剧内核，但若你计划做仙剑二衔接会省事。

> **❓ 待作者拍板**：
> 1. 回魂珠谁用？（你通关仙剑二的印象？）
> 2. 仙剑一结局画面正典 = A / B？

### 分歧 4：电视剧 vs 游戏设定

> 仙剑电视剧（2005，胡歌 / 刘亦菲 / 安以轩）与游戏设定有大量差异，粉丝圈容易混。

- 电视剧加入大量原创剧情、人物关系改动。
- **本项目扩展以游戏为准，不采用电视剧设定**（除非作者有意致敬）。
