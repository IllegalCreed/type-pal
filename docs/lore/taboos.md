# 扩展红线清单（taboos）

> 这些是扩展剧情**绝对不能碰**的设定——动了就等于吃书官方正传 / 外传，或让角色 OOC（崩坏）。
> 每条创作决策都必须过一遍这个清单。
> 最后更新：2026-06-25

## 🔴 硬红线（动了直接吃书，不可商量）

### T1 · 女娲族死亡宿命不可逆
- **紫萱 → 林青儿（巫后）→ 赵灵儿 → 李忆如 → 小蛮**，代代以身殉道。
- 赵灵儿、林青儿在仙剑一中已明确牺牲。
- **不能"复活"灵儿 / 巫后来圆结局**。哪怕用傀儡虫 / 回魂珠，也只能是"躯壳续命"层面的处理（参考月如的傀儡虫），不能否定其牺牲的宿命闭环。
- 依据：✅ [百度百科·女娲族](https://baike.baidu.com/item/%E5%A5%B3%E5%A8%B2%E5%90%8E%E4%BA%BA/9097458)

### T2 · 李逍遥的官方后续不可推翻
- 仙剑二：成为蜀山**第 27 代掌门**、与月如正式在一起、女儿李忆如。
- 仙剑五：卸任掌门成为**蜀山七圣**，晚年如酒剑仙。
- **扩展若时间线在仙剑一结局之后，必须衔接这条轨迹**，不能让他"不当掌门"或"和别的人在一起"。
- 依据：✅ [维基·李逍遥](https://zh.wikipedia.org/zh-cn/%E6%9D%8E%E9%80%8D%E9%81%A5)

### T3 · 阿奴的归宿不可改
- 终身未嫁，暗恋逍遥（"安静的爱"）。
- 后续成长为白苗族长 → 巫月神教掌门（海棠夫人）。
- **不能给她安排官方归宿之外的姻缘**（这是其人物色彩核心）。
- 依据：✅ [萌娘百科·阿奴](https://zh.moegirl.org.cn/%E9%98%BF%E5%A5%B4)

### T4 · 拜月 / 水魔兽终局不可翻案
- 仙剑一终局：灵儿封印拜月 / 水魔兽，同归于尽。
- **不能写"拜月未真正死透"卷土重来**——这是同人创作最常见的雷区之一。
- 若要延续反派，**必须是新反派**，不能是拜月复活 / 残魂 / 分身之类。
- 依据：✅ [知乎·仙剑1结局](https://www.zhihu.com/question/560100162)

### T5 · 蜀山掌门代数不可乱编
- 仙剑三：徐长卿为**第 23 代**。
- 仙剑二：李逍遥为**第 27 代**。
- 中间 24-26 代是官方留白，但**扩展不得编造与后续冲突的代数**。若写前传涉及蜀山掌门，须落在 24-26 之间或更早，且不与徐长卿 / 李逍遥冲突。
- 依据：✅ 维基

### T5.5 · 林月如归宿链不可推翻（2026-06-25 深挖坐实）
- 锁妖塔重伤 → 傀儡虫续命（活尸态）→ **尸身保存在圣姑处（白河村附近），李逍遥每月采灵药续命** → 傀儡虫失效昏睡 → 九转回魂珠复活 → 仙灵岛生活数年 → **早逝**（仙剑五已交代）。
- **这条链跨仙剑一/二/五已坐实，扩展必须遵循，不得改**：
  - 不能让月如"长生 / 从此幸福"——她最终必早逝。
  - 复活前的"圣姑处 / 特定空间续命"限制是官方设定（作者记忆 + 搜索一致）。
  - 唯一悬而未决：回魂珠**谁用**（李逍遥 vs 忆如，来源冲突，见 [versions.md](versions.md)）。
- 依据：✅ [知乎·月如状态](https://www.zhihu.com/question/378073259)、[维基·林月如](https://zh.wikipedia.org/zh-cn/%E6%9E%97%E6%9C%88%E5%A6%82)

### T6 · 忆如-韩仲晰-小蛮 悲剧链不可断（2026-06-25 深挖坐实）
这是把仙剑一→仙剑五串起来的核心暗线，**任何一个环节都不能动**：
- **白河村韩医仙之子阿宝（韩仲晰）** → 必须被魔族植入"伐天"灵体 → 必须由李逍遥救、阿奴抚养。
- 韩仲晰**必须**与忆如在试炼窟重逢、相恋、私奔成婚（漫画《忆相逢》）。
- **必须**生下小蛮（仙剑五主角存在的前置）。
- 韩仲晰**必须死**（伐天觉醒；一说被李逍遥所杀）。
- 忆如**必须守寡、早逝**（女娲族宿命在她身上延续）。
- 小蛮**必须**由阿奴（海棠夫人）抚养长大 → 仙剑五主角。
- 依据：✅ [百度百科·韩仲晰](https://baike.baidu.com/item/%E9%9F%A9%E4%BB%B2%E6%99%B0/5504495)、[维基·系列角色列表](https://zh.wikipedia.org/wiki/%E4%BB%99%E5%89%91%E5%A5%87%E4%BE%A0%E4%BC%A0%E7%B3%BB%E5%88%97%E8%A7%92%E8%89%B2%E5%88%97%E8%A1%A8)

**💡 唯一可创作的口子**：在**仙剑一白河村**扩展里，可埋"煎药小男孩（阿宝）"的命运伏笔——伏笔 ≠ 改结局，不碰红线。这是把原版扩展和系列背景缝合的官方预留接口。

## 🟡 软红线（依赖版本正典选择，见 [versions.md](versions.md)）

### T7 · 林月如结局版本正典（部分已坐实，剩余待定）
- 月如**归宿链主干已坐实**（见 T5.5），不再是悬置的。
- 剩余待定：①回魂珠谁用（逍遥 vs 忆如）；②仙剑一结局画面取哪个版本（DOS 悲剧意象 / 新仙剑真复活）作为"正典呈现"。
- 一旦作者在 [versions.md](versions.md) 拍板，扩展必须遵循。

### T8 · 灵儿"生育即死"设定
- 粉丝圈流传"女娲族生育后灵力衰竭而死"，但**是否官方明文待查**。
- 扩展若要解释灵儿之死的因果，**先查证官方表述**，不要直接采用粉丝解读当真值。

### T9 · 电视剧设定
- 电视剧（2005）有大量原创剧情与人物改动。
- **默认排除电视剧设定，以游戏为准**（待作者确认）。

## 🟢 创作安全区（官方留白多，扩展空间大）

> 这些是**适合放扩展剧情**的地方——官方没细说或只给了片段，创作者填充不易碰红线。

| 安全区 | 说明 | 适合的 DLC 类型 |
|---|---|---|
| **李三思夫妇的死因 / 生平** | 原版只交代"父母早亡"，仙剑三补了"师从景天"，但死因仍模糊。**作者提过的"独立入口 DLC"天然题材** | 第二种 DLC（独立入口） |
| **林天南的家事 / 南武林往事** | 南武林盟主、丧妻、独宠月如，留白多 | 第二种 DLC（独立入口） |
| **巫后林青儿年轻时** | 仙剑一是她 27 岁化身石像，之前 19 岁嫁巫王、生平有空间 | 第二种 DLC（前传向） |
| **仙剑一各城镇的 NPC 支线** | 原版 NPC 多为一两句台词，深化空间大 | 第一种 DLC（内嵌支线） |
| **结局后 → 仙剑二前的 ~8 年** | 逍遥带忆如、走向蜀山的间隙（月如状态依赖 T6） | 后传支线 |

## 创作前的自检清单

写任何一段扩展剧情前，过一遍：

- [ ] 有没有"复活"已死的女娲族后人？（违 T1）
- [ ] 有没有改动李逍遥后续的官方归宿？（违 T2）
- [ ] 有没有给阿奴安排新姻缘？（违 T3）
- [ ] 反派是不是拜月 / 水魔兽的翻案？（违 T4）
- [ ] 有没有乱编蜀山掌门代数？（违 T5）
- [ ] 月如的生死状态是否和已定正典一致？（违 T6）
- [ ] 灵儿之死的解释是否依赖了未证实的粉丝设定？（违 T7）
- [ ] 有没有混入电视剧设定？（违 T8）

每条都过了，再往下写。
