## 女娲族核心宿命设定（时间线影响）

- **女娲族后裔肩负守护苍生的宿命**，代代以身殉道。✅
- **"一旦繁衍后代便会灵力衰竭而死"**——母亲生育后必亡。⚠️ 网易/粉丝向设定解读

## 忆如-韩仲晰暗线（跨作品关键，2026-06-25 深挖）

> 这条线把**仙剑一白河村**一直串到**仙剑五小蛮**。是"结局后扩展"最重要的硬约束，也是把原版扩展和系列大背景缝合的接口。

| 时间点 | 事件 | 可靠性 |
|---|---|---|
| 仙剑一·白河村 | 韩医仙之子**阿宝（韩仲晰）**登场（煎药小男孩） | ✅ |
| 仙剑一期间/后 | 白河村被魔族所毁 → 阿宝被**李逍遥**救下 → 被植入魔尊之子**"伐天"**灵体 → 送**阿奴**抚养 | ✅ |
| 仙剑二（忆如 8 岁） | 忆如先由韩医仙抚养 → 后被李大娘接回仙灵岛；月如被回魂珠复活 | ✅ |
| 仙剑二结束 3 年后（忆如 ~11） | 忆如去苗疆祭母 + **试炼窟为月如找傀儡虫** → 与韩仲晰重逢 | ✅ |
| 仙剑 OL（忆如 16 岁） | 忆如与韩仲晰相恋的主线 | ✅ |
| 漫画《忆相逢》（忆如至 20 岁） | 两人私奔、成婚、生**小蛮** | ✅ |
| 之后 | 伐天觉醒 → **韩仲晰死**（一说被李逍遥所杀）→ 忆如守寡 → **忆如早逝** | ⚠️ |
| 仙剑五 | 小蛮（忆如遗孤）由阿奴（海棠夫人）抚养，成主角 | ✅ |

**对扩展的意义**：
- 这条线是**官方既定的悲剧链**，扩展不得改其关键节点（阿宝必成魔宿、必娶忆如、必死；忆如必生小蛮、必早逝）。
- 但**仙剑一白河村**是它的源头——你在仙剑一扩展里深化白河村时，可埋"煎药小男孩"的命运伏笔，这是把原版扩展和系列背景缝合的**绝佳接口**，且不碰红线（伏笔≠改结局）。
