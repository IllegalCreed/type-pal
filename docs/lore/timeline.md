# 仙剑剧情时间线与流程攻略

> 仙剑系列历代作品的时间线关系。扩展剧情必须安插在正确的时间点，不与前后作品冲突。
> 可靠性：✅ 官方/多源一致 ＞ ⚠️ 单源 ＞ ❓ 存疑
> 系列概览整理于2026-06-25；本项目流程最近核对：2026-10-02。
> 下方滚动攻略的001–005已有两阶段实跑依据；005正常路线与复读/存读专项分开核验。
> 后期章节及跨作品设定保留旧稿和原来源标记，不代表已经过本项目逐段一手核验。

## 使用这份剧情记录

讨论“刚送完酒”“回厨房”“去码头”“婶婶病了”这类剧情简称时，先查下方滚动攻略，
明确说的是哪一次对话、为什么要去下一处、谁改变了剧情条件，再查对应脚本。不能仅靠系列印象补全顺序。

本文负责故事细节、自然游玩路线、人物称呼和易混点；[碎片目录](../../projects/pal/e2e-checkpoints/README.md)
负责E2E起止边界与合法前驱，[执行回执](../testing/e2e/contract.md)负责实跑结果。它们共用001、002等分段编号，
本页章节号不是测试编号。新增剧情知识优先补这里，不再另建一套互相矛盾的攻略。

事实分开记录：作者确认的是本项目采用的剧情范围；原版提取脚本证明对白和原有触发；
当前作者工程证明二阶段现有编排；实际E2E才证明对应引擎真的走通。下面“已实跑”引用既有回执，
不是本次又重跑一次，也不是完整录像或全游戏验收。

## 盛渔村开场滚动攻略

这一段的因果是：逍遥被叫醒帮忙接待客人，端菜时留下客人退回的桂花酒，拿酒换来醉道士的学剑邀约；
随后受婶婶委托出门买虾，在码头听到仙灵岛传闻，回村才得知婶婶病倒。买虾因此被新的救人目标打断，
不是先得知病情再出门买菜。

### 001 梦醒与房内密道

从标题选择“新的故事”，先完整播放新游戏视频，再由梦境切入逍遥的卧房。李大娘叫醒逍遥，
两人拌嘴，随后催他帮忙招呼客人。大娘离开后，逍遥念叨、挪开床边遮挡物并演示密道，最后恢复操作。
所以001的结束不是“视频播完”，也不是大娘刚走出门；房内的独白与密道演出还在本段。

人物与对象：李逍遥、李大娘、密道遮挡物。床边与走动的大娘是同一人物的不同演出实例，不能记成两个人。
依据：[001回执](../testing/e2e/stages/001-opening/report.md)、[梦境正文](../../projects/pal/content/scenes/s000.json)、
[房内正文](../../projects/pal/content/scenes/s001.json)；已核55行正文和本段参与者。

### 002 接待苗人与赏银

从卧房正常出门，到二楼走廊靠近李大娘，触发她与三名苗人的接待长对话。
苗人头领交代要求，逍遥得到500文赏银；三人随后各自进客房。必须等三人全部入房、走廊中的三人消失，
才进入003。房内出现的是对应客人的实例，不是又来了三位新客人。

演出的先后不能简化成“大家说完话才一起起步”：已核表现包含先起步、关键对白时站定、短暂续走、最后离场。
二阶段用明确编排表达这些停步，不让全地图NPC都随对话冻结。剧情记忆只需记住交谈与赏银完成时人物关系仍连贯，
不要把原引擎的调度细节当成剧情本身。

依据：[002回执](../testing/e2e/stages/002-inn-guests-and-reward/report.md)、[走廊李大娘与三苗人](../../projects/pal/content/scenes/s003.json)。

### 003 赶不走的醉道士与厨房交代

三苗人入房后，逍遥下楼找李大娘，再到门口与醉道士交谈。道士不是要钱，而是讨酒；
逍遥担心挨婶婶骂，拒绝给酒，道士赖着不走。随后回到厨房，李大娘让他把桌上酒菜端给楼上的苗人。
此时只听交代，还没有拿菜，更没有给道士喝酒。

易混点：曾把“听到大娘喊你再去厨房”记在这一段，但核对后明确，台词“逍遥～你过来一下！”
属于004送酒结束后的喊话，不应提前挪进003。003的终点对白是“快把桌上的酒菜端上楼去”。

依据：[003回执](../testing/e2e/stages/003-kitchen/report.md)；当前走廊大娘、道士初见与厨房交代分别位于
[客栈大厅](../../projects/pal/content/scenes/s003.json)和[厨房](../../projects/pal/content/scenes/s001.json)。

### 004 端菜与桂花酒邀约

1. 在厨房拿起酒菜，听大娘确认就是那盘，逍遥开始端菜。
2. 把酒菜送到苗人随从客房。客人嫌桂花酒不够烈，表示自己带了酒，逍遥把退回的桂花酒收在怀里。
3. 回到门口，面对醉道士，通过物品菜单使用桂花酒。道士讨“一口”，却把酒喝光；逍遥要他赔偿。
4. 道士提出以教剑回报，约定明晚三更在十里坡山神庙见，随后消失。逍遥惊讶，大娘又喊他过去，逍遥应答。

到恢复自由移动就结束004，不继续进入厨房领取买虾任务。这里是**学剑邀约，不是当场学会御剑术**。
桂花酒不是捡到便自动触发剧情，正式流程包含面对目标的物品使用；取消和错误站位不耗酒，属于独立测试，
不插进正常攻略的连续剧情。

依据：[004回执](../testing/e2e/stages/004-meal/report.md)、[取菜和随从正文](../../projects/pal/content/scenes/s001.json)、
[道士赠酒正文](../../projects/pal/content/scenes/s003.json)。赠酒正文归道士，物品只是使用入口。

### 005 买虾出门与香兰报信

作者于2026-10-02确认本段范围。下面路线已在两阶段实跑，40行主线对白与说话人完整，见[005回执](../testing/e2e/stages/005-shrimp/report.md)。

1. **回厨房找李大娘。** 她给50文，托逍遥买几斤新鲜虾，并说市场买不到就问打渔的船家。
2. **去码头市集，先问鱼嫂。** 鱼嫂说这两天风浪大，船家没有捕到鱼货，新鲜虾也没得卖。
   这一步补足买虾的缘由，推荐保留；不是报信事件的程序必需条件。
3. **听水生叔讲仙女。** 靠近水生叔，听他说东边仙灵岛上有漂亮仙女；逍遥打趣他。
   这段谈话会切换张四的对话，使他接下来回应仙灵岛传闻。
4. **听张四回应。** 张四说自己也去过仙灵岛，没见到仙女，倒被一个凶婆婆赶了出来；逍遥怀疑两人见鬼。
   必须是这段回应，而非张四原先“风浪大、没打到鱼”的闲聊；它结束后才开启回村报信。
5. **离开码头市集，回盛渔村外街。** 丁香兰跑来告知：逍遥出门后，李大娘突然昏倒，洪大夫催他赶快回去。
   逍遥答应马上回去，报信对话结束并恢复操作，即为005终点。

程序依赖与推荐路线要分清：**水生叔首段 → 张四的仙灵岛回应 → 再进入盛渔村**，才是这次报信的触发链。
厨房委托只给钱和推进大娘自己的后续对话，鱼嫂只说明无虾；二者没有设置报信开关。
不能由此在正常剧情攻略中省略买虾的前因，也不能把“问过鱼嫂”写成必需的剧情标记。

005不含返回客栈探病、洪大夫诊断、求药或出海。报信脚本会在后台预备后续人物状态，
但这不表示玩家已经经历后面的剧情；后续分段仍须另核边界。

已核演出：香兰先走近、停步喊话，报信说完后自行沿村路返回，逍遥不等她走完整段就恢复操作。
重复交谈时，大娘只复读催帮忙、不再给50文；张四在仙灵岛回应之后先提醒回店，再稳定复读打渔祈愿。
这些重复交谈在独立guards核过，不插进正常story路线。二阶段报信正文位于香兰本人方案，场景入场只负责显式调用。

一手证据定位：原版提取`data/extracted/events/all.json`的`L_741`为买虾给钱，`L_1528`为水生首段，
`L_1436`末尾的`0x6D [5,903,0]`安排下一次入村报信，entry903的281/287称谓明确为“香兰”。
`L_1606`鱼嫂对话没有这个开关；秀兰的后续对白是“听大姊说～李大娘病了”。
当前作者工程可查[厨房大娘](../../projects/pal/content/scenes/s001.json)、
[水生叔与张四](../../projects/pal/content/scenes/s005.json)、[回村报信](../../projects/pal/content/scenes/s004.json)。
原版提取文件为本机资源，不将缺少该文件的干净clone误称为已具备原始资产。

### 006 回客栈求药与出海上仙灵岛

005 报信结束后，逍遥从盛渔村外街回到客栈。进入李大娘房间区域后，洪大夫的触碰脚本先自动开始诊断；
对话结束后，逍遥再与小虎子交谈。小虎子正文有首次说明和两次复读，内容是仙灵岛有仙女、可以求药。

洪大夫段落的结束动作是本段关键后继：显式把码头张四切换到“出海上船”方案，并恢复张四的可见状态。
这不是自动行为，也不是进入码头就凭等待猜出来的状态。离开房间、经过客栈大厅和村外街后，逍遥在码头与张四交谈，
听完“走吧～上船”，再以正常移动走到船只触发区；船只脚本负责载入仙灵岛。

穿过客栈走廊出口附近还会进入苗人头领的求药指引：他先谈“树欲静而风不止”，随后说明水月宫、破天锤和忘忧散，
李逍遥收下破天锤并服下丹丸（`dlg.366–419`）。这段在两轨当前 005 存档链中都实际出现，不能因为它位于003使用过的场景地图就省略。

本段停止在 `s014` 仙灵岛场景已经载入；岛上首段落地对白属于后续内容，不纳入本段“上岛即止”的主线边界，也不继续水月宫或破阵。

脚本证据：[客栈 e35/e36](../../projects/pal/content/scenes/s002.json)、[张四与船只](../../projects/pal/content/scenes/s005.json)。

第一阶段对照：原始 `L_1509` 的队伍走位、0x15 朝向、0x3F 骑乘和 scene15 切换，当前 Reforge 分别由 `moveParty`、`setPartyFacing`、`ride(e116)` 和 `loadScene(s014)` 表达。

### 后续怎样滚动补全

- 每确认或实跑一段，就补这份攻略中的前因、路线、人物、关键对白用途、后果和停止点，再同步碎片目录。
- 分清必需触发、推荐叙事与可选支线；有复读、阶段切换、物品使用或重复领奖风险时写明条件。
- 人名、人物实例、地点别称和曾经混淆的时序写进查找表；已核的正文与结论直接更正，不只在末尾堆反驳。
- 为实际经过且含义已核的实体、方案、步骤命名；尚未理解的后期内容不靠泛称或猜测补名。
- 每条新结论连接实际脚本或执行回执。只有读了代码就标“脚本已核”；有真实运行才能标“已实跑”。
- 006以后随推进再细化。旧概览中的✅不能自动升级为当前版本的触发、路线或完整E2E证明。

## 忆如-韩仲晰暗线（跨作品关键，2026-06-25 深挖）

> 这条线把**仙剑一白河村**一直串到**仙剑五小蛮**。是"结局后扩展"最重要的硬约束，也是把原版扩展和系列大背景缝合的接口。

| 时间点 | 事件 | 可靠性 |
|---|---|---|
| 仙剑一·白河村 | 韩医仙之子**阿宝（韩仲晰）**登场（煎药小男孩） | ✅ |
| 仙剑一期间/后 | 白河村被魔族所毁 → 阿宝被**李逍遥**救下 → 被植入魔尊之子**"伐天"**灵体 → 送**阿奴**抚养 | ✅ |
| 仙剑二（忆如 8 岁） | 忆如先由韩医仙抚养 → 后被李大娘接回仙灵岛；月如被回魂珠复活 | ✅ |
| 仙剑二结束 3 年后（忆如 ~11） | 忆如去苗疆祭母 + **试炼窟为月如找傀儡虫** → 与韩仲晰重逢 | ✅ |
| 仙剑 OL（忆如 16 岁） | 忆如与韩仲晰相恋的主线 | ✅ |
| 漫画《忆相逢》（忆如至 20 岁） | 两人私奔、成婚、生**小蛮** | ✅ |
| 之后 | 伐天觉醒 → **韩仲晰死**（一说被李逍遥所杀）→ 忆如守寡 → **忆如早逝** | ⚠️ |
| 仙剑五 | 小蛮（忆如遗孤）由阿奴（海棠夫人）抚养，成主角 | ✅ |

**对扩展的意义**：
- 这条线是**官方既定的悲剧链**，扩展不得改其关键节点（阿宝必成魔宿、必娶忆如、必死；忆如必生小蛮、必早逝）。
- 但**仙剑一白河村**是它的源头——你在仙剑一扩展里深化白河村时，可埋"煎药小男孩"的命运伏笔，这是把原版扩展和系列背景缝合的**绝佳接口**，且不碰红线（伏笔≠改结局）。
