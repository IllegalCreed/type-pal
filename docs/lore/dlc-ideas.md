## DLC-01 · 鬼界支线（构思成型）

> 2026-06-25 讨论。作者原创构思，经查证官方无冲突。**叙事质量高，推荐作为引擎跑通后的首个实战内容。**

### 核心设定

- **触发**：鬼阴山后山，**某特定年月时辰**，鬼界入口在此临时开启（呼应"鬼界为六界生灵灵魂中转之地"的官方设定）。
- **入口性质**：**临时性**——时辰一过即关闭。不构成永久通道，**不与仙剑二王小虎进鬼界冲突**。
- **主线**：李逍遥进入鬼界后，**追寻疑似父母（李三思夫妇）的灵魂**。
- **结局处理（高级悲剧）**：**最终并未和父母正面相遇**。在追寻过程中——发生了一些事，解决了一些问题，了解到一些父母旧事，了却了心里的纠结。
- **角色弧**：呼应李逍遥"一开始就崇拜父母"的设定 → 鬼界经历让崇拜**从盲目变为有依据**（确认父母为救皇甫英而死、盗水灵珠的侠义）。

### 关键叙事规则（作者定义，世界观自洽）

> ⭐ **鬼界 NPC 不是全知叙述者**：鬼只记得生前之事，且多为道听途说之辈。
>
> 推论：
> - 鬼界里听到的"传闻"**天然不可靠** → 李逍遥得到的只是碎片，不是真相全貌。
> - 不同的鬼说法可能**互相矛盾** → 需自己拼凑。
> - 支持"了却纠结但不正面相遇"——他得到的从来不是完整答案，而是**足够释怀的碎片**。
>
> 叙事质感：**不是"揭秘"，是"拼图"。**

### 女飞贼伏笔链（贯穿鬼界 → 扬州）

```
鬼界（仙剑一·鬼阴山后）
  └─ 李逍遥听到/看到一个关于
     "当年有个姑娘追随南盗侠"的传闻或幻影
        └─ 不点名是女飞贼（鬼只记得生前事，道听途说）
           └─ 玩家此时不知是谁
              ↓
扬州（仙剑一·正传）
  └─ 女飞贼登场
     └─ 她年轻时倾慕李三思（南盗侠）→ 效仿走上飞贼之路
        └─ 过程中认出李逍遥是故人之子 → 手下留情
           └─ 玩家恍然："鬼界那个传闻原来是她！"
```

**女飞贼动机链（干净留白，官方无设定）**：
- 倾慕李三思是**单向的、未果的** → 不动摇李三思夫妇关系（红线安全）。
- "未完成的爱" → 仙剑式悲剧内核。
- 官方对女飞贼**无背景设定** → 这是干净的创作空间，扩展不吃书。

### 评估：为什么推荐作为首个实战内容

- 在仙剑一**现成场景**（鬼阴山）里，素材复用。
- 用仙剑一**现成机制**（回魂仙梦式幻境/梦境）的变体，不引入新系统。
- 叙事有深度但不需新战斗系统（鬼界遇鬼可用现有战斗）。
- 改动面可控：临时入口 + 一段支线剧情，不动主线结构。
- **同时是练手和正式产出**——做得好就是第一个能玩的扩展内容。
