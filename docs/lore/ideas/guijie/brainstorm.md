## 铺垫链（2026-06-29 讨论，作者提出）

> 关键洞察:作者自发加了"盛渔村偏见前置任务" —— 这给整条支线安了**主题动机锚点**。李逍遥为什么需要"重新认识父母"?因为他从小被父母盗贼身份的流言影响,崇拜里掺着怀疑。这是专业叙事设计才会主动做的事。

### 1. 盛渔村前置铺垫（新增）
- **背景动机**:李逍遥父母李三思夫妇是盗贼(南盗侠),江湖名声复杂 → 盛渔村人**对李逍遥有所偏见**。
- **李逍遥内心**:虽然崇拜父母,但**难免被流言影响** —— 这是支线的**情感起点**(崇拜里有裂痕)。
- **前置分支任务**:在盛渔村做一个**前置支线**,让玩家感受到这种偏见 + 李逍遥的纠结。
  - 作用:给"重新认识父母"这个主题**立动机** —— 没有这个,鬼界的"拼图"就没有张力(拼出的真相为什么要紧?)。
  - 位置:仙剑一开篇盛渔村(第一章 1.1 附近)。

### 2. 鬼阴山·韩医仙提醒（新增铺垫）
- 白河村韩医仙在鬼阴山与李逍遥一行**分开前**,提醒主角"小心"。
- 作用:给鬼界入口一个**可信的预警**,不是凭空冒出来。
- 位置:第七章鬼阴山段(7.x)。

### 3. 鬼界入口触发（待结合昼夜系统）
- **三次背影**:后山可看到疑似父亲的背影飘过,第三次看到他**进入入口** → 引导玩家进入支线地图。
- **时辰触发**:若新引擎做昼夜系统(roadmap 议题 2),这里**指定某刻时辰**才能触发 → 入口的"临时性"用机制落地。
- 位置:鬼阴山后山(第七章后)。

## 戏胆（2026-06-29 作者拍板方向，2026-06-30 增补小角色）

> ~~旧提案"父母执念徘徊、一直等儿子来"~~ **已否决**（作者 2026-06-29 否决）。否决理由：与父母之爱本性矛盾——父母不可能"盼着子女死后团聚"。该方向有情感逻辑漏洞。

### 核心戏胆：误入鬼界 + 背影陷阱 + 父母已入轮回

**关键设定（作者提出）**：
1. **李逍遥是误入鬼界**，不是被父母引来——父母不可能盼子女死。
2. **引导李逍遥的"父亲背影"是仇人假扮的陷阱**。原设想"三次背影"的第三次引导入入口，现反转：那是仇人设的局。
3. **李三思夫妇早已入轮回**，鬼界里只剩**故事/事迹流传**，不是他们的灵魂。
4. **仇人**（李三思的仇敌，死后成鬼界恶鬼）一直引导李逍遥，目的是设计干掉他（报复其子）。

### 为什么这个方向更好（手艺复盘）
- **修复父母之爱逻辑漏洞**：父母因爱子而**不留恋、早入轮回**，更悲更真。
- **有真正的反转（戏眼）**：寻亲故事 → 中途发现是猎杀陷阱。认知翻转 = 高潮。
- **更纯地兑现"拼图非揭秘"**：父母真正不在了，只剩故事流传——最纯的拼图（拼一个不在的人的肖像）。
- **恨意反成证据（戏剧反讽）**：仇人为设局不得不谈论李三思夫妇，越恨越贬低，反越坐实其侠义。

### 小角色（恩人向导）—— 2026-06-30 作者提出，结构性补全

> 补上了整个支线的两个结构性缺口：① 鬼界向导 + 正面信息源；② boss 战的情感导火索。

**角色功能**：
- **识别方式（2026-06-30 作者修订，从"认铁剑"升级）**：李逍遥为进入某处，施展**飞龙探云手**偷了某鬼差的钥匙 → 碰巧被小鬼**目击** → 认出这是李三思的家传绝技 → 判定李逍遥可能是恩人之后。**比铁剑更准**（飞龙探云手是李家独门，铁剑是死物），且把识别从"陈述"变成"场景"（show don't tell）。铁剑可作之后的二次确认。
- **察觉活人气息**：小鬼察觉到李逍遥、林月如的**活人气息** → 帮他们**隐藏气息**，方便在鬼界行动。（潜在游戏机制：气息有持续时间/会泄露/被强鬼识破——做节拍表/关卡时展开。）
- **身份来源**：李三思**生前**救过/帮过的人，比李三思先死，在鬼界等轮回。**不需要李三思灵魂在场**（符合"父母已入轮回"）。
- **作用**：① 向导，引导李逍遥在鬼界行动；② 正面信息源，讲父母真实事迹（与仇人的恨形成对照）；③ **牺牲自己**，促成/触发李逍遥与 boss 的战斗。

**双重证据结构（复调叙事）**：

| | 仇人 | 小角色（恩人） |
|---|---|---|
| 对李三思的感情 | 恨 | 恩 |
| 对李逍遥的行动 | 设陷阱害他 | 引导帮他 |
| 泄露的父母事迹 | 恨意中漏出侠义（反证） | 感恩中讲出侠义（正证） |

两股相反力量独立证明同一件事：李三思夫妇是好人。小角色的死本身是最强证据——愿为已死恩人之子而死，证明恩人生前之事分量重到足以拿"余命"去还。

### 🌟 月如复活伏笔（2026-06-30 作者提出，神来之笔）

> **修原版最大叙事漏洞**：月如复活长期被诟病为"机械降神"（锁妖塔重伤→傀儡虫→仙剑二回魂珠，缺因果）。本支线在**锁妖塔（月如重伤）之前**埋下她能被复活的因果 → 让突兀设定变成"原来如此"。

**伏笔设计**：
- boss 是"水灵珠受害者"，死于苗疆灵力灾变/诅咒 → boss 死后，**残余灵力/怨念凝结体**（与"生→死"边界有关）散落。
- **月如无意间接触/吸收了它** → 获得一种"**魂魄不易离散**"的性质（不是复活，不是续命，只是死后魂魄多停留/多完整一点）。

**为什么这么设计（因果链自洽）**：
- 傀儡虫能起作用，前提是月如还有可操纵的魂/肉身；若魂魄早散，傀儡虫也没用。
- 这个"魂魄不易离散"正是**傀儡虫能起作用的必要条件** → 给"傀儡虫为何对月如有效"补了官方设定一直缺的因果。
- **不剧透**：鬼阴山时点无人提傀儡虫/复活，月如只是"身体里多了点什么，说不清"，完全不影响当下剧情。
- **焊接支线与主线**：月如复活链 = 鬼界奇遇（本支线）+ 傀儡虫（圣姑）+ 回魂珠（仙剑二）。本支线为整条链补了前置因果。

**老玩家体验**：鬼界支线时月如活蹦乱跳、捡东西时不知意义 → 锁妖塔重伤、圣姑用傀儡虫 → 老玩家回想鬼界突然懂："难怪她魂能保住。" 伏笔最高境界：**未来的自己懂了**。

### 🚨 月如复活伏笔的红线（必须拿死）

> 月如归宿是红线 T5.5：傀儡虫续命（活尸态）→ 回魂珠复活 → 仙剑二仙灵岛数年 → **仙剑五早逝**。**最终必死，不得推翻。**

- ✅ 本伏笔只解释"傀儡虫**为何有效**"，**不改变"她最终会死"的结局**。
- 🚫 **严禁**写成"月如从此不死/长生/改命"。
- 分寸：月如吸收的东西是"**延缓离散**"的，不是"永生"的。它让傀儡虫有下手余地，但不能违背"最终早逝"。
```
起：误入鬼界(好奇) + 跟"父亲背影"(期待) + 遇小角色被认出(意外的暖)
承：小角色引导+讲父母真实事迹(崇敬积累，正面证据)
   + 追"背影"总追不上(困惑) + 从其他鬼听碎片(拼图充实)
转/戏眼：发现背影是假的!是仇人陷阱!(震惊/背叛感)
高潮触发：小角色为护李逍遥 / 为揭露陷阱而牺牲(血淋淋的情感导火索)
boss战：仇人愤怒中口不择言，暴露更多父母事迹(恨意反成证据)
合：父母已入轮回(真正的不在)，但事迹/爱是真的
   → 释怀(崇拜有依据) + 带着完整真相离开，不是为复仇而战
```

### ⚠ 反转必须钉好的两点（手艺）
1. **得有伏笔**：事后回想"背影有破绽"——剑不是铁剑 / 背影过处鬼畏惧而非敬重。意料之外、情理之中。
2. **反转只否定"引路人是假的"，不否定"情感是真的"**：背影假，但故事真、爱真。拼图是真的，只有诱饵是假的——守住这条，前面积累才不白费。

### ⚠ 小角色牺牲→boss 战的分寸（必须钉死）
- **风险**：牺牲→boss 战容易变成"为兄弟报仇"的动作片套路，劫持"释怀/认识父母"的主题。
- **分寸**：boss 战的意义不是复仇，是**揭露真相**——仇人战中愤怒口不择言，暴露更多父母事迹（恨意反成证据）。
- 小角色的死 = **触发战斗**（情感导火索）；战斗的**收获** = **拼到更多真相**（主题推进）；战斗**结局** = 李逍遥带着完整真相释怀离开，**不是杀仇人出气**。
- 守住：小角色的死有意义（救了李逍遥），但支线落点仍在"释怀/认识父母"上。

## 悬而未决

### ❓ 入口位置：**已定（2026-06-30）** —— 鬼阴山后山临时裂隙。
- 定论：鬼界入口**不唯一**。酆都是"正路/官道"（制度化、长期开放），鬼阴山后山是"临时裂隙/野路"（偶发、时辰一过即关）。官方从未设定唯一入口，酆都只是"出现过的入口"。
- 设定因果：鬼阴山本阴气汇聚，特定时辰与鬼界偶发共鸣开临时裂隙。名字自洽 + 给昼夜系统真实叙事功能。
- 好处：完全规避"李逍遥仙剑一怎么到酆都"；与仙剑二王小虎走酆都正路是两条独立线，零冲突。
- 详见 [world-rules-ghost-realm.md §二](../../world-rules-ghost-realm.md)。

### ❓ 戏胆核心：**已定**（误入 + 背影陷阱 + 父母已入轮回 + 小角色牺牲，见上）。

### ❓ 仇人身份（2026-06-30 据《水灵劫》正典锁定方向；识别依据 2026-06-30 修正）

- ⚠ **原设想"仇人=四大恶人之一"已否决**：经官方百科查证（[百度百科·四大恶人](https://baike.baidu.com/item/%E5%9B%9B%E5%A4%A7%E6%81%B6%E4%BA%BA/3951871)），李三思**本人即四大恶人之一**（南盗侠），另三人是其**同伙**而非仇敌。同伙害其子逻辑不成立。
- 红线 T4：仇人**不能是拜月**（拜月翻案是硬红线）。但《水灵劫》确认——害死李三思的直接元凶是**拜月下无影毒**（详见 [characters.md 李三思条目](../../characters.md)）。
- ✅ **《水灵劫》正典给了 boss 恨意的根源**（2026-06-30 查证）：李三思受**巫后托付**带走水灵珠（非主动盗珠）→ 此行为**客观上间接导致巫后牺牲、苗疆遭灾**（拜月无法用珠→操控水魔兽发洪水诬陷巫后→巫后与水魔兽同归于尽→苗疆大旱）。
- **推荐方向：候选②（水灵珠受害者，原创鬼）** —— 因苗疆遭灾家破人亡的无辜者，死后在鬼界恨"李三思"，设局害其子。**这个恨是正当的**（他真的受害了），让 boss 不是纯反派，增加道德灰度。

## Boss 身份 + 剩余占位 · 候选提案（2026-07-02，Claude 提案，待作者拍板）

> 一次性给出 boss 身份两案 + 据点/路C/收尾占位的候选填法。**全部为 [提案] 状态，作者拍板后才落 beat-sheet。**
> 出发点：《水灵劫》正典留白——巫后给了李三思"逃跑计划"，**计划的执行人官方没写**（见 [characters.md 李三思条目](../../characters.md)）。Boss 从这个缝里长出来，填缝有出处。

### 主推案：「送他出苗疆的人」

**生前**：南诏边地猎户向导，巫后信得过的宫外眼线。奉巫后密令接应李三思出境（"送此人走雾障岭，不得过问他带了什么"）。同行数日，篝火夜话——李三思提过"家里有个小子，叫逍遥"（与花海对小女孩的念叨**同款台词**，李三思想家的习惯动作，两处互证人物一致性）。

**恨的因果**：拜月得不到真珠→发洪水诬陷巫后→苗疆大旱（正典因果，约十年前）。他全家没于水灾。民间流传的是拜月的官方叙事（"圣物失窃，天降大罚"）→ 他回想自己亲手送出境的中原人："是我，把灾祸送出了苗疆。" 最后投了淹死全家的那条河。

**死后**：魂追仇人到中原侧鬼界→发现李三思**早已入轮回**——连复仇都迟到了。恨无处安放，拒过无常殿，沦为脱离管制的普通恶鬼（**非天鬼族**，红线安全），在鬼阴山裂隙内侧烂了十年。

**一次焊死四个逻辑缝**：
1. **B3 硬约束**（叫得出"逍遥"、熟身形步态佩剑）——篝火夜话+同行数日。⚠ 顺带修 beat-sheet 据点段的时序矛盾：现文说"伪装套话解释了知道名字"，但 B3 呼唤发生在**入界之前**，套话尚未发生——生前熟识是唯一自洽解。
2. **裂隙为何在鬼阴山 + 村民为何忌讳**——他的怨念十年冲撞界膜，把裂隙顶薄。B2 韩医仙"晚上别逗留"的民间禁忌 = 怨念冲界的民间观测。B2/B3/裂隙成因/boss 动机四点一线焊死。
3. **已定台词"你父亲欠我们一条河的命"**——洪水淹家、投河而死，"河"字严丝合缝。
4. **时间线纪律结构性安全**——他至死不知巫后托付（巫后没说包裹是什么），**说不出**"水灵珠/巫后"等剧透词，只会喊"圣物/天罚/那条河"，李逍遥全程听不懂。

**道德灰度三层**：真受害（全家没于灾）+ 真被骗（信的是拜月版因果——**他的恨本身是拜月谎言的二次伤害**）+ 生前真帮过李三思（护送出境）。父亲的恩人变成儿子的仇人，中间隔着一个谎言和一场灾——"侠义有代价"长成了具体的人。

**伪装形象（据点占位可填）**：生前跑商队的"老向导鬼"，在据点以给新鬼指路为业——**生前是向导，死后还在指路，只是这次指向陷阱**。

**时间线核对**：李三思赴苗疆约 17-18 年前（李逍遥 1-2 岁）；拜月发洪水约 10 年前（回魂仙梦锚点）。"送人出境→数年后灾变"顺序放得下，拜月布局多年反而更合理。

### 备选案：「追了一辈子背影的守卫」

水灵珠"失窃"当夜的守殿卫士，被拜月栽"失职招灾"罪名，为自证孤身追捕李三思数月未果（李乘金翅凤凰飞走），回乡时家已没于洪水，背污名而死。卖点："**我追了他一辈子的背影，如今用这个背影钓他的儿子**"——追捕者对背影的熟稔给"假扮背影"最强解释力；且他与李三思是**两个都被拜月冤枉的人，一个恨死了另一个**，与 B1 老人的"误会"镜像最工整。弱点：身份链长（守卫→被冤→追捕→回乡→死），台词空间要求高；"体制内守卫"离"苗疆无辜受害者"定位稍偏。两案核心部件（篝火知名/追捕知形）可互换嫁接。

### Boss 战骂词三段（恨意反成证据的具体落法）

血量每过一阶段掉一段骂词，战斗即拼图最后一页：
1. **骂贼**："中原来的贼！装什么大侠！"——**与 B1 老人用词一模一样**。凡间鬼界，骂的是同一个人、同一个字。
2. **骂天**："全家都没了……就因为他！凭什么？！凭什么他死了还能当大侠？！"——恨挂在**灾祸与不公**上，不碰"谁信谁/为何来苗疆"。⚠ **严禁透露水灵珠/巫后/信任关系**（作者2026-07-02红线）：原 Claude 版"为什么她偏偏信你爹"里的"她/信"暗含"有女人信任李三思"，会提前泄露苗疆关系，违反时间线纪律（巫后/水灵珠是第十八章回魂仙梦才揭晓）。本重写把恨集中在"我受害、他不配好名声"上，李逍遥只能听出"爹在苗疆惹过大祸、害过人命"，**听不出任何"女人/圣物/托付"信息**——为日后回魂仙梦留纯白。
3. **泄露温柔**："他说要带他家小子来看南诏的花……装！装什么慈父！"——与花海回忆撞成同一意象（李三思带小女孩看花、想带儿子看花）。**恨了十年，记住的全是他的好。**

彩蛋（可选）：原版鬼阴坛必败战可偷石长老毒龙砂（timeline ✅）。若玩家偷过，boss 战多一句："在祭坛上看见那手贼功夫时，我差点以为是**他**从轮回里爬回来了。"

### 路 C 显真身：第四次背影

前三次背影在 B3。路 C 尽头**第四次**见父亲背影——这次它不走了。李逍遥喊"爹"，背影缓缓转身：父亲之形→据点"知情者"之脸→恶鬼真容，三层剥落。**整条支线是在等一个背影转身，转过来的是仇人的脸；真正的父亲的背影永远不会转身了——他已入轮回。** 直接给 D.3 独白供弹药，"三次背影"结构闭环（3+1）。
可选加码（有争议，作者拍）：boss 一阶段保持李三思之形作战，逼李逍遥打"父亲的脸"，月如台词稳军心，二阶段现真容。

### 据点三个占位的候选填法

- **打听特征·三层递进（信息可靠度分级）**：① 名号"南盗侠"→ 传闻级碎片，**故意互相矛盾**（鬼A"劫了半个江南，恶人"/鬼B"他的钱都散给穷人"/老鬼C"他为救一个中毒的官差以身试毒"——皇甫英事迹的模糊回声，不点名，暗通 DLC-04）→ 兑现"鬼非全知叙述者"规则，复刻 B1 困惑；② 铁剑示人 → 年长的鬼认得"南边使剑的侠客"（对接 characters.md 既有 demo 传闻）；③ 飞龙探云手**不主动展示**——据点小事件（帮小鬼追回被抢之物）自然使出，被"老向导"（boss 伪装）看见借此搭话"这手法……你是李三思什么人？"。伪装者不自己凑上来（可疑），让手法递台阶；日后回想：他认出手法那刻的震动是真的——仇人看见了仇人的绝技，只是当时被读成故人感慨。
- **女飞贼伏笔（已定分寸：轻、不点名）**：据点茶棚老鬼讲古，一拍即收："当年江南有个姑娘，夜夜踩着屋脊追一个人的影子。追上了么？没有，人家有家室。后来那人死了，听说她还在偷，偷成了名贼……"——"**追影子**"与"追背影"同韵（女飞贼追李三思的影，李逍遥追父亲的影，都追不上）。扬州城墙战玩家自己想起来。
- **据点↔大鬼轻焊接（可选，一句台词）**：老鬼抱怨"这些年这一带越来越不太平，鬼差都不常来了"——裂隙常年被怨念冲撞、秩序松动，大鬼截流魂魄是"生态后果"**非 boss 部下**（部下化会脏了小鬼报恩的纯度）。

### 主题层：爱入轮回，恨滞留（按既有规则推导，白送）

父母因爱子不留恋，过堂干净早投胎；boss 因恨拒判，脱离管制烂在原地十年。**爱让人走得干净，恨让人留得腐烂。** D.3 的释怀因此从鸡汤变成有利害的选择：李逍遥若带着恨离开鬼界（为小鬼、为被骗），就在走 boss 的路。可选补一拍（点到即止防洗白）：boss 消散前恍惚"……我是不是，也能去投胎了？"——恨断了，他反而解脱。李逍遥目睹：恨到头，什么都不剩。

- **B1 暴击的实质**：不是"我开始怀疑爹了"，是"**我竟然一个字都答不上来**"——无言以对的羞辱+无力，非信念危机。
- **执念校准**：~~"我爹到底是不是贼"（怀疑句）~~ → "**我爹不是贼——可我为什么一句话都说不出来？**"（求证的冲动，憋着一口气把证据找回来）。
- **Boss 段红利**：信念不摇、**认知被迫扩容**——把"爹伤过无辜者"装进"爹是大侠"的框，框不裂但被撑大："大侠"的定义从完美英雄长成**背着代价行侠的人**。"复杂的释怀"落点在此；且避免"信念反复横跳"的廉价剧作。
- **D.4 姿态随之校准**：判词是**胜利者的从容**（终于能把"贼"字接过来翻过去），不是艰难的和解；长版"我是贼的儿子"=从被扣帽子到**戴着帽子笑**，非"从躲到领"。
- **A.7 措辞校准**：~~"B1 创伤的治愈"~~ → "**第一次拿到实证的畅快**"（治愈的是无言，不是怀疑）。
- **连带 beat-sheet 待拍板项**：B1.6 "带着'我爹到底是不是贼'的未解之结" → 建议改为"我爹不是贼，可我一句话都说不出来"式憋屈（执念=求证非怀疑）。B1.4"灵魂暴击"、B1.6"执念点燃"的机制不变，只校内涵。

### 提案内部优先级（Claude 排序）

**boss 主推案 + D.4 心语升级** ＞ 骂词三段、第四次背影 ＞ 其余锦上添花。
