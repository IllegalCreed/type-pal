## 目的

查人物、剧情顺序、世界规则或扩展创作依据时，从这里进入唯一主题来源。AI负责查证与一致性检查，不以聊天记忆裁定设定。

## 范围

按需维护仙剑一直接相关资料；触及其他作品时再查对应来源。世界观资料与[未承诺制作的故事素材](ideas/README.md)分开，创意登记不等于立项或排期。

## 当前状态

本页是现行导航，主题的可靠性、版本选择及待核项以正文为准。“作者确认”“原版脚本已核”“当前工程已有编排”“实际实跑通过”分别记录；旧✅标签不自动获得官方一手或当前运行信用。

女娲后裔“死后不入轮回”的来源争议仍按[世界规则](world-rules.md)与[时间线](timeline.md)核对，不由目录裁定，也不撤销[既定创作红线](taboos.md)。月如归宿的呈现版本、回魂珠使用者等未决项回[版本登记](versions.md)分别判断。
