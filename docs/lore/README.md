# docs/lore/ — 仙剑设定真值库

> 本目录是本项目的**世界观 / 剧情设定的权威参考库**。所有围绕仙剑 IP 的扩展创作（第二阶段的 DLC 剧情、未来可能的任何内容）都以这里为准绳，**不与官方设定冲突**。
>
> **谁说了算**：
> - **作者（你）= 最终裁判**。你是仙剑粉丝，对设定的记忆比 AI 可靠。
> - **AI = 查证助手 + 结构化 + 一致性检查**。AI 的流行文化记忆半对半错，**不作为真值**，只负责从官方 / 百科 / wiki 检索并标注来源，由作者校验。
> - **来源可靠性**逐条标注：✅ 官方 / 多源一致 ＞ ⚠️ 单源或粉丝向 ＞ ❓ 存疑待核。

## 为什么有这个库

- 作者只对**仙剑一**印象清晰，其他历代印象模糊，需要查证。
- 扩展剧情的硬约束 = **不推翻官方正传 / 外传**。同人创作最大的雷区是 OOC（角色崩坏）和吃书官方设定，本库就是防雷用的。
- AI 记忆不可靠，**不能依赖对话里的即兴回答**，必须落到可回查、可版本管理的文档。

## 工作方式：按需查证 + 滚动建库

**不**预先查完所有历代设定（那会变成永远准备不完的大工程）。而是：

1. **当前只围绕仙剑一扩展** → 优先维护仙剑一直接相关的人物 / 事件 / 时间线。
2. **其他历代**：只在扩展剧情可能碰到时才查证并补入。比如写到李逍遥父亲时，才查证仙剑 3 / 3外传里李三思的官方设定。
3. **查证结果写进本库**，一次查证、永久复用，下次创作直接翻库。

## 扩展红线（hard constraints）

> 每条 = "动这条就吃书官方设定 / OOC"。创作时任何剧情都必须过一遍这个检查。

详见 [taboos.md](taboos.md)。摘要：

- **女娲族死亡宿命不可逆**：历代女娲后裔（紫萱→林青儿→赵灵儿→李忆如→小蛮）皆以身殉道，死后不入轮回。不能"复活"灵儿 / 巫后来圆结局。
- **仙剑一正典结局**：赵灵儿与水魔兽 / 拜月同归于尽；林月如傀儡虫续命（DOS/98 版）或被救活（新仙剑隐藏结局）——**扩展取哪个版本为正典，必须先定**（见 [versions.md](versions.md)）。
- **李逍遥的官方后续**：仙剑二成为蜀山 27 代掌门、与月如正式在一起、女儿李忆如；仙剑五成为蜀山七圣、晚年如酒剑仙。**扩展不得推翻这些**。

## 更新规则

- 每次查证后**立即落库**，不要堆在对话里（对话会被压缩丢失）。
- 每条设定标**来源链接**和**可靠性**。
- 发现冲突 / 版本差异 → 记进 [versions.md](versions.md)，由作者定哪个算正典，不擅自合并。
- 本库**只升不降**：纠正过的设定覆盖旧值，但保留"曾被误记为 X"的备注，避免重复踩坑。
