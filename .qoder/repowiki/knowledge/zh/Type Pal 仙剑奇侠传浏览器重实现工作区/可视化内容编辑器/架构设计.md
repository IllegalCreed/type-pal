本包是 Phase 2 可视化编辑器,D-B0 地基已就位(非占位骨架)。当前结构:

- `src/main.tsx` —— React 根;`useEffect` 调 reforge 的 `loadProject('demo')` 把入口场景 id 打到 console,证明「editor → reforge import + /projects serveDir + loader」整条复用链通(B0 只证链路,不画 canvas)。
- `src/core/` —— 纯 TS 编辑核(无 React、无 DOM):`commands.ts`(Command 接口 + MoveEntityCommand 示例)、`edit-session.ts`(EditSession + undo/redo 栈 + subscribe)。所有编辑 = Command(apply/invert 都不可变,返回新 EditorState);模式不得直接 mutate 数据,一律发 Command。React 经 subscribe + useSyncExternalStore 订阅(B1 接)。
- `vite.config.ts` —— `react()` 插件 + `serveDir` 中间件(`/projects`、`/extracted` → 仓库根;抄 reforge/vite.config.ts,含去前导斜杠修复,跨平台零 symlink)。
- `index.html` —— React root 挂载点。

依赖边界(package.json 显式声明):依赖 workspace 内 @type-pal/content + @type-pal/reforge,**不碰** game / pal-extract;shared 只经 reforge 间接、只用冻结解码类型(接受的 D18 债)。tsconfig 加了 DOM/DOM.Iterable lib + react-jsx。

后续演进(B1+,尚未实现):画布视口(平移/缩放 + 复用 renderSceneFrame 画底图 + 编辑器叠加层)、布置模式(选中/拖动/增删实体 + 改进场点)、Inspector 面板、File System Access 保存、校验面板 UI。设计见 docs/phase2/editor/editor-design.md。
