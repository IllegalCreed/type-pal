- 所有持久化/工程数据接口都包含稳定字符串 id 字段，且 validate.* 中对 id 做显式 typeof 检查并抛错。
- 运行时校验函数采用「assertArray/assertObject + requireKeys」组合，缺键时抛出含上下文路径的错误消息（如 `scenes[${i}]: 缺键 "id"`）。
- 领域类型按单一职责拆分到独立文件，再由 index.ts 统一 re-export，避免跨目录循环引用。
- 面向未来的可扩展点用可选字段 + 空数组/空记录默认值表达（如 tags: string[]、equipment: Record<string,string>），而非单独扩展接口。
