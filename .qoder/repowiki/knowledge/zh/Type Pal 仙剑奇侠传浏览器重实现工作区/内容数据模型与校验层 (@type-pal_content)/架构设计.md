模块以 `src/index.ts` 为统一入口，集中导出场景/实体/对话/网格/角色/物品/技能/精灵/本地化等核心类型；每个领域拆分为独立文件（character.ts、grid.ts、item.ts、locale.ts、rich-text.ts、skill.ts、sprite.ts），由 index 聚合再向外暴露。

- 依赖方向单向：上层 reforge/editor → content；content 内部仅通过相对路径互相引用，无外部运行时依赖。
- grid.ts 提供 D16 菱形坐标到像素的纯数学换算（`gridToPixel`、`pixelToGrid`、`spriteScreenY`），作为渲染地基被多子系统复用。
- character.ts 区分 L2 模板（CharacterTemplate）与 L1 运行态实例（CharacterInstance），并通过 `instantiate` / `buildWorld` 把 manifest.startWorld 组装成初始 WorldState。
- rich-text.ts 解析 locale 中的 `<color>` 标记为 TextSpan[]，是 DialogueLine.text 的中间表示。
- sprite.ts 定义精灵注册表项 `SpriteDef { id, spriteNum, label }`：`EntityDef.sprite` 引用其语义 id，reforge 据此解析到原版精灵号（去掉引擎硬编码）。
- validate.ts 充当 zod 的轻量替身：对 loader 加载的工程 JSON 做「数组/对象 + 必需键 + id 是 string」的守卫式校验（含 `validateScenes`/`validateCharacters`/`validateSkills`/`validateItems`/`validateSprites`/`validateLocale`），注释明确未来可局部替换为 zod schema 而保持签名不变。
- validate-refs.ts 提供 `validateReferences(bundle): Issue[]` 跨引用完整性校验（entity.sprite→sprites、interact→dialogues、text/speaker→locale、startWorld.party→characters、equipableBy/grantSkill/levelUp→skills/items 等）；系统未落地字段（poisonId/triggerScript.scriptId/teleport.target）跳过。编辑器加载/编辑时跑，结果进校验面板。
- 测试文件与源文件同名并列（*.test.ts），配合 package.json 中 vitest 脚本运行。
