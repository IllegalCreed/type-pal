根目录作为多包工作区编排层，通过 `pnpm-workspace.yaml` 声明 `packages/*` 子包，并在顶层 `package.json` 提供跨包脚本（`check/typecheck/test/lint/format` 经 `pnpm -r run` 分发，`extract/bake` 经 `--filter` 定向到 `@type-pal/pal-extract` / `@type-pal/migrate`）。

数据管线自上而下串联：`pal_extract` 从 `data/raw/` 的原始 MKF/RPG 二进制反汇编出 `data/extracted/`（JSON 数据表 + PNG 瓦片/精灵 + 事件字节码），`migrate` 将其烘焙为 RGBA 真彩资产并产出 `content_schema` 实例；`shared_lib` 被各包共同依赖，提供 MKF/YJ2/RLE 解码器、事件命令枚举与帧率常量等跨包契约；`game`（第一阶段）与 `reforge`（第二阶段）消费同一份 `shared_lib` 类型，前者直接加载 `data/extracted`，后者配合 `editor` 与 `demo_project` 走第二阶段内容工程流程。

`reference/sdlpal/` 作为只读参考源码，`CLAUDE.md` 强制区分「第一阶段·忠实还原」与「第二阶段·Reforge 重写」两套世界观，禁止混用；`sdlpal.cfg` 与 `tsconfig.base.json`、`biome.json` 统一构建与代码风格约束。
