模块由三个职责分明的文件组成，构成「加载 → 解码 → 渲染」单向依赖链：
- `assets.ts`：纯函数式资源层，通过 `AssetBase` 根路径 + manifest 子目录拼接 URL，用 `fetch` 拉取 JSON(tilemap/palette)与 gzip RLE(sprite/tileset)，再经 `decompressGzip`(基于浏览器原生 `DecompressionStream`)和 `@type-pal/shared` 的 `parseSpriteChunk` 解码为 `RleFrame[]`；对外暴露 `loadTilemap/loadPalette/loadTileset/loadSprite/loadGlyphs`。
- `render.ts`：定义 `Renderer` 接口与 `Canvas2DRenderer` 实现，封装 tile 帧烘焙(`bakeFrame`)、双层瓦片铺底(layer0→layer1)、按 baseY 深度排序的精灵+cover-tile 遮挡算法（端口自 sdlpal `PAL_CalcCoverTiles`），并通过 `frameCache`(WeakMap) 与 `tileCache`(Map) 缓存已着色 canvas。
- `main.ts`：浏览器应用入口，读取 `VITE_PROJECT_ID` 与 URL 参数(`?pal`, `?collision`, `?gallery`)，并行 `Promise.all` 加载 tilemap/tileset/palette/glyphs/cursor/portraits，构造 `Canvas2DRenderer`、`DialogBox`、`MenuBox` 及各类菜单状态机，以 `requestAnimationFrame` 驱动 tick/render 循环，并在 `window.__reforge` 上挂调试句柄。
依赖方向严格自上而下：`main.ts` 组合 `assets.ts` 与 `render.ts`，二者互不引用；渲染逻辑被抽到 `render-scene.ts` 供编辑器复用。
