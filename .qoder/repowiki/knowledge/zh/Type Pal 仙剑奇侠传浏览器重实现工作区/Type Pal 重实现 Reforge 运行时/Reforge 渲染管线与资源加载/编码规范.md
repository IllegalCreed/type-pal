- 资源加载统一走 `fetchJson<T>(url)` 包装器，失败时抛错并携带 URL 与 HTTP 状态码，便于定位缺失资源。
- 可选资源(光标、头像)采用 `.catch(err => { console.warn(...); return 降级值 })` 模式，保证主流程不因非关键资源失败而崩溃。
- 所有 UI 绘制在 320×200 逻辑坐标系内完成，再通过 `ctx.save()/ctx.scale(WORLD_SCALE, WORLD_SCALE)/ctx.restore()` 放大，且关闭 `imageSmoothingEnabled` 保持点阵锐利。
- 世界坐标到屏幕坐标转换使用 `gridToPixel` / `spriteScreenY` 等共享工具，精灵绘制统一传入 `anchorX/anchorY` 脚锚点而非左上角。
