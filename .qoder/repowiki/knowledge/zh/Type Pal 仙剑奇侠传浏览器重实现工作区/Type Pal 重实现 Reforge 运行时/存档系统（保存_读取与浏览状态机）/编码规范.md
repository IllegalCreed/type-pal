- 对外暴露的持久化对象（SaveMeta/SavePayload）在内存实现中一律通过 structuredClone 返回，防止调用方原地修改污染内部缓存。
- 存档格式版本与工程内容版本解耦：SavePayload.version 固定为 SAVE_VERSION 驱动迁移，contentVersion 由上层传入反映 @type-pal/content 变更。
- 槽位布局采用“固定序”常量 ALL_SLOT_IDS 驱动 UI 与逻辑，slotKind 函数统一判定 auto/quick/manual，禁止硬编码字符串分支。
- 浏览器存档界面采用纯函数状态机模式：每个输入产生新的 state 对象（浅展开），I/O 动作以 action 字段外泄，由上层消费后回调 putSlot/getPayload。
