模块按职责拆分为四层：
- `types.ts`：定义 SlotId/SlotKind 枚举常量（auto/quick/m01..m28，共30槽、每页3格→10页）、SaveMeta（浏览用轻量快照）与 SavePayload（含 version/contentVersion/projectId/world/position 的全量还原结构），是跨层契约。
- `ops.ts`：纯函数工厂——`buildMeta` 通过注入的 `nameOf` 解析角色名生成预览；`buildPayload` 打包全量存档；`captureThumbnail` 使用离屏 Canvas + toBlob 生成 PNG 缩略图 Blob。
- `store.ts`：以 `SaveStore` 接口抽象存储后端，提供 `MemorySaveStore`（测试/降级，基于 Map + structuredClone 防外部突变）和 `IndexedDbSaveStore`（浏览器端，DB `type-pal-saves` v1，三个 objectStore `meta/payload/thumb` 共享同一事务保证原子写入，IDB 原生结构化克隆无需 JSON 序列化）。
- `browser-state.ts`：无副作用的状态机，维护 `SaveBrowserState`（active/mode/cursor/metas/confirmOverwrite），通过 `openSaveBrowser` 初始化、`browserMoveCursor` 导航（↑↓±1、←→整页、clamp 不 wrap）、`browserConfirm` 决策（save 时空手动槽→write、已存手动槽→覆盖确认、auto/quick 不可写；load 时仅已存槽可读），输出 `{state, action?}` 供上层执行 I/O。
依赖方向：`browser-state` → `types`；`ops` → `types`；`store` 独立实现 `SaveStore`；上层组合 ops/store/browser-state，避免循环依赖。
