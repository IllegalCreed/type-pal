模块按职责拆为三个文件，依赖方向单向：slot.ts → layout.ts → dialog-box.ts。
- slot.ts：纯函数状态机，维护 top/bottom 两个 SlotEntry（各自 lineIdx）及 activeSlot，语义为“同槽覆盖、异槽共存”，不接触渲染。
- layout.ts：纯函数排版器，把 DialogueLine[] 经 resolveText + parseRichText 展开为字符流，按 GlyphTable 宽度逐字累加并在 maxRight - startX 处换行，输出扁平 DisplayLine[]；与 DOM/Canvas 解耦。
- dialog-box.ts：唯一对外类，持有 CanvasRenderingContext2D、GlyphTable、RLE 光标帧、头像图与 Locale，组合 slot 推进与 layout 结果，实现两段式 fUserSkip（先瞬显整页再翻页）、autoAdvance 尾停顿不可加速、每页 LINES_PER_PAGE=4 的行级分页，以及活跃槽末行光标绘制与 baked 缓存。
- dialog-assets.ts：提供 bakeCursorTinted 等光标着色工具，被 dialog-box.ts 消费。
边界：本模块只消费 @type-pal/content 的 DialogueLine/TextSpan/GlyphTable 与 ../text/* 的测量/渲染原语，不反向依赖上层引擎。
