reforge 是各子模块的装配层：main.ts 在启动时按顺序完成（1）工程加载 loadProject → （2）并发异步加载 tilemap/tileset/palette/glyphs/cursor/portraits/menu assets → （3）构造 Canvas2DRenderer + DialogBox + MenuBox + 各状态机（menu/magic/equip/use/system/saveBrowser），再进入 requestAnimationFrame 循环。

- 渲染分层由 render() 统一编排：底层调用 renderSceneFrame 画场景底图+精灵（Y 深度排序），随后在同样 320×200 逻辑坐标下 ×WORLD_SCALE=4 放大绘制 dialogBox 和 menu 层，所有 UI 共享同一套 GLM 字模与 palette。
- 输入分发遵循三态互斥优先级：menu.active > dialogBox.active > 探索；键盘经 Keyboard.consumePressed 缓冲后按当前态路由到对应 state-machine 函数，状态机返回新状态并回写 world。
- 存档系统通过 SaveStore 接口（IndexedDbSaveStore / MemorySaveStore 降级）与 browser-state 纯函数状态机解耦，缩略图用 ImageBitmap 缓存避免重复解码。
- index.ts 作为 barrel 仅向 editor 暴露渲染器/资产加载/碰撞/场景帧绘制，dialog/menu/save/input 等游戏 shell 专属模块不导出，形成“编辑器复用 vs 游戏运行”双边界。
