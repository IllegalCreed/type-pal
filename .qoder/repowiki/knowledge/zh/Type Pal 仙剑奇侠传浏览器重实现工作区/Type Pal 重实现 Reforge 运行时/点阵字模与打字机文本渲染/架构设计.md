模块按职责拆为四个独立文件,依赖方向单向:typewriter → text-render → glyph/palette-color。
- `glyph.ts`:定义 `Glyph`/`GlyphTable` 接口,提供纯函数 `decodeGlyph`(MSB-first 位图→RGBA)供单测,以及浏览器端 `loadGlyphs`(fetch glyphs.json)+`bakeGlyph`(离屏 canvas + Map 缓存 cp:rgba 键)。
- `palette-color.ts`:固化原版 palette 的 UI RGBA 快照(`DIALOG_RGBA`、`TITLE_RGBA`、`CURSOR_RGBA`),通过 `DialogColor` 枚举映射,不再绑定场景调色板。(注:这些常量虽以 `_RGBA` 命名,实际类型是 `readonly [number,number,number]` 三元组 —— 即 RGB 无 alpha 通道,命名名不副实,沿用至今未改。)
- `text-render.ts`:组合层,`renderSpans` 遍历 TextSpan 逐字符 bake+drawImage,按 SDLpal 约定叠加 (+1,0)/(0,+1)/(+1,+1) 黑阴影;`measureSpans` 仅计算宽度用于布局。
- `typewriter.ts`:纯时间函数 (`charsShown`/`isLineDone`/`countChars`),不挂 tick,由上层用 `performance.now` 驱动进度并传入 `maxChars`。
