模块按「共享原语 + 各面板独立文件」分层:
- `menu-box.ts` 是核心原语库:九宫格框 `drawSlicedBox`(frame-00..08 平铺+阴影)、单行卷轴 `drawScroll`、确认框 `drawConfirmBox`、数字绘制 `drawNumber/drawNumberLeft`,以及集中式资源加载器 `loadMenuAssets` 产出 `MenuAssets`(黄框/红框/卷轴/itembox/数字 sprite/头像/光标等)。所有坐标以 320×200 逻辑坐标书写,调用方已设 `ctx.scale(WORLD_SCALE=4)`。
- 各面板文件(`equip-box.ts`、`use-box.ts`、`magic-box.ts`、`system-box.ts`、`save-browser-box.ts`)各自导出一个顶层 draw 函数,接收 `(ctx, state, world, assets, glyphs, now, locale?, items?)`,内部用常量声明布局真值并组合上述原语。
- `item-list.ts` 抽离出「红框 3 列网格 + itembox 详情」这一跨面板复用的物品列表组件,被 equip/use/magic 共同复用。
- 依赖方向单向:面板 → `menu-box`(原语) + `text/text-render`(renderSpans/measureSpans) + `@type-pal/content`(数据/文本),不反向依赖;每个面板仅依赖自身对应的 `*-menu-state.js` 类型。
