- 布局常量以 `const X = N` 形式在文件顶部集中声明,并在注释中注明对应 sdlpal/uigame.c 源码位置作为真值来源。
- 颜色统一采用 `[R,G,B] as const` 元组,命名遵循 `COLOR_NORMAL / COLOR_DISABLED / COLOR_DISABLED_SEL / SELECTED_COLORS`(6 帧闪烁数组)模式,避免硬编码 RGB。
- 选中项高亮一律取 `SELECTED_COLORS[Math.floor(now / 100) % SELECTED_COLORS.length]`,以 100ms 步进实现原版 6 色炫彩闪烁。
- 文本渲染走 `renderSpans(ctx, [{ text: lookupText(id, locale) }], x, y, { glyphs, shadow, forceRgba })` 三件套,禁用阴影时显式传 `shadow: false`。
- 九宫格框一律通过 `assets.box/redBox/scroll/itembox` 的 `{ tiles }` 传入,由 `drawSlicedBox` 按 frame-00..08 索引 i*3+j 定位,禁止直接 `drawImage` 拼边框。
- 数字显示优先用 `drawNumber/drawNumberLeft` 配合 `assets.nums(黄)/numsBlue(蓝)/numsCyan(青)` sprite,右对齐固定字段宽度,左对齐紧跟斜杠。
