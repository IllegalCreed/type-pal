- 碰撞判定采用「纯函数 + 注入回调」模式：`resolveMove` 只读 `pos`/`intent`，是否阻挡通过外部传入的 `IsBlocked` 决定，使移动逻辑可独立单测。
- 移动意图使用 MoveIntent 的 dcol/drow ∈ {-1,0,1} 表示菱形轴步进，禁止对角移动，保持单轴一步语义。
- 对旧引擎数据格式的兼容通过「像素层 + GridPos 适配层」双入口实现：底层 `pixelToTile` 保留原行为，上层 `isBlockedAt`/`sameGrid` 作为新代码唯一入口。
- 输入状态分离为 held（持续）与 pressed（边沿），并通过 `consumePressed()` 消费后清空，避免同一帧重复触发。
