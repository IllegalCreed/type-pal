模块由三个职责正交的单文件组成，依赖方向单向：input → movement → collision。
- `input.ts` 暴露 `Keyboard` 类，维护 `held`/`pressed` 两个 Set，在构造时向目标 Window 注册 keydown/keyup 监听；`consumePressed()` 每次返回快照并清空，实现「自上次起新按下」的边沿语义，同时阻止浏览器默认滚动与 F5/F9 刷新。
- `movement.ts` 是纯函数层：接收 `GridPos` + `MoveIntent`（dcol/drow ∈ {-1,0,1}）+ 注入的 `IsBlocked` 回调，按菱形轴单步计算 next，被挡则原地停，不碰 DOM、可独立单测。
- `collision.ts` 封装 SDL-PAK 旧引擎的「菱形四分法」像素→(col,row,h) 映射与 tile bit 13 (0x2000) 障碍位检测，导出 `buildIsBlocked(map)` 供 `resolveMove` 注入；同时提供 `sameTile` / `isBlockedAt` / `sameGrid` 等 GridPos 入口，内部复用 pixelToTile 以兼容 data/extracted 旧 Tilemap，注释明确迁移到新格式后该层将退役。
- 边界约定：`height` 在移动中保持不变（地面行走恒 0），实体碰撞通过 `sameGrid` 比较 col/row，h 不参与逻辑层判定。
