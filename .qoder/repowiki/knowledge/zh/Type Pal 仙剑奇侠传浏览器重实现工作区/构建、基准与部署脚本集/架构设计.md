本模块是纯 shell 工具集合，按职责拆分为三类：
- 构建类：`build-sdlpal.sh`（标准 sdlpal）与 `build-sdlpal-classic.sh`（PAL_CLASSIC + headless harness），均遵循 copy-reference → patch → gmake 的幂等模式，产物分别落在 `build/sdlpal/unix/sdlpal` 和 `build/sdlpal-classic/unix/sdlpal`。
- 基准提取类：`extract-battle-baseline.sh` 遍历 `build/sdlpal-baseline/battles/fixtures/*.kv` 调用 battle harness 生成 JSON；`extract-tilemap-baseline.sh` 对固定 mapNum 列表 dump PNG；`run-sdlpal-baseline.sh` 写临时 cfg 启动 GUI 截图，三者共享 `sdlpal-classic` 二进制与 `data/raw/` 资源。
- 部署类：`deploy.sh` 实现 app/data/all 三目标，app 走 tar+scp+原子 mv 切换 dist.new/dist.old，data 用 rsync --delete 增量同步 `data/extracted` 至 `/var/www/type-pal/extracted` 并通过 aliyun CLI 刷新 CDN；nginx 配置由 `nginx-type-pal.conf` 提供。
依赖方向单向：脚本只读 `reference/sdlpal`、`data/raw`、`packages/game`，写入 `build/` 与远端服务器，不反向依赖项目源码。
