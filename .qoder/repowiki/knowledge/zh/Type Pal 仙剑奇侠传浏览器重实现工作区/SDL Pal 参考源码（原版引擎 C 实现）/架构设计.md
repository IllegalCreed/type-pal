目录 `reference/sdlpal/` 是上游项目 sdlpal 的只读快照，按“核心逻辑 + 平台适配”两层组织：
- 顶层 C 源文件（main.c、game.c、play.c、scene.c、map.c、battle.c、fight.c、script.c、res.c、audio.c、video.c、input.c、ui.c 等）构成游戏核心子系统，通过全局结构体 `gConfig`、`gpGlobals` 以及 `PAL_*` 前缀函数互相通信；入口在 `main.c`，依次调用 `PAL_Init()` → `PAL_TrademarkScreen()` → `PAL_SplashScreen()` → `PAL_GameMain()`。
- 各平台适配层位于子目录 `win32/`、`unix/`、`macos/`、`ios/`、`android/`、`emscripten/`、`wii/`、`3ds/`、`winrt/`、`libretro/`，每个目录提供独立的 `Makefile`/CMakeLists/Android.mk/Xcode project 以及 `pal_config.h`，通过条件编译接入同一套核心代码。
- 音频后端采用多实现策略：`adplug/`（OPL/RIX）、`libmad/`（MP3）、`liboggvorbis/`（OGG/Vorbis）、`libopusfile/`（Opus）、`timidity/`（MIDI），由 `midi.c`、`rixplay.cpp`、`mp3play.c`、`oggplay.c`、`opusplay.c` 等统一封装为 `AUDIO_PlayMusic` 接口。
- 资源加载集中在 `res.c`，依赖 `yj1.c` 解压 YJ1 包，配合 `MKF` 归档格式读取位图、精灵、脚本等资源。
- 测试用例位于 `tests/`，使用自定义 `test_main.cpp` 驱动；补丁集 `patches/` 提供 headless 战斗/地图导出等开发辅助 patch。
- 本仓库仅将其作为“规格参考”，不纳入构建系统，更新方式为 `git clone --depth 1` 后删除 `.git`。
