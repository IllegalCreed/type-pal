- 所有对外 API 使用全大写 `PAL_` 前缀命名（如 `PAL_Init`、`PAL_FreeResources`、`PAL_ProcessEvent`），内部静态函数则用小写加下划线。
- 错误处理统一通过返回非零错误码并在调用方用 `TerminateOnError(...)` 打印日志后退出，而非抛出异常。
- 平台差异通过 `#if defined(__WIN32__) / __EMSCRIPTEN__ / __IOS__ / __N3DS__` 等宏在单份核心代码中条件编译，平台特定实现放在对应 `*/pal_config.h` 和 `native_midi*.c` 中。
- 内存分配一律走 `UTIL_calloc`/`UTIL_malloc` 等包装函数，避免直接调用标准库 `malloc/free`，便于调试与跨平台替换。
- 字符串格式化使用自实现的 `UTIL_va` 替代 `sprintf`，并通过 `PAL_GLOBAL_BUFFER_SIZE` 控制全局缓冲区大小。
