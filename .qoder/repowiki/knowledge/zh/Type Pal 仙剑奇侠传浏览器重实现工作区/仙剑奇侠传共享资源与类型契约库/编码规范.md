- 数据模型 interface 的每个字段都附带注释说明其对应的 sdlpal C 结构体成员、字节偏移或数据来源(MKF chunk / DATA.MKF chunk 编号),确保与 Win9x 原版 1:1 对齐。
- 对可能越界的 buffer 读取一律使用 `buf[offset++]!` 非空断言,并在注释中以 `biome-ignore lint/style/noNonNullAssertion` 声明理由,因为结构体布局已保证边界。
- 对外暴露的公共 API 保持纯函数形式,不持有可变状态;需要累积状态的场景(如 rngBlitDelta)通过显式传入 mutable surface 参数,调用方负责生命周期管理。
- 错误处理采用抛出 Error 字符串的形式,包含具体上下文信息(如 chunk 下标、ptr 位置、未知 opcode 值),便于快速定位反序列化问题。
- 数值型枚举全部拆成具名字段或字面量联合类型(如 `ItemFlags`、`SpellFlags`、`MagicType`、`AbstractKey`),避免裸 number 魔法值,并在注释中列出 sdlpal 原始宏定义。
