本模块是纯 TypeScript 类型 + 纯函数库,无运行时副作用,通过 `src/index.ts` 统一 re-export 所有子模块供其他包消费。

内部按职责切分为相互独立的文件,依赖方向单向:最底层格式解析(`mkf.ts` → `yj2.ts`)→ 上层复合解码(`rng.ts` 组合 mkf/yj2/rle)→ 领域数据模型(`events.ts`/`resources.ts`/`tables.ts`/`input.ts`)→ 顶层聚合导出(`index.ts`)。`rle.ts` 同时被 `rng.ts` 和外部 game 包引用,作为精灵 RLE 解码的唯一实现,避免分叉。

- `mkf.ts`:只读 MKF 归档头解析,返回 `{buffer, offsets}` 视图对象,不持有状态。
- `yj2.ts`:1:1 port 自 sdlpal `yj1.c::YJ2_Decompress`,含自适应 Huffman 树与 LZSS 回引,仅暴露 `decompressYj2`。
- `rle.ts`:RLE 精灵帧解码 + sprite chunk 解析,带 400px 维度安全守卫,供 extractor 与 runtime 共用。
- `rng.ts`:组合 mkf/yj2/rle 解 RNG 动画(sub-MKF → YJ2 → RLE delta blit),维护 320×200 surface 增量累积。
- `events.ts`/`resources.ts`/`tables.ts`/`input.ts`:定义 JSON 数据文件的 TypeScript interface,字段名与 sdlpal `global.h` 一一对应,注释标注 C 源码行号与字节布局。
- `index.ts`:除 re-export 外还集中定义 FPS/FRAME_MS 等全局时间常量,并附详细设计注释解释 fade 60fps 采样原因。

每个源文件均有同名 `.test.ts` 单元测试,通过 vitest 运行;包本身标记 `private:true`,仅作为 workspace 内 monorepo 依赖使用。
