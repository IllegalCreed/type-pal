- 每个绘制函数以 `drawXxx(fb, ...)` 形式暴露,参数首参固定为 `Framebuffer`,禁止直接访问 Canvas API,保证可单元测试。
- 对外资源(精灵表、背景 FBP、物品图标、毒表等)统一通过可选字段注入 `PresentContext` / `BattleAssets`,draw 函数对缺失资源走防御性空实现而非抛错。
- 战斗与大世界共用 `applyScreenWave`/`applyScreenShake`/`stepPaletteFade`/`applyDitherSteps` 等纯函数特效,通过 `advanceEffects` 布尔在 fade-only 补帧时跳过计数器推进。
- 菜单渲染采用 `switch(entry.kind)` 分派到独立 `draw-*-menu.ts` 文件的模式,新增菜单类型只需加 case 和对应文件,不改动分发器签名。
- 所有坐标/颜色常量以注释标注 sdlpal 源行号(如 `scene.c:750-755`、`text.c:1408-1426`),便于对照原版修正视觉差异。
