- 所有对外部环境的副作用(用户手势、DOM、navigator、window)都先判 `typeof window !== 'undefined'` 再执行,保证测试/SSR 可单测纯逻辑路径。
- 对可能失败的外部 IO(fetch/soundfont/glyphs)一律 `.catch(console.warn)` 降级继续运行,不阻断主流程,仅留告警。
- 通过 `setXxxHandler` 全局 setter 向 core(event-system/menu-driver/scene-system)注入回调,而非在构造时传参,保持 shell 与 core 的双向解耦。
- 模态播放(AVI/FBP/RNG/ending)统一设置 `gs.suspendRaf = true` 独占 canvas,播完 `finally` 中恢复,主循环据此跳过 present 避免重绘闪烁。
- 音频相关函数(`sfxUrl`/`musicUrl`/`pickMusicTrack`/`battleVictoryTrack`/`sfxForBattleEvent`)写成纯函数,由 `syncShellAudio` 在 onPresent 中消费 GameState 状态驱动。
