模块以 `main.ts` 为唯一入口,按环境分支 PROD/dev/e2e 装配 shell 层能力,再调用 `bootstrap.ts` 的 `bootstrap()` 完成核心初始化。

- 启动编排 (`main.ts`):检测 `import.meta.env.PROD` 与 `serviceWorker`,PROD 下用 `precache-client` + `precache-ui` 注册 SW 并挂两段进度(必要资源→虚线,SW 全量→实线),通过 `enterGate` Promise 实现「进入游戏」按钮与自动放行的竞态守卫;dev/e2e 直接 `initBootLoading` + `releaseGate` 无门直进。
- 引导器 (`bootstrap.ts`):并行拉取 soundfont / glyphs / dialog assets 与 `loadAll(SCENE_ID)`,组装 `PresentContext`、`BattleAssets`、`SceneAssetsCache`(LRU=16,protect=currentSceneId)、`CommandBus`、`KeyboardInputSource`、`AudioManager`(注入 SpessaSynth MIDI 后端),注册 `setSceneLoader`/`setMapReloader`/`setObstacleChecker` 等 core 回调,定义 `onPresent` 驱动帧渲染并在 `gs.suspendRaf` 期间让路给 AVI/FBP/RNG/ending 等 modal 播放器,同时根据 `suspendRaf` 暂停/恢复 SW 预缓存避免抢带宽。
- 主循环 (`main-loop.ts`):rAF 累积器按 `gs.mode` 在 battle(40ms)/explore(100ms) 间切换,每 rAF 至多 1 tick(忠实 sdlpal `DelayUntil` 不补帧),fade/battleAnim 期仍 present 做 wall-clock 细分;
- 子系统: `audio.ts`(SFX WAV + BGM OGG/MIDI 后端抽象 `MusicBackend` + `AudioManager`)、`audio-midi.ts`(SpessaSynth Web Audio Worklet 合成)、`input.ts`(键盘→AbstractKey 映射,含 Replay/Recording 源)、`avi-player.ts`/`fbp-player.ts`/`rng-player.ts`/`ending-player.ts`(modal 播放器,写 fb 后 flushToCanvas)、`boot-loading.ts`/`fetch-retry.ts`/`splash-fallback.ts`/`trademark-fallback.ts`/`audio-volume.ts` 等辅助。

依赖方向:`main.ts` → bootstrap → main-loop/audio/input/present/core;shell 各子模块只依赖 `../core/*` 与 `@type-pal/shared`,彼此之间通过函数参数或全局 setter(`setSceneLoader` 等)解耦,无循环引用。
