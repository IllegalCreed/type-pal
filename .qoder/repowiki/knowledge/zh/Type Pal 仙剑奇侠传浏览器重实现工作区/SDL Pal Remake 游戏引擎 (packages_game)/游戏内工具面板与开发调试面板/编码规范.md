- 每个功能文件都配同名 `.test.ts` 单测,形成 `xxx.ts` / `xxx.test.ts` 一一对应的目录布局。
- DOM 构建一律使用 `document.createElement` + `textContent` + 类名,禁止 `innerHTML`,由注释明确声明安全约束。
- 样式集中通过 `injectXxxStyles()` 幂等注入到 `<head>`,以固定 `id` 的 `<style>` 节点防重复插入。
- 对外暴露的装配函数(`setupToolsPanel` / `setupDevPanel` / `setupMinimap` / `setupSpeedrunHotkeys`)统一接收一个 `*Deps` 接口对象,把外部副作用(读取 GameState、写入存档、渲染缩略图)反转注入。
- 速通计时器采用单例模式(`getTimer()` 懒创建 + `__resetSpeedrunForTest` 供测试重置),主循环通过 `tickSpeedrunTimer(gs, nowMs)` 每帧推进。
