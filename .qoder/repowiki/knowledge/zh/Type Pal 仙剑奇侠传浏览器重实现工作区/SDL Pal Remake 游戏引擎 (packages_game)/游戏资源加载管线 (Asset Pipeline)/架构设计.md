模块以 `loader.ts` 为唯一对外入口,提供 `loadAll(sceneId)` 一次性聚合加载与 `SceneAssetsCache` LRU 场景级懒缓存;内部按资源域拆分为独立子模块:
- `png.ts`:基于 `createImageBitmap` + Canvas2D 把 pal-extract 输出的 RGBA 索引 PNG 转成 `{indices, opaque}` 的 `IndexedImage`,是除 RLE blob 外所有位图资源的共同解码器。
- `tileset-blob.ts`:通用 gzip sprite/RLE blob 管线——fetch → `DecompressionStream('gzip')` 解压 → `parseSpriteChunk`(来自 `@type-pal/shared`)→ `Map<tileIndex, IndexedImage>` 或帧数组,被 tileset/npc/battle/magic 四路复用。
- `rle-decode.ts`:仅 re-export shared 的 `decodeRle`/`parseSpriteChunk` 并提供浏览器端 `base64ToBytes` 工具。
- `dialog-assets.ts`:对话头像(RGM.MKF chunk 已预 decode 为 PNG)与 DATA.MKF chunk 12 图标(base64+sprite group)的专用加载器。
依赖方向单向:loader → png/tileset-blob/dialog-assets → rle-decode → @type-pal/shared;本模块不反向依赖 present/gameplay,仅通过类型 import 暴露 `LoadedAssets` 给上层 bootstrap/present 使用。
