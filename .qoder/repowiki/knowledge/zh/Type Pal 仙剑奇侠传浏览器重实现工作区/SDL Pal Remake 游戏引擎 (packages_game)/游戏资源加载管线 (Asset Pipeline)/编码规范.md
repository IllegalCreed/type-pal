- 外部资源 URL 统一以常量 `BASE = '/extracted'` 拼接,避免硬编码路径散落各处。
- 可选资源加载采用 try/catch + `console.warn` 降级返回空集合的模式,保证单个资源缺失不阻断整体启动。
- 并发加载一律用 `Promise.all([...].map(async ...))` 并行 fetch,失败项各自 `.catch` 吞错,外层再汇总。
- 位图数据统一封装为 `{width, height, indices: Uint8Array, opaque: Uint8Array}` 的 `IndexedImage` 接口,由 PNG 解码与 RLE 帧转换两处产出。
- Map 键严格遵循 sdlpal 原始 chunk index 或 parseSpriteChunk 返回下标,注释中显式声明「键一致性铁律」以保证与旧 loader 同构。
