本包以 src/main.ts 为唯一入口，按职责划分为五个子模块并通过共享的 GameState/BattleState 与 LoadedAssets 契约协作：
- shell_orchestration 负责浏览器生命周期（SW 预缓存、两段进度条、可玩门）、资源加载、主循环与输入/音频/视频播放，并在 bootstrap.ts 中组装 core_engine。
- core_engine 以 GameState 为单一事实源，通过 command-bus 与 event-system 驱动 battle/menu/save/scene 等子系统，不依赖任何渲染 API。
- presentation_layer 消费 core 的状态与 asset_pipeline 产出的 LoadedAssets，把 320×200 8-bit 帧缓冲绘制到 Canvas。
- asset_pipeline 从 /extracted 目录并发拉取 tilemap/sprite/dialog 等二进制资源，解码后注入 LoadedAssets，被 present 与 shell 共同消费。
- dev_tools 在运行期以浮层 UI 形式挂载到同一 Canvas 上，面向玩家提供工具面板，面向开发者提供仅 DEV 构建的 Dev Panel。
跨层约束：core 禁止引用 present/shell；present 只读 core 状态；asset_pipeline 输出纯数据；dev_tools 通过 vite 条件编译开关与 runtime flag 控制是否启用。
