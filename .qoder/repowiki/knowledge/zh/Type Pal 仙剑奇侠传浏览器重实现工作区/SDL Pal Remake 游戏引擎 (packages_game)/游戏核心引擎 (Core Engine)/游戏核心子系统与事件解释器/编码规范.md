- opcode 常量以 `OP_` 前缀 + 十六进制值 + 中文注释标注 sdlpal script.c 行号,形成「常量 = 真值」的对照表风格。
- 对外部系统(战斗、商店菜单、RNG/FBP 播放、存档、quit)一律用 `let _handler: Fn | null` + `setXxxHandler(fn)` 注入式回调,保持 core 不直接 import 上层模块。
- 全局单例数据(词表、全局脚本数组/labelMap、store 表、毒 OBJECT 表、敌人 OBJECT 表)通过 `setXxx(...)` 在 bootstrap 启动时注入,测试中传 null 重置。
- fade 相关 API 拆为「构造器(纯函数产出 state) + step/finalize(每帧应用)」两阶段,调用方负责把 state 挂到 `gs.paletteFadeState` 并管理 waiting。
- effective stat 统一走「base PlayerRolesRuntime + Σ rgEquipmentEffect[part]」叠加模型,getter 遍历 0..MAX_PLAYER_EQUIPMENTS 累加,mutator 对应清零。
- 每个公开函数顶部 JSDoc 注释写明 sdlpal 源码位置(global.c/script.c/palette.c)与行为差异,作为 port 溯源依据。
