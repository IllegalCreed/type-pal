模块按职责拆分为多个独立文件,通过 `GameState` 作为单一真相源串联:
- `command-bus.ts`:Core→Present 单向命令通道,定义 `PresentCommand` 联合类型(对话/战斗 UI/SFX/BGM),`createCommandBus()` 以 `emit/drain/complete` 三方法实现 tick 内同步 emit、tick 末 Present drain 的 M2 语义。
- `event-system.ts`:SDL-PAL 事件脚本解释器,集中声明所有 opcode 常量(`OP_START_BATTLE`…`OP_QUIT`)并实现 `tickEventSystem` 主循环;通过 `setXxxHandler` 注入式回调(战斗、商店菜单、RNG/FBP 播放、存档加载、quit)解耦高层依赖,避免反向 import 环。
- `game-state.ts`:导出 `GameState` 接口及其子状态(`EventCursor`/`DialogBoxState`/`NpcState`/`PlayerRolesRuntime` 等),字段注释逐条标注 sdlpal global.h 行号,是存档序列化唯一来源。
- `palette-fade.ts`:纯函数 fade 引擎,构造器(`buildFadeOut`/`buildFadeIn`/`buildSceneFade`/`buildColorFade`/`buildFadeToRed`)产出 `PaletteFadeState`,由 `stepPaletteFade`/`finalizePaletteFade` 每帧应用,与 dither 引擎正交。
- `equip-effect.ts`:6 个 effective stat getter + `updateAllEquipments`/`removeEquipmentEffect` mutator + 同步 scriptOnEquip runner(`runEquipScriptSync`),暴露 `PLAYERROLES_ROW` 映射供 event-system 0x17/0x19/0x1A 使用。
- `rng.ts`:mulberry32 可播种 PRNG(`createSeedableRng`),保证战斗对拍确定性。
- `word-lookup.ts`/`dialog-history.ts`:单例词表注入(`setWordTable`)与环形历史追加(`pushDialogHistory`)。
- `inspect/battle-inspect.ts`:从 dev-panel 抽出的只读快照收集器(`collectPartyStatusReadouts`/`collectEnemyStatusReadouts`/`collectFieldInfoReadout`),无开发门控,生产工具面板复用。
依赖方向:core 文件之间仅单向引用(`event-system → equip-effect / palette-fade / word-lookup / dialog-history`;`equip-effect → event-system`(回引 runPlayerPoisonEntrySync);`inspect → equip-effect + game-state`),不反向依赖 present/battle/menu 层。
