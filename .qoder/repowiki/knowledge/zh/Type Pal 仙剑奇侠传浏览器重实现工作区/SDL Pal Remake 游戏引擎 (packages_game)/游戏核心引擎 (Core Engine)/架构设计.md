本模块是 sdlpal 重实现的核心运行时，按职责拆分为四个子包，围绕共享的 `GameState` 与 `CommandBus` 协作：
- `shared_core`（顶层文件 + inspect）提供全局状态、事件脚本解释器、调色板淡入淡出、可播种 RNG、词表查询、装备效果计算与调试快照，是所有子系统的共同依赖。
- `battle/` 在战斗模式下消费 `GameState`，由 `BattleState` 作为单一事实源组织回合队列、动作执行、敌方 AI、伤害公式与动画时间线，并通过 `battle-opcodes.ts` 暴露给事件脚本。
- `menu/` 在非战斗模式接管输入，以 `menuStack` 驱动多栈式子菜单，最终将玩家选择转化为对 `GameState` 的修改或命令总线调用。
- `save/` 独立于运行模式，通过 `api.ts` 统一接口读写 IndexedDB（无 IDB 时回退内存 Map），序列化/反序列化的根对象即 `GameState`。
- 跨子系统的通信契约集中在 `command-bus.ts` 与 `event-system.ts`：菜单与战斗都通过命令总线发布意图，事件系统负责解析脚本并触发副作用；`mode.ts` 与 `scene-system.ts` 则根据当前场景决定由哪个子系统处理输入。
- `inspect/battle-inspect.ts` 作为调试工具直接读取 `BattleState` 快照，不参与主循环。
