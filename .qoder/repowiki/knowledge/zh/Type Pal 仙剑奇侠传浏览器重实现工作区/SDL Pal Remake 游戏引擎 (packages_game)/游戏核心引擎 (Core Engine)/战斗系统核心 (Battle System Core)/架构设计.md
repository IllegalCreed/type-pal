本模块围绕 `BattleState`（core_state_positions_settlement）这一工作副本展开，所有子模块通过读取/修改其字段协作：
- `turn-queue.ts` 按 SDL 规则构建行动顺序，调用 `actions/*` 中的纯函数式动作处理器；
- 动作处理器依赖 `ai_formulas_damage_status` 提供的伤害计算与状态机，并触发 `battle-anim-driver.ts` 生成 `BattleAnimFrame` 序列写入 `anim-timeline.ts`；
- `enemy-ai.ts` 在每回合开始时基于同一 `BattleState` 选择下一个行动者，保证玩家与敌人共享确定性输入；
- 回合结束时由 `battle-settlement.ts` 读取最终状态判定胜负。
所有计算均为纯函数或无副作用更新，使同一 `BattleState` 初始值可被测试用例精确回放。
