模块由两层组成:
- `turn-queue.ts`:纯函数 `buildActionQueue`,按 SDLPal `fight.c` 规则把敌人(含 dualMove 二次)和队员按 dexterity 降序稳定排序,产出 `ActionQueueItem[]`,供上层 tickPerformAction 消费。
- `actions/` 下每个文件对应一个 `kBattleAction*` 枚举值,导出独立的 `performXxx(state, ...)` 函数:物理(`attack.ts`)走 `calcPhysicalAttackDamage` + 动画时间线;法术(`magic.ts`)扣 MP → 跑 `spell.scriptOnUse`/`scriptOnSuccess` → 可选 inline 伤害 → 建 PreMagic/OffMagic/DefMagic/Summon/Trance 链;物品(`item.ts`)跑 `item.scriptOnUse` 后按 consuming 扣库存;防御(`defend.ts`)仅置 flag;逃跑(`flee.ts`)用修复版 fleeRate 公式并播放失败动画。

依赖方向单向:action 文件只读 `BattleState`、通过 `CommandBus` emit Present 命令、调用 `anim-timeline.ts` 与 `battle-anim-driver.ts` 构造帧序列,不反向引用 turn-queue;`turn-queue.ts` 自身无外部依赖,是纯数据转换层。所有 perform 函数都附带 sdlpal 源码行号注释,以 `from reference/sdlpal/fight.c:...` 为契约锚点。
