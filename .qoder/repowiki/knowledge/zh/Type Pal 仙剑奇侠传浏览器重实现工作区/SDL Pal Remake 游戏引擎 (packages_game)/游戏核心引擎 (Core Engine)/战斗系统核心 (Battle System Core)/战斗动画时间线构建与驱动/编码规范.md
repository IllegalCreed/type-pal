- 每个 timeline builder 顶部注释以「对照 fight.c:XXXX-YYYY」形式列出 sdlpal 源行号,作为 1:1 port 的可追溯证据。
- 帧时长一律经 `delayMs(frames)` 计算再写入 `durationMs`,禁止硬编码毫秒值,确保 40ms 基准一致。
- Builder 输入使用具名接口(`BuildPlayerAttackInput`/`BuildEnemyPhysicalInput`/`BuildOffMagicInput` 等),字段注释说明 sdlpal 语义与缺省行为,而非裸对象字面量。
- 可选副作用(sound/damageNum/battleMessage/screenWave/keepEffect)采用条件展开 `...(cond ? { field } : {})` 挂到 frame 上,由 driver 逐帧消费,保持 builder 纯输出。
- opcode handler 对未注入表或无目标的情况统一返回 `{ consumed: true }` 静默 no-op,避免抛错破坏脚本执行流。
