本模块由三个职责正交的文件组成，依赖方向单向：`enemy-ai.ts` → `formulas.ts` ← `magic-damage.ts`。

- `enemy-ai.ts`：纯函数 `decideEnemyAction`，对照 sdlpal `PAL_BattleEnemyPerformAction` 的 fallback 分支（sleep/paralyzed→pass；confused→随机活敌或自身；silence→禁魔法；否则按 magicRate 掷骰选魔法或物理），通过可选 `status` / `party` / `enemySlots` 参数在旧 fixture 与 RNG 逐抽对齐的新路径间切换，输出 `BattleAction` union。
- `formulas.ts`：5 个纯函数 1:1 port 自 `fight.c` 的 PAL_CLASSIC 路径——`calcBaseDamage`、`calcPhysicalAttackDamage`、`calcMagicDamage`、`getEnemyDexterity`、`getPlayerActualDexterity`，用 `(n << 16) >> 16` 模拟 C SHORT 语义，所有浮点截断用 `Math.trunc` 保证与 C truncate-towards-zero 一致。
- `magic-damage.ts`：封装两条 sdlpal 法术伤害入口的共享核心——`applyMagicDamage`（玩家→敌人 inline 攻击法术，minDamage=1）和 `applyEnemyMagicDamage`（敌人→玩家，含 autoDefend 预掷、resistMult=20、defending/Protect/autoDefend 除因子、clamp 到 hp），并通过 `simulateMagic` 复用同一骨架处理 0x42 SimulateMagic 与 0x66 throw weapon；`resolveObjectMagic` 从 object-magics.json 解析任意 id 到 magic union 视图。

边界约定：本模块不持有 RNG 状态，RNG 通过 `SeedableRng` 注入；不执行脚本（wScriptOnTurnStart/Ready/BattleEnd）、不展开 dualMove 队列、不 perform 具体 action，仅产出 `BattleAction` 或返回伤害结果供上层 battle-system 消费。
