本模块由三个文件构成战斗核心数据层：
- `battle-state.ts`：声明所有战斗运行时类型（`BattlePlayer`/`BattleEnemy`/`BattleAction`/`BattleAnimFrame`/`SummonFrameState` 等）以及 `BattleState` 主结构体，提供纯函数 `createBattleState(input)` 把 `GameState` + fixture 投影为可变的局部 working state；字段注释逐条对齐 sdlpal `fight.c` / `battle.h` 的 C 结构体与常量。
- `battle-system.ts`：消费上述类型实现 phase 状态机入口 `startBattle` / `tickBattle`，通过 `gs.__battleResources` 注入资源表，按 `preBattle → selectAction → performAction → postAction → won/lost/fleed` 流转，并在 `won` 首 tick 调用 `buildBattleWonSettlement` 构建 `state.settlement` 交给顶层 hold 处理。
- `battle-settlement.ts`：仅定义结算演出数据结构（`BattleSettlementScreen` union、`LevelUpScreenData`、`HiddenExpUpScreenData`、`BattleSettlementState`）及超时计算 `settlementScreenTimeoutMs`，被 battle-system 在 won 阶段消费。
依赖方向单向：`battle-system.ts` 消费 `battle-state.ts` 的类型与工厂，`battle-settlement.ts` 只暴露接口供两者引用；三者均不反向依赖 present 层，present 仅读取 `BattleState` 字段渲染。
