模块由三层构成:
- `anim-timeline.ts`:纯函数 builder 集合(如 `buildPlayerAttackTimeline`/`buildEnemyPhysicalTimeline`/`buildPlayerOffMagicTimeline`),接收只读快照(`posOriginal`/idx/精灵参数)返回 `BattleAnimFrame[]`,不 mutate state;每个 builder 注释标注对应 fight.c 行号作为 1:1 port 证据。
- `battle-anim-driver.ts`:运行时驱动,提供 `startBattleAnim`(建 `state.battleAnim`)、`advanceBattleAnimFrames`(40ms tick 推进 idx+apply)、`stepBattleAnimRender`(rAF wall-clock 视觉细分,仅刷 `applyAnimFrameVisual` 避免逻辑副作用漂移)、`resetFightersAfterAction`(port PAL_BattleUpdateFighters 复位段);sound/damageNum/battleMessage 通过 `CommandBus` emit,与 present 解耦。
- `battle-opcodes.ts`:M5.B-w2.a 的 battle-context opcode 分发器(`dispatchBattleOpcode`),在 0x42/0x66/0x92/0x6A 等 case 中调用 timeline builder + `startBattleAnim`,把脚本指令桥接到时间线。
依赖方向:`opcodes → (timeline builders + driver)`,driver 仅依赖 `battle-state` 类型,避免与上层 action 系统循环引用。
