- 每个菜单文件导出 createXxxMenu(state 构造) + moveUp/Down/Left/Right/PageUp/PageDn/Home/End/Cancel/Confirm 等输入处理函数,由 menu-driver 统一按 kind 分派调用。
- 菜单状态使用显式 `phase` 字段('list'|'use-target'|'done'|'pick-caster'|…) 表达 sdlpal 内部 while-case 流程,dispatcher 在 Confirm 分支中切换 phase 并决定是否 push 新菜单或 pop 栈。
- 跨菜单共享的全局光标(g.iCurInvMenuItem/g.iCurMainMenuItem/g.iCurSystemMenuItem/g.iCurInvActionMenuItem)每帧由 dispatcher 写回,保证 ESC 重开菜单时光标位置持久。
- Catalogs(items/spells/magics/playerRoles)通过模块级 setMenuCatalogs 单例注入,requireCatalogs() 在运行时读取,避免 tick 接口侵入 deps 参数。
- 与外部副作用(开始新游戏/读档/退出)一律通过 setXxxHandler 注入回调,dispatcher 只 fire-and-forget Promise,不直接 import scene-system/save api。
- 菜单颜色常量(MENUITEM_COLOR/MENUITEM_COLOR_INACTIVE/…)/网格尺寸(INV_ITEMS_PER_LINE=3,INV_LINES_PER_PAGE=7)集中声明并与 sdlpal 宏值一致,由 pickItemRowColor 纯函数计算闪烁色供渲染层复用。
