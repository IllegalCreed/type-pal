模块由一个主 CLI (`src/cli.ts`) 和一组独立可执行的 `scripts/*.ts` 组成,二者都通过 `fileURLToPath(import.meta.url)` + 相对路径推导 `REPO_ROOT`,再固定读写 `data/raw`(输入)与 `data/extracted`(输出),不共享运行时包。

- `cli.ts`:Shebang `#!/usr/bin/env node`,作为 `pnpm extract` 的总装入口,按阶段顺序调用 `io/mkf.js`、`events/disasm|annotate|recompile|slice`、`resources/*` 解析器,把 MKF/GOP/PAT/MGO/F.ABC/FIRE/RNG/RGM/BALL/SOUNDS.MKF 等二进制拆成 JSON manifest + PNG/gzip RLE blob,最后用 `buildManifest(collectAssetEntries(OUT))` 生成 SW 预缓存清单;执行前会清空 `data/extracted` 但保留 `videos/` 目录。
- `scripts/extract-videos.ts`:外部依赖 ffmpeg,将 `data/raw/{1-6}.avi` 转 H.264+ AAC mp4 到 `data/extracted/videos`,增量跳过逻辑基于 mtime。
- `scripts/render-tilemap.ts`:纯函数 `renderTilemap()` 导出供测试 import,同时支持 `tsx` 直接运行渲染 scene 1 或 `--map=N`;内部自行实现 sdlpal 同源的 RLE 解码与 isometric blit,用于 pixelmatch 基线对比。
- `scripts/sdlpal-dump-map-all.ts`:编排 `sdlpal-classic --dump-map` 与本模块 `renderTilemap` 的全量 pixel diff,产出 `build/m4-map-diff.md` 与 JSON 报告。
- `scripts/find-scenes-without-setpartypos.mjs`:扫描 `data/extracted/events` 中缺少 `setPartyPos` 的 scene,按 caller-trace → NPC-anchored BFS → bare BFS 三级策略推断 partyStart,结果写 `/tmp/scenes-without-setpartypos.json`。
- `scripts/grep-sdlpal-chunks.ts`:调用系统 `grep` 在 `reference/sdlpal/` 里按 MKF chunk 名分组输出引用,辅助文档草稿。

依赖方向:scripts 仅依赖 Node fs/path/child_process 和本模块 `src/io/mkf.js` 及自身实现的算法,不被其他包反向引用,属于一次性构建工具集。
