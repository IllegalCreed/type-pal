需要先在仓库根准备 `data/raw/` 下的 SDL-PAL 原始数据(MKF、GOP、Musics、unifont-cn.bdf 等);视频脚本要求 `ffmpeg` 在 PATH(macOS:`brew install ffmpeg`);常用命令:
- `pnpm -F @type-pal/pal-extract extract` — 全量资源提取
- `pnpm -F @type-pal/pal-extract extract:videos` — AVI→mp4 转码
- `pnpm -F @type-pal/pal-extract render-tilemap` — 渲染 scene 1 tilemap 到 `build/scene-1-full.png`
- `pnpm -F @type-pal/pal-extract sdlpal-dump-map-all` — 全场景 pixeldiff 报告
- `pnpm tsx packages/pal-extract/scripts/find-scenes-without-setpartypos.mjs` — 推断缺失 partyStart 的 scene
