- 所有脚本通过 `dirname(fileURLToPath(import.meta.url))` 推导 `HERE`,再以 `resolve(HERE, '../../..')` 定位 `REPO_ROOT`,避免硬编码绝对路径。
- 对外部二进制依赖(`ffmpeg`、`sdlpal-classic/unix/sdlpal`、系统 `grep`)统一用 `execFile`/`execFileSync` 调用并显式检查 PATH,失败时打印安装指引后 `process.exit(1)`。
- MKF 读取一律走 `openMkf(loadFile(...))` + `readChunk(mkf, i)` 模式,并对空 chunk / YJ2 解压异常做 try/catch 防御性跳过。
- 资源管线优化产物统一以 gzip 压缩的原始字节流写入 `.rle` 后缀文件(非 `.gz` 以避免服务器 Content-Encoding 双解压),manifest JSON 仍列出帧级元信息。
- JSON 输出通过 `writeJson(path, data)` 封装,先 `mkdirSync(dirname(path), { recursive: true })` 再 `JSON.stringify(data, null, 2)` 格式化写入。
- 脚本入口采用 IIFE 风格:定义 `main()` 异步函数并在末尾 `main().catch(err => { console.error(err); process.exit(1) })`,错误码区分业务失败(如 round-trip 校验失败 exit 2)与未捕获异常(exit 1)。
