- 所有二进制结构以常量声明记录大小与字段数(`*_SIZE`/`*_FIELDS`/`*_COUNT`),并在解析入口用 `byteLength % SIZE !== 0` 做对齐校验后抛错。
- 每条记录先 `slice` 出子缓冲再用 `DataView.getUint16(offset, true)` 逐个槽位读取,同时保留一份 `raw: Uint16Array` 暴露原始 u16 序列。
- GBK 文本一律经 `decodeGbk` 解码后再做后处理(如 `stripTrailingOne` 剥尾部标记字符 `'1'`),避免误伤双字节 trail。
- 可复用的 MKF/YJ2/RLE 解码不在此处实现,而是以 `export { ... } from '@type-pal/shared'` re-export,维持旧 import 路径的同时供 runtime 复用。
