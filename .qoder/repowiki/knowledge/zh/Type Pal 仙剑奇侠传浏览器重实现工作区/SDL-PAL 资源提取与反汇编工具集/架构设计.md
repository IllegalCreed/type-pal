本模块按关注点拆分为四层，由顶层 `src/cli.ts` 统一编排：
- `io/` 提供 MKF/SSS/M.MSG/WORD.DAT/RLE/YJ2 等底层归档与压缩格式的字节解析；
- `resources/parsers/` 消费 io 层输出，将 DATA.MKF 的 ball/sounds/items/enemies 等 chunk 转为 JSON 中间产物；
- `events/` 独立于 resources，对事件字节码执行 disasm → annotate → slice → recompile 的 roundtrip 管线；
- `scripts/` 与根目录 `audit-data-mkf.mjs` 作为一次性分析/渲染脚本，复用上述库。
所有子包共享同一份 tsconfig 与 package.json，通过相对路径在 src 内部互相引用，测试文件与源码同目录放置（__tests__/xxx.test.ts），形成“解析器 + 单测”的一体化组织。
