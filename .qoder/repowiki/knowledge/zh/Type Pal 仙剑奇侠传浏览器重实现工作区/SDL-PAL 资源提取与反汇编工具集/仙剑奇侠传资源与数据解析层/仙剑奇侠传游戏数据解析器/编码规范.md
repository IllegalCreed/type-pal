- 每个 parser 在文件顶部用注释列出所对照的 sdlpal `global.h` 结构体名与字段顺序,作为布局契约文档。
- 字段偏移集中声明为 `const OFF = { field: byteOffset } as const` 对象,再通过 `u16(view, base, OFF.field)` 读取,禁止硬编码偏移数字。
- 对输入 buffer 长度进行显式下界检查并在不足时抛错(`expectedMinBytes`),而非静默截断,保证解析失败可定位。
- 可选的名称字段一律命名为 `_name?: string`,由调用方传入的 `Words` 经 OBJECT 段反向查找填充,引擎运行时不消费。
- 带符号语义的 WORD 字段使用 `s16()` 读取(如 ENEMY 的攻击修正、速度、声音),无符号字段用 `u16()`,并在注释中标注 signed 来源。
- 位域标志(raw u16)拆成具名布尔对象(`ItemFlags`、`SpellFlags`),并通过本地 `parseXxxFlags` 函数封装,避免在解析循环中散落 `!!(raw & (1 << N))`。
