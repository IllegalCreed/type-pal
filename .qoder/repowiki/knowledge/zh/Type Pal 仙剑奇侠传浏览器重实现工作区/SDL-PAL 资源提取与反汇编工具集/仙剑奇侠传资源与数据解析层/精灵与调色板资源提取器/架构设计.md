本模块按资源类型拆分为三个独立入口:
- `sprite.ts`:核心管线,复用 `@type-pal/shared` 的 `parseSpriteChunk` 把 RLE 帧转为 `RleFrame[]`,再用 `encodeIndexedPng` 以 RGBA 三通道复制 palette index、alpha 通道承载 opaque mask 的方式输出 PNG 字节;对外暴露 `extractCharacterSprites(spriteIds, mgoChunks)` 供调用方传入已解压的 MGO.MKF chunk。
- `battle-sprite.ts`:战斗 sprite 提取,复用 `framesToOut`/`parseSpriteChunk`;通过 `${kind}:${id}` 复合键区分来源 MKF(F.MKF 队员 vs ABC.MKF 敌方),由调用方负责按 kind 从正确文件读 chunk。
- `palette.ts`:纯函数解码 PAT.MKF chunk(768 或 1536 字节)的 VGA 0-63 → RGB 0-255 升位,可选夜间半块与 cycles 段。
依赖方向单向: battle-sprite → sprite → @type-pal/shared + pngjs;本模块不直接读写磁盘,只接收/产出 Uint8Array 与结构化对象。
