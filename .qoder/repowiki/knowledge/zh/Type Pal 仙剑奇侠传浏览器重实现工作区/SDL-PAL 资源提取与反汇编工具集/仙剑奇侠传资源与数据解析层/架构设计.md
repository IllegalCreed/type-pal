本模块按资源域横向切分子目录：`parsers/` 下每个文件对应一个 global.h 结构体或 MKF chunk（如 `items.ts`、`spells.ts`、`enemies.ts`、`player-roles.ts`、`ball.ts`、`rgm.ts`、`rng-frames.ts`、`sounds.ts`、`stores.ts`、`battle-fields.ts`、`fire.ts`），通过共享的 `_utils.ts` 暴露 OBJECT 段偏移常量与 u16/s16 读取 helper；`map.ts`、`scene.ts`、`enemy-pos.ts` 负责 MAP.MKF/GOP.MKF 与 SSS.MKF chunk 13 的地图/场景/敌方站位解析；`sprite.ts`、`palette.ts`、`battle-sprite.ts` 处理 MGO/F/ABC.MKF 的 RLE 位图帧与 VGA 调色板；顶层 `asset-manifest.ts` 提供 `collectAssetEntries` + `buildManifest` 将各解析器产出的 PNG/JSON 扫描为带 SHA256 version 的清单。所有解析器遵循“输入 Buffer/DataView → 纯函数 → JSON 对象数组”的契约，由上层 CLI 编排调用并写入 `extracted/` 目录。
