本模块由三个独立解析函数组成,分别对应三类游戏数据:
- `map.ts`:把已解压的 65536 字节 MAP.MKF chunk(128×64×2 u32 LE)与原始 GOP.MKF sprite chunk 组合成 `{ tilemap, tiles }`,tileset 字段留空由上层 CLI 填充 gzip blob 路径。
- `scene.ts`:基于 SSS.MKF 的 scenes/eventObjects 全局表,按 scene[eventObjectIndex..nextScene.eventObjectIndex) 区间切分,生成 `dumpAllEventObjects` 与 `dumpScene` 两个导出;脚本入口 ip=0 映射为 undefined,其余统一为 `L_<ip>` 标签。
- `enemy-pos.ts`:解析 DATA.MKF chunk 13 的 5×5 PALPOS 数组,将 C 侧 pos[enemyIdx][maxEnemyIndex] 转存为 layouts[count-1][enemyIdx],以适配运行时按 enemyCount 选择 layout 行。
依赖方向单向:仅 import `@type-pal/shared` 中的共享类型(`Tilemap`,`RleFrame`,`parseSpriteChunk`,`SceneObjects`,`EventObjectsFile`)以及本包内 `io/sss.js` 的原始结构,不反向依赖 CLI 层。
