- 每条指令固定 8 字节(u16 opcode + 3×u16 operand),所有二进制 I/O 一律通过 `DataView.getUint16(off, true)` / `setUint16(..., true)` 小端读取写入。
- opcode 语义集中在 `opcodes.ts` 的 `opcodeTable` 注册表中声明,disasm/recompile 通过查表或 `lookupOpcode` 反向查找分发,禁止硬编码 opcode 数值。
- 反汇编采用“两遍扫描”模式:第一遍产指令并收集 label 目标,第二遍统一打 `L_N` 标签,确保 goto 目标在输出中可见。
- 对尚未完整处理的 opcode 一律回退到 `{ op:'raw', opcode, operands }`,保证 disasm→recompile 的字节级可逆不变量。
- BFS 可达性分析同时处理具名 goto 的字符串标签与 raw 条件跳转的数字 operand(JUMP_TARGET_OPERAND/RANDOM_JUMP_OPCODE),防止 slice 误剪分支。
- 注解查找优先使用外部 symbols 表,再降级到 WORD.DAT 名表并按 wObjectID 减去对应 OBJ_START 偏移,越界返回 undefined 不注入注释。
