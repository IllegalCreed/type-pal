模块围绕 8 字节定长指令(u16 LE opcode + 3×u16 LE)的 SDL-PAL 脚本系统,按职责拆分为五个独立文件:
- `opcodes.ts`:opcode 注册表(`opcodeTable`),声明每条指令的 3 个操作数字段语义(FieldKind)、条件跳转目标映射(`JUMP_TARGET_OPERAND`)以及随机跳(0xA2)特殊处理,并自动为未具名 opcode 填充 raw 占位。
- `disasm.ts`:两遍扫描——第一遍逐条翻指令为 Command(具名 opcode 产出结构化命令,其余落 `raw` 保证字节可逆),同时收集所有 label 目标;第二遍给被跳转/入口 ip 打 `L_N` 标签。
- `recompile.ts`:disasm 的严格逆操作,通过 label→index 映射把字符串跳转还原为 u16 偏移,维持 disasm↔recompile 的字节级不变量。
- `slice.ts`:基于 BFS 从每个场景的 scriptOnEnter/scriptOnTeleport 及事件对象 trigger/autoScript 入口出发,计算每条指令的 reachable-by-scene 集合,将仅单场景命中的指令归入 scene 文件、≥2 个场景命中的归入 shared,并改写跨文件 goto 为 `shared#L_N`;另对 items/spells/enemyObjects 的全局 script 入口做独立 BFS 并强制归 shared。
- `annotate.ts`:遍历结构化 Command 树(sequence/if/choice/raw),对照 WORD.DAT 名表(wObjectID 命名空间偏移 PERSON_OBJ_START/ITEM_OBJ_START/…)和外部 symbols 表,在 itemId/spellId/personId/enemyId 等字段旁注入 `_item/_spell/_person/_enemy/_scene` 可读注释。
- `roundtrip.ts`:串联 parseSss+parseMessages → disasm → recompile,逐字节比对原始与重编译产物,失败时报告首个差异的字节偏移、指令下标与 opcode。
依赖方向单向:disasm/recompile/slice/annotate 均只读 opcodes 定义;roundtrip 组合 disasm+recompile;无循环依赖。
