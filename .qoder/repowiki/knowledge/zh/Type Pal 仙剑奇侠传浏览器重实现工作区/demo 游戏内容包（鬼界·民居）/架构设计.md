本模块为纯数据驱动的游戏内容包，无代码逻辑，由引擎在运行时加载：
- `manifest.json` 作为包入口，声明 id/name/contentVersion、entryScene、content 各 JSON 文件映射、assets 子目录映射以及 startWorld 初始世界状态（队伍、金钱、已学技能、背包、种子属性）。
- `content/` 存放结构化数据：`scenes.json` 描述地图复用（reuseOriginalMap）、房间尺寸、入口坐标、实体与对话；`characters.json` 定义角色基础属性、初始装备与仙术；`items.json` 以统一 schema 描述消耗品与装备（buyPrice/sellPrice/equip/use/effects），effects 通过 kind 字段区分 healHp/statBonus/grantSkill 等；`skills.json` 与 `locale.json` 分别提供技能表与键值文案。
- `assets/` 按 manifest.assets 约定组织二进制资源：`maps/*.json`（地图布局）、`tilesets/*.rle` / `sprites/*.rle`（RLE 压缩图块与精灵）、`palettes/*.json`（调色板）。
依赖方向单向：manifest → content/*.json → assets/*，不反向引用任何代码。
