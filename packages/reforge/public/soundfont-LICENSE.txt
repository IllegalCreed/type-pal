TimGM6mb — SoundFont License
============================

soundfont.sf3 in this directory is "TimGM6mb" (SF2 format despite the file
extension; the runtime synth detects format by RIFF content, the URL is just
kept stable), used as the General MIDI synthesis bank for runtime BGM playback
(SpessaSynth).

Chosen over the previous GeneralUser GS 2.0.3 (32 MB) for its small size
(~6 MB): the production server bandwidth (~440 KB/s) made the 32 MB bank
dominate cold-start loading time (2026-06-12). To switch back, restore
the file from git history and revert this notice.
